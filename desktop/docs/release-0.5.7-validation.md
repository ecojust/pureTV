# pureTV Manager 0.5.7 发布验证

**准备中，尚未发布。** 本文件只记录本轮范围与待完成验证，不能作为安装包已通过检查或已公开的证明。

## 改动范围

Gitee 市场当前的麦动KTV 2.1.10 为 53,570,243 字节，其原始下载地址返回 HTTP 403。旧版管理器把 Git blob 备用下载限制在 32 MiB，因此拒绝这份文件。0.5.7 将 APK 市场备用下载上限提高到 128 MiB，并保留固定提交、Git blob、字节数、内容哈希、取消和超时检查。

这只覆盖已确认的客户端大小限制。用户尚未提供其具体应用与错误，不能据此认定所有“下载按钮无法下载”反馈都由同一原因造成。客户端自身更新与 APK 市场是不同下载流程。
