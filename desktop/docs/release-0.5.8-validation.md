# pureTV Manager 0.5.8 发布验证

**准备中，尚未发布。** 本记录完成版本与说明准备；0.5.8 源码冻结、正式 CI、安装包发布及公开下载验证仍待后续执行。未将 0.5.7 的测试结果记作本版本通过。

## 本次范围

- 管理器 APK 市场改用 `https://apps.b14f.com/` 下的 `game/`、`launcher/`、`media/`；客户端更新改用同一服务器的 `client/`。
- 读取服务器 HTML 目录，通过 HEAD 元数据与条件 GET 检查所选文件的一致性；下载后记录本地 SHA256，供缓存复用时校验。若匹配的 manifest `packages` 条目提供 SHA256，额外核对该值。
- 本地 SHA256 记录不等于服务器独立提供的内容校验；HTTP 元数据也不等于不可变 Git 提交。未声明服务器所有安装包均有 SHA256 清单。
- 移除这两条下载流程中的 Gitee 备用下载，隔离旧源缓存；论坛仍使用 Gitee issues。

上述为本次实现范围，运行结果以本版本后续验证为准。

## 版本准备

7 份版本及锁文件已从 0.5.7 精确更新至 0.5.8，共 9 处自有版本字段。JSON/TOML 结构比较确认第三方依赖及其他字段未变；主任务已修改的 `apps.b14f.com` CSP 与 devCsp 保持不变。

计划标签为 `desktop-v0.5.8`，尚未在本准备阶段创建；最终源码提交与工作流编号待填写。

## 服务器状态

主任务迁移检查阶段观测到 36 个 APK：游戏 20、启动器 10、影音 6；`client/` 目前仅有 0.5.6。该记录不是 0.5.8 上传完成的证明，目录内容会变化，发布前后需重新核验。

本准备阶段未上传服务器文件。即使后续 GitHub Release 发布成功，应用内更新仍以服务器 `client/` 中实际提供的版本为准，不能把 GitHub 发布与服务器同步合并为一个状态。
