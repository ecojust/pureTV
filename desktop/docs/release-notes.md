# pureTV Manager 0.5.1

## 简体中文

- APK 市场按「启动器、影音、游戏」排列，分别显示数量，支持分类内搜索并记住各类滚动位置；保留原有下载、版本选择与待安装流程。
- 启动器布局中新增应用块或切换应用时，自动填入应用名称和已缓存的 SVG 图标，文字默认白色。已有布局的自定义内容保持不变。
- 移除窗口顶部及内容区底部重复的软件名称，保留左下角品牌标识与原生窗口按钮。
- 软件上架入口与弹窗统一为「软件上架请直接提交 PR」，同步简体中文、繁体中文和英文。

## 繁體中文

- APK 市場依「啟動器、影音、遊戲」排列，分別顯示數量，支援分類內搜尋並記住各類捲動位置；保留下載、版本選擇及待安裝流程。
- 啟動器佈局新增應用區塊或切換應用時，自動填入應用名稱與已快取的 SVG 圖示，文字預設白色。既有佈局的自訂內容保持不變。
- 移除視窗頂部及內容區底部重複的軟體名稱，保留左下角品牌標誌與原生視窗按鈕。
- 軟體上架入口與彈窗統一為「軟體上架請直接提交 PR」，同步三種介面語言。

## English

- APK Market tabs are ordered Launchers, Media and Games, with separate counts, searches within each category and remembered scroll positions. Downloads, version selection and installation queues retain their existing behavior.
- Adding an app tile or selecting another app in the launcher editor fills in its name and cached SVG logo, with white text by default. Existing custom layouts are preserved.
- Removes duplicate product names from the window title and content footer, retaining the lower-left logo and native window controls.
- The software listing button and dialog now say “Submit a PR to list software,” with matching Simplified Chinese and Traditional Chinese translations.
