# pureTV Manager 0.8.0

## 简体中文

- 游戏卡片新增「部署到电视」。连接并授权目标电视后，点一次即可从本地准备 APK、安装到电视。安装成功后，管理器会提示你在电视启动器中把游戏添加到主屏幕。
- 电脑直接从 48 款内置游戏项目读取程序、图像和音效。部署时用同一份项目和随附的正式签名数据组装电视 APK。电脑首次游玩、保存 APK 以及通过已连接的 ADB 部署都能在没有互联网的情况下完成。
- 「联网游戏」保留六款作者托管的作品，以及《Kart Rush》和《CF 运输船》。这两款在电脑上联网游玩，首次部署从原发布地址获取电视包。
- 安装文件变大。0.7.0 及更早版本的内置更新器对安装包有大小限制，从本页下载对应平台的新版覆盖安装即可保留现有配置。

## 繁體中文

- 遊戲卡片新增「部署到電視」。連線並授權目標電視後，按一下即可從本機準備 APK、安裝到電視。安裝成功後，管理器會提示你在電視啟動器將遊戲加入主畫面。
- 電腦直接從 48 款內建遊戲專案讀取程式、圖像和音效。部署時使用同一份專案及隨附的正式簽署資料組裝電視 APK。電腦首次遊玩、儲存 APK，以及透過已連線的 ADB 部署，都可在沒有網際網路的環境下完成。
- 「連線遊戲」保留六款由作者代管的作品，以及《Kart Rush》和《CF 運輸船》。這兩款在電腦上連線遊玩，首次部署從原發行來源取得電視安裝檔。
- 安裝檔較大。0.7.0 和更舊版本的更新器有安裝檔大小限制，請從本頁下載新版並覆蓋安裝，保留既有設定。

## English

- Choose **Deploy to TV** on a game card after connecting and authorizing your TV. Manager prepares the APK locally, installs it on that TV and, on success, explains how to add the game to the launcher’s home screen.
- The client runs 48 games from their bundled project files. To deploy a game, it assembles the TV APK from those same files and the original signing data. Play on your computer for the first time, export an APK or deploy to a connected TV over ADB without internet access.
- **Online games** includes six author-hosted titles plus Kart Rush and CF Transport Ship. These last two games use the web player on your computer and retrieve their original TV package on first deployment.
- Because the game library increases installer size, the updater in 0.7.0 and earlier may reject the download. Install the package for your platform from this release to keep your settings.

Windows x64 安裝版及可攜版、macOS ARM64 和 Intel DMG、Linux x64 DEB 的校驗值見 `SHA256SUMS.txt`。macOS 使用 ad-hoc 簽署，尚未經過 Apple 公證。Windows 安裝套件未使用商業程式碼簽署。應用程式內更新以 [client 目錄](https://apps.b14f.com/client/) 提供的版本為準。

Checksums for the Windows x64 installer and portable executable, macOS ARM64 and Intel DMGs, and Linux x64 DEB are in `SHA256SUMS.txt`. macOS builds use ad-hoc signing and lack Apple notarization. Windows builds lack commercial code signing. In-app updates use the versions available in the [client directory](https://apps.b14f.com/client/).
