# pureTV Manager 0.4.8

## 简体中文

在布局编辑器中点击“添加应用块”，新建块默认宽度为 **160**、高度为 **142**。Home 和 Apps 页面均使用此尺寸，画布预览与应用到电视的布局保持一致。已有应用块保留原尺寸，新建后仍可手动调整宽高。

## 繁體中文

在佈局編輯器中點擊「新增應用區塊」，新建區塊預設寬度為 **160**、高度為 **142**。Home 和 Apps 頁面均使用此尺寸，畫布預覽與套用至電視的佈局保持一致。現有應用區塊保留原尺寸，新增後仍可手動調整寬高。

## English

New app blocks created with “Add app block” in the layout editor now default to **160 wide × 142 high** on both Home and Apps pages. The canvas preview and layout applied to the TV use the same dimensions. Existing app blocks retain their sizes, and you can still adjust the width and height after adding a block.
