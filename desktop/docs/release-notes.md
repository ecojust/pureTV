# pureTV Manager 0.9.0

## 简体中文

- 打开「游戏 → 本地游戏」，选择包含 `index.html` 的目录即可在管理器内游玩自己的网页游戏。目录中的修改会在下次打开时生效。
- 游戏可通过 WebSocket 读取 pureTV 局域网手柄的玩家席位、方向和动作键。本地游戏页提供 MCP 配置，可用开发工具登记和启动游戏、查询连接状态、发送测试按键。
- 「线上游戏」保留新版游戏卡片。点击封面即可游玩，支持离线的游戏首次打开时自动下载，完成后封面会显示「已下载」。连接电视后可从卡片部署游戏。

## 繁體中文

- 開啟「遊戲 → 本機遊戲」，選取含有 `index.html` 的資料夾，即可在管理器內遊玩自製網頁遊戲。下次開啟遊戲會載入最新的檔案。
- 遊戲可透過 WebSocket 讀取 pureTV 區域網路手把的玩家席位與按鍵。本機遊戲頁提供 MCP 設定，可用開發工具登記及啟動遊戲、查看連線狀態並傳送測試按鍵。
- 「線上遊戲」沿用新版遊戲卡片。點選封面即可遊玩，支援離線的遊戲會在首次開啟時下載，完成後封面會顯示「已下載」。連接電視後可從卡片部署遊戲。

## English

- Open **Games → Local games** and add a folder containing `index.html` to play your own web game in Manager. Reopen the game to load edits.
- Read player seats, directions and action buttons from pureTV LAN controllers over WebSocket. The Local games tab provides the MCP configuration for registering and launching games, inspecting connections and sending test input.
- **Online games** keeps the updated catalog cards. Select a cover to play. Offline-capable games download on first launch and display a downloaded badge. Use **Deploy to TV** to install a catalog game on a connected TV.
