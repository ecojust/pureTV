# pureTV Manager 0.7.0

## 简体中文

- 左侧「游戏」整合「网页游戏」和「电视游戏市场」。在网页游戏卡片上可选择「电脑游玩」，也可为目录中已有的 56 款游戏准备电视 APK。
- 其中 50 款通过「获取电视 APK」取得官方签名包。六款作者在线游戏通过「生成电视 APK」在电脑上用预签名模板组装，各款独立安装，游玩时由电视联网加载作者网站。
- 在弹窗核对包名和 SHA-256 后，可将 APK 保存到电脑，无需连接电视。也可加入安装队列，在「待安装应用」中通过 ADB 安装到已连接的电视。

## 繁體中文

- 左側「遊戲」整合「網頁遊戲」和「電視遊戲市場」。在網頁遊戲卡片上可選擇「在電腦上遊玩」，也可以為目錄中已有的 56 款遊戲準備電視 APK。
- 其中 50 款透過「取得電視 APK」取得官方簽署的安裝檔。六款由作者代管的遊戲可透過「產生電視 APK」，在電腦上使用預先簽署的範本組裝。各款可獨立安裝，遊玩時電視需要連線至作者網站。
- 核對套件名稱與 SHA-256 後，可將 APK 儲存至電腦，無須連接電視。也可加入安裝佇列，在待安裝清單中透過 ADB 安裝到已連線的電視。

## English

- Open **Games** in the sidebar for both **Web games** and the **TV game market**. Each of the 56 web game cards lets you play on your computer or prepare a TV APK.
- Choose **Get TV APK** to retrieve an official signed package for 50 games. For the six games hosted by their authors, **Build TV APK** assembles a standalone package on your computer using a pre-signed template. Each installs separately and connects to the author’s site to play.
- Check the package name and SHA-256, then save the APK to your computer without connecting a TV. To install it, add it to the install queue and use **Pending apps** with an authorized ADB connection.

Windows x64 安裝版及可攜版、macOS ARM64 和 Intel DMG、Linux x64 DEB 的校驗值見 `SHA256SUMS.txt`。macOS 使用 ad-hoc 簽署，尚未經過 Apple 公證。Windows 安裝套件未使用商業程式碼簽署。應用程式內更新以 [client 目錄](https://apps.b14f.com/client/) 提供的版本為準。

Checksums for the Windows x64 installer and portable executable, macOS ARM64 and Intel DMGs, and Linux x64 DEB are in `SHA256SUMS.txt`. macOS builds use ad-hoc signing and lack Apple notarization. Windows builds lack commercial code signing. In-app updates use the versions available in the [client directory](https://apps.b14f.com/client/).
