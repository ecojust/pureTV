# pureTV Manager 0.4.5

- 点击「应用到电视」后立即显示全局检查进度，明确提示正在读取电视应用并校验布局；检查失败或取消时显示结果，避免等待期间看起来没有响应。确认后仍显示写入进度和应用结果。
- 应用前检查保留当前编辑草稿和应用可用性校验，跳过其他启动器背景的读取，减少与本次操作无关的等待。
- 粘贴 SVG 图标时，自动移除 `role`、`aria-*` 属性及仅包含文本的 `title`、`desc` 元数据，使常见导出的 SVG 符合现有 v5 协议。保留实际图形路径、变换和颜色；不支持的绘图元素或脚本仍会拒绝，并提示具体原因。
- 修复属性面板「显示组件」开关开启后被普通复选框样式覆盖的问题，恢复圆形滑块，并使用当前主题的颜色；系统组件的只读开关保持禁用。

本次仅更新电脑管理器，无需更新电视端启动器 APK。[全部电视 APK、源码与截图](https://github.com/ecojust/pureTV/tree/master/resource)位于资源目录。

提供 Windows x64 安装版／便携版、macOS ARM64／Intel DMG、Linux x64 DEB；文件校验值见 SHA256SUMS.txt。macOS 为 ad-hoc 签名，未进行 Apple 公证；Windows 未进行商业代码签名。电视实机兼容性仍需安装验证。
