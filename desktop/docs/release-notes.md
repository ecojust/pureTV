# pureTV Manager 0.8.4

## 简体中文

- 在侧栏打开「游戏」，即可从同一份列表浏览游戏。点封面或游戏名称可在电脑上开始游玩。
- 支持离线游玩的游戏会在首次使用时自动下载并校验。保存成功后，封面右下角会显示「已下载」。
- 每张卡片都有「部署到电视」按钮。已下载的游戏会复用本地文件，作者托管的游戏仍需联网游玩。

## 繁體中文

- 從側欄開啟「遊戲」，即可在同一份清單瀏覽遊戲。點選封面或遊戲名稱即可在電腦上遊玩。
- 支援離線遊玩的遊戲會在首次使用時自動下載並驗證。儲存完成後，封面右下角會顯示「已下載」。
- 每張卡片都有「部署到電視」按鈕。已下載的遊戲會沿用本機檔案，作者代管的遊戲仍需連線遊玩。

## English

- Open Games in the sidebar to browse the catalog in one list. Select a cover or game title to play on your computer.
- Games with offline support download automatically on first use. A badge on the cover shows when the files have been verified and saved.
- Use Deploy to TV on any card. Downloaded games reuse their local files. Author-hosted games require an internet connection to play.
