# pureTV 电视系统管理器

**pureTV Manager 0.3.6** 是电脑端电视系统管理工具，通过 ADB 管理 Android TV / Google TV 的设备信息、应用和默认启动器，并提供完整 MCP 接口。

下载：[0.3.8 发布页](https://github.com/ecojust/pureTV/releases/tag/desktop-v0.3.8)。提供 Windows x64 安装版／便携版、macOS Apple Silicon ARM64／Intel x86_64 DMG（macOS 11+）和 Linux x64 DEB。文件大小与 SHA256 校验清单见发布页。管理器安装在电脑，电视开启并授权 ADB 即可管理应用。

## 功能

| 页面 | 功能 |
| --- | --- |
| 设备连接 | 首页输入 IP／端口与连接；展示 Android、SDK、安全补丁、CPU、内存、磁盘、分辨率、运行时间；下载或选择 ADB |
| 应用管理 · 已安装 | 搜索／分类、应用与启动器安装包大小、批量启用／停用、为当前用户卸载／恢复 |
| 应用管理 · 待安装 | 导入本地 APK、逐项或勾选批量安装；成功项移出队列，失败和未执行项保留 |
| 启动器 | 设置／恢复默认 HOME，查看包大小、导入和逐项安装启动器 APK；支持时读取和编辑 layout.json 布局及应用图标 |
| 操作记录 | 最近 200 项修改记录，包含目标设备／用户、逐项结果与错误 |

非首页仅在顶部显示当前连接状态，不重复放置 IP 和连接表单。各类列表独立滚动，表头及顶部批量操作保持可见，选择和重新渲染保留列表位置。

## macOS 安装与首次打开

提供 **Apple Silicon ARM64** 和 **Intel x86_64** 两种 DMG，最低系统均为 **macOS 11**，请按电脑芯片选择。打开 DMG，将 `pureTV Manager.app` 拖入 `Applications`，再从「应用程序」打开。

应用对整个 `.app` 执行 ad-hoc 签名，最低系统版本为 macOS 11。**ad-hoc 签名不是 Developer ID 签名，也不代表通过 Apple 公证**；首次打开仍可能出现来源或开发者验证提示。

- 提示「无法验证开发者」：尝试打开一次后，进入「系统设置 → 隐私与安全性」，找到 pureTV Manager 的拦截信息并选择「仍要打开」（Open Anyway）。macOS 11／12 的入口为「系统偏好设置 → 安全性与隐私」。
- 提示「已损坏，无法打开」：先从本仓库的 [0.3.8 发布页](https://github.com/ecojust/pureTV/releases/tag/desktop-v0.3.8) 下载 DMG 和 `SHA256SUMS.txt`，在终端进入下载目录并计算校验值：

  ```bash
  cd ~/Downloads
  shasum -a 256 pureTV-Manager-0.3.8-macos-arm64.dmg
  ```

  Intel Mac 将上述文件名换为 `pureTV-Manager-0.3.8-macos-x64.dmg`。

  将输出的完整 SHA256 与 `SHA256SUMS.txt` 中同名文件的一行比较；不一致时重新下载，不要打开该副本。校验一致后，重新将 DMG 中的应用拖入「应用程序」，覆盖旧版。

  如果校验一致、确认文件来自本仓库，重新安装后仍因下载隔离属性被拦截，可在终端对这一份可信应用解除隔离，然后再打开：

  ```bash
  xattr -dr com.apple.quarantine "/Applications/pureTV Manager.app"
  ```

  此命令仅移除上述应用的下载隔离属性，不使用 `sudo`，不关闭全局 Gatekeeper。如果仍打不开，请提供完整提示和 macOS 版本；不要扩大命令作用范围。**此方法不适用于「将损坏电脑」或其他恶意软件警报。**

## 连接与系统信息

首页先显示当前电脑的有效局域网 IPv4、网卡名称与子网前缀，支持「刷新本机 IP」。无需连接电视或安装 ADB；多网卡地址分别列出，不把本机 IP 自动当成电视地址。查询直接读取系统网卡，不访问公网 IP 服务。

1. 电脑与电视接入可互通的网络，在电视开发者选项开启 ADB／网络调试。
2. 首页填写 IP／主机名和调试端口，在电视上接受授权。点击连接后会记住有效地址和端口，连接失败也会保存；下次启动自动填入，不自动发起连接。
3. 首页自动显示系统信息，点击「刷新信息」重新查询。内存来自 `/proc/meminfo`，存储容量来自 `/data` 分区；权限或固件限制时显示未知。

### 连接失败排查

- **No route to host／无法通过局域网到达**：电脑当前无法到达电视，先确认电视在线且 IP 未变化，电脑与电视处于可互通的局域网，检查 VPN、防火墙和路由器访客网络／设备隔离。如果使用 macOS，进入「系统设置 → 隐私与安全性 → 本地网络」允许 pureTV Manager，然后重新打开应用连接。
- **Connection refused／拒绝连接**：检查电视是否开启网络 ADB 调试，以及端口是否与电视显示一致；端口不一定是 5555。
- **连接超时**：检查电视是否休眠、地址／端口、网络和防火墙是否放行。

管理器保留原始 ADB 错误，并提供对应中文／英文提示。地址只保存在本机应用数据目录，GUI 和 MCP 共用最近地址；不会把它写入浏览器存储。

## ADB 在线配置

主按钮在工具可用时显示「ADB 已就绪」；缺少 ADB 时显示「下载 ADB 工具」。点击「下载 ADB 工具」，阅读并勾选 Android SDK 许可后确认。固定版本 **Platform Tools 37.0.1** 优先 Google，失败自动切换腾讯镜像；所有来源核对同一官方字节数与 SHA256。解压完整工具集后检查 `adb version` 并保存路径。

工具区域另提供「重新下载」：即使 ADB 已就绪或缓存有效，也强制重新下载完整工具包、校验后在新目录配置。失败或取消保留原工具与配置，连接电视期间需先断开。

缓存校验完整时可离线复用；损坏缓存重新下载到新目录，不覆盖在用工具。工具放在电脑应用数据目录，不修改系统 PATH 或 macOS 应用包。已有 `adb`／`adb.exe` 可手动选择。更换 ADB 前需先断开电视。下载支持取消，失败或取消保留原有配置。

## 应用安装与包大小

在「应用管理 → 待安装应用」导入本地普通 APK，勾选后确认安装。每次最多 10 个，每个不超过 2 GiB；不支持 APKS／XAPK。成功项按完整路径移出待安装队列，其他项保留；安装不会因仅导入文件而自动执行。

安装后刷新应用列表，新的可启动应用可在启动器布局中选择。具备服务或其他用途但没有启动入口的 APK 不会被假装成可点击的启动器应用。

应用和启动器的大小统计主 APK 与分包 APK 的合计字节数，不包含应用私有数据、缓存、原生库或优化文件。通过分组查询路径和文件元数据减少 ADB 往返；无法读取或结果不完整时显示「未能读取」。

## 当前启动器的自定义布局

只有当前默认启动器成功返回符合协议的布局接口时才显示编辑器。Manager 0.3.7 动态检测已安装启动器的 `<包名>.layout` 协议接口，通过验证后支持编辑，无需添加包名白名单。**pureTV 0.3.6** 与 **Nova TV 0.1.0** 均已实现；其他启动器可按[接入规范](../resource/README-development.md#第三方启动器接入与动态检测)实现。仅有 APK 内静态 layout.json、尚未实现读写接口的启动器不能保存布局。包名变化需要安装新 APK 并重新选择默认桌面。

在当前默认启动器卡片点击「调整布局」，打开电视画布弹窗。Home 与 Apps 分别定义列数和卡片顺序，支持拖动、名称、图标、颜色及 layout.json 导入。只能添加已安装可启动的用户应用，应用后读回复查。旧版 apps.json 不兼容。详情：[启动器布局文档](docs/launcher-layout.md)。


## 语言、主题与资源

左下角支持简体中文、繁體中文、English，以及青绿、深蓝、石墨三套主题；窗口和 Agent 的偏好修改实时同步并保存。

根目录 [resource](../resource/README.md) 提供带实际 APK、作者、许可、源码和校验记录的资源。完整 layout.json 规范与文件／画面对照见[根 README](../README.md#layoutjson-规范与画面对照)。

## MCP / Agent

保持管理器打开，在首页「MCP · Agent 调试」复制 JSON 到客户端。标准 stdio 代理连接同一窗口，共享当前电视、Android 用户、ADB、操作锁和记录；状态、错误、布局与画面同步显示。

**31 个工具**覆盖界面现有设备管理功能，包括系统信息、连接、应用安装／卸载／启停、启动器切换／布局、ADB 下载配置、用户背景图、原生文件选择器、取消和历史。详见 [MCP 接入及工具](docs/mcp.md)。

## 操作范围与恢复

批量应用操作最多 100 项，逐项执行并核对，部分失败不报告为全部成功。核心组件与当前默认 HOME 受保护；切换桌面不会自动停用原厂桌面。卸载只针对当前用户，保留数据，不删除系统分区 APK；恢复要求设备仍保有安装包。

取消扫描／下载或停止后续批量项不会回滚已完成操作；正在执行的修改会完成并复查。配置、原桌面记录、工具与最近操作位于系统应用数据目录 `com.ecojust.puretv.manager`。用户提供的启动器背景图保存在本地应用数据目录。

## 0.3.6 连接与退出行为

本版本以 0.3.2 为基础，保留原有 ADB 连接流程。连接前读取本机所有 IPv4 网卡的实际子网前缀；电视与所有网卡均不在同一网段时弹窗提醒，可选择继续连接（例如已有跨网段路由或 VPN）。无法获取地址时不阻止连接。

关闭窗口或退出管理器时，先取消可取消任务、等待正在修改的一项完成，再调用当前配置的 `adb kill-server`，随后退出。这也会断开其他程序共用的 ADB 服务；清理失败会记录错误，超时后仍退出。

布局编辑器选中卡片后显示实际打开的应用、包名或内置功能，可从已安装且可启动的用户应用中更换目标。自定义显示名称不会改变真实目标。切换默认启动器通常无需重启电视，按遥控器 Home 键进入即可。

所有页面、列表与布局弹窗关闭滚动回弹，采用统一细圆角滚动条。新版启动器使用 layout.json 版本 5，显示只读 screen 基准和 users/system 组件，系统只读，用户块支持 SVG 与多选排布，电视与管理器共用布局；详见[场景规范](docs/launcher-layout.md)。
