# Used Car direction measurement and complete browser controller acceptance

The original full browser run failed its RIGHT camera-position assertion after LEFT passed. The car center moved left in the frozen before camera (NDC delta -0.01066106), while observed steering and yaw turned right. The car travelled forward 4.263 metres, began with lateral velocity -1.059, and a collision had occurred after the preceding left turn. Requiring the center to reverse screen displacement immediately mixed steering with forward motion, perspective and momentum. The failed report and exact scripts remain unchanged in original-browser-failure.

An independent 3D reviewer projected the recorded headings from one fixed origin through the original before camera, using a 3m forward ray. That calculation gave LEFT -0.04061503 and RIGHT +0.01733626. The source coordinate system is +Z forward at yaw zero, with x=sin(yaw) and z=cos(yaw); the copied source files and independent arithmetic are retained. These are derived diagnostics from real recorded poses, not new rendered screenshots.

Only the Used-specific QA direction assertion changed. It retains ordinary SDK inputs, moving-on-road preconditions, the raw before/after snapshots and center displacement diagnostics. It compares both observed yaw directions at one unchanged origin with the same real before camera. Six offline checks run the exact new assertion fragment against the original snapshots: correct LEFT/RIGHT pass, opposite yaw and unchanged yaw each fail. Cloned negative snapshots never touch a running model.

The complete rerun passed nine groups and all 139 original SDK messages received matching ACKs, including pause freeze, held-input disconnect/reconnect, all nine keys and long hold, separate two-controller seats and held-sync suppression. Actual heading deltas were LEFT -0.01603097 and RIGHT +0.01056790; the latter center displacement remained -0.04019185 and is preserved as a diagnostic. Two-seat input routing does not claim a two-player campaign completion.

All 39 browser assets match the signed Used Car 0.1.4 APK byte-for-byte. Production game files, original SDK and model clocks were unchanged. This desktop JVM/Chromium run uses the actual TCP receiver with a synthetic native bridge; it does not claim Android emulator acceptance or physical TV/phone/ESP32 testing. The independent Android whole-emulator crashes remain separate retained failures. Original process stdout/stderr, executed sources, screenshots and raw reports are preserved and hash-indexed.
