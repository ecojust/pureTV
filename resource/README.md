# 电视 APK 资源目录

启动器位于 `launcher/`，影音和工具应用位于 `apps/`，游戏的源码与签名 APK 位于 [joystick-games/](../joystick-games/)。下表按商城资源分类，点击名称可查看对应软件及其 APK。[浏览首页全部游戏](../README.md#games)

启动器布局自定义使用管理器可识别的 layout.json 接口，当前配套启动器使用 v5 users/system 协议。界面预览与相关许可见各文件夹说明。
