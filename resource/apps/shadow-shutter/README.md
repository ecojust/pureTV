# 影窗快门

移动遮光板的窗口，让三块运动中的纸影完整组成目标照片。纸片必须全部入窗，不能被前层纸片或浅色纸带遮挡；位置、画幅和朝向都要准确。按顺序拍齐三张照片即可完成关卡。

方向键或手机摇杆移动窗口；**A 拍摄**，每次新按下消耗一张胶片；**B 切换横幅／竖幅**。同一次按下 A、B 时先切换画幅再拍摄，长按 A 不会连拍。拍摄保存按键边界的实际画面，随后纸片继续运动，成功换目标也不会重置舞台。

三个关卡依次为「纸鸟回眸」「纸帆远航」「壶影茶灯」，胶片分别为 5、5、6 张，时限为 76、84、90 秒。最后一张胶片完成第三个目标仍算成功；否则胶片耗尽或超时失败。蓝图显示完整目标及各纸片，接触印样保留已完成照片；全舞台导航预览与真正的窗口曝光区分开显示。

使用仓库现有电视游戏壳选择关卡并开始。**P** 暂停或继续，**R** 重试；手机 START 暂停或继续。暂停停止模型推进，重试恢复原关卡的初始运动相位、胶片和目标。版本 0.1.0，包名 `com.ecojust.shadowshuttertv`，作者 ecojust / 桔子桑，MIT。

规则采用固定 60 Hz、整数坐标与精确矩形区域运算，详见[模型合同](docs/model-contract.md)。从仓库根目录可运行定向规则测试：

```sh
node --test resource/apps/shadow-shutter/tests/game-model.test.cjs
```

已完成 22 项规则边界测试、三关各一胜一负的 6 个普通案例，以及对这 6 份既有记录的[独立审计](docs/independent-shadow-review.json)。边界测试中的合成几何与截止时间夹具单独标明，不计作普通通关。独立审计不重新运行游戏或导入生产模型。

源图检查覆盖 4 个已有普通状态及图标；候选浏览器版的 12 幅原图已由 root 和 QA 分别查看。当前结论来自软件模型与浏览器，未进行实体电视、遥控器或手机硬件测试，不代表硬件帧率或输入延迟保证。
