# 环轨炮台 / Orbit Turret

炮台固定在中央，面对来自整圈的目标。用持续旋转和有飞行时间的弹丸提前拦截；需要时启用短时近身护盾。三档警戒分别有 **8、12、16** 个公开目标，分成 **2、3、4** 波，每波四个。

## 操作

- 按住左／右：逆时针／顺时针旋转，不能移动基地。上／下不使用。
- 按住 A：每 0.22 活跃秒自动射击。键盘空格、Z、Enter，遥控器确认或手机右上区域。
- B：开启 1.25 活跃秒护盾，每局两次。键盘 X 或手机右下区域。按住不会重复消耗；护盾尚未结束时不能续期。
- P / Escape / START 暂停；R / SELECT 重试。

旋转、射击和新按下的护盾可以同时操作。暂停冻结整个战场；断开控制或取消按键只停止操作，已发射弹丸和来袭目标仍会运动，重新松开控制后再按才能继续。

## 命中与耐久

金色轨迹目标直冲，粉色轨迹目标沿弧线靠近。身后的短线是已经走过的路径，不是自动瞄准线。弹丸速度有限，需要瞄准目标将要到达的位置。

- 一颗弹丸实际碰到一个目标，会同时移除二者。
- 护盾只拦截接触当前青色圆圈的目标，不会清空远处敌人。
- 一个目标接触基地，扣一点耐久并移除该目标。基地有三点耐久；第三次碰撞立即失败，即使它是最后一个目标。
- 所有目标均已解决且基地仍有耐久，获胜。允许最多两次漏防。

右侧区分枪击、护盾拦截和已解决总数。生命条、护盾剩余次数、当前波次与下一次出现倒计时均来自实际状态，没有隐藏目标或答案角度。

## 几何与验证

每个目标的出现时间、初始角度、径向速度和旋转速度完全公开。目标位置按极坐标公式计算；弹丸沿直线飞行。模型把运动分为不超过 1/240 秒的小段，并做弹丸和目标相对线段的扫掠碰撞，避免只比较两帧端点造成漏击。曲线碰撞采用小段弦线近似，不宣称精确解出连续曲线交点。

物理接触先按时间排序；同刻依次处理枪击、护盾、撞击，再按实体编号排序。基地归零优先判失败，终局只推进到真正的接触时刻，丢弃剩余时间。
