# 环轨炮台美术与信息设计

紫蓝星图与薄青色环轨衬托固定中央炮位。原创八角基地、黄铜炮管、分面陨石均烘焙到单张图集；背景星点与轨道刻度由确定性几何绘制。没有复用自由移动射击游戏的角色或关卡画面。

战场中心 (290,277)，目标初始半径206、实体半径11，完整目标位于画布顶部60至底部494之间。最大活动环轨半径220。顶部标题和底部操作条在特效之后重新覆盖，防止贴边爆炸盖住文字。右侧面板起于x572，保留与战场的间距。

基地的实际碰撞圈为半径24，护盾活动圈为半径64。目标半径11的轮廓与判定一致；弹丸实体为半径4的亮核，外晕仅为装饰。炮口与模型的32单位出生距离对齐。目标只有实际历史短尾，没有预测命中点；金色表示直冲、粉色表示绕行，轨迹形状也能区分。进入94单位范围的目标增加珊瑚色外侧短杠，作为近身警告。

三格编号耐久条与中文 HUD 对应。右栏同时保留波次、已解决数、枪击与护盾拦截数、下一次出现时间、护盾次数／剩余秒数和炮向角度。已解决总数可以包含漏防，结算另列撞击次数，避免把全部目标解决误写成全部击落。

图集 starStation(0,0,640,384)、stationBase(640,0,128,128)、turretGun(768,0,128,128)、orbitalRock(896,0,128,128)，避开共享白块、圆片与 ASCII 字符。画布正文最小24逻辑像素；中文由公共 DOM 绘制。全部动态图形在公共 WebGL 批次内提交。

实际截图和录像须在冻结资产上进行，重点查看真实炮管朝向、弹丸和目标短尾、近身护盾及960×540侧栏。本文不把尚未进行的浏览器预览或实体硬件检查当作完成证据。
