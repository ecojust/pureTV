# 波表与验证范围

三档警戒使用8／12／16个目标，出现间隔1.55／1.30／1.12活跃秒。每四个目标为一波；目标混合零、正、负角速度，基础径向速度20／22／24并作公开的小幅变化。生产资源只保存起始参数和实际物理过程，不保存自动瞄准表或通关操作。

作者测试的普通驾驶器每66／73／80／87／91毫秒观察当前公开状态，选最早可能接近基地的目标，用弹丸速度估算提前角，再发送离散左／右／松开和持续A。其三关全枪击成功约需13.9／17.2／19.8活跃秒。另一个驾驶器在第一次真实护盾拦截之前不射击，随后使用相同普通控制，三关约需14.4／17.9／20.2秒，实际枪击6／11／14、护盾拦截2／1／2，零漏防。驾驶器只在tests中，不进入运行时。

自然失败测试包括完全挂机和固定朝向持续射击：后者确实击落一部分目标，仍因第三次基地接触失败。测试每次普通输入后核对活动数量、已解决数、碰撞收据、耐久和击落分类守恒。

扫掠相交、精确切线、护盾即时范围、到期边界、同刻接触优先级、最终归零优先等极端几何采用明确标注的合成状态夹具；不冒充生产起局路线。独立配对审阅单独实现极坐标及相交公式，另写普通驾驶器，确认时间抖动下的三胜、枪击与护盾消耗。

独立审阅指出小于1e-10的合法正dt曾被完成判断忽略。完成比较已改为不减EPS，并加入step(1e-12)确实推进的回归。接触与事件边界保留契约明确的浮点容差，曲线用短弦扫掠，不声称连续曲线交点的位级精确。
