# 电芯交换

在港口维修台上，为机械泵和信标塔分配六枚电芯。每枚电芯的电量与内阻不同，串联和并联会实际改变供电功率、耗电速度与发热。看清下一段任务的功率范围，在断电窗口安排交换和接线，让两台设备完成各自的工作。

工作台有两行，每行前两个位置连接该行设备，第三个位置是备用槽。方向键或手机摇杆选择位置；**A 换电**先标记来源，再选择另一位置按 A，交换两枚电芯。电芯始终保留自己的电量和温度，不会因交换恢复。再次选择原位置可取消；**B 接线**在未标记来源时切换当前行的串联／并联，有来源标记时只取消标记。

交换和改线只允许在断电窗口进行。供电期间，两台设备分别按实际功率积累工作，完成本段任务后自动停机，等待下一段。注意电芯剩余电量、设备温度和下一段需求；功率持续越界、电芯耗尽、过热或任务超时都会结束本局。

**P** 暂停或继续，**R** 重试。手机右侧上下两个大触控区分别执行 A／B；遥控器方向和确认键也能操作。开始、暂停和结算界面使用毛玻璃背景。

画面采用原创维修台、电芯插槽、实体负载和串并联线路，用烘焙图集合并 WebGL 绘制。电视说明使用中文，手机控制器支持中文和英文。电路采用固定名义电压与电阻负载的游戏模型；电量用库仑、功率用瓦、工作与热量用焦耳分别记录。

三关为「港口试供」「轮值负载」「夜间双机」，使用相同规则与不同的初始电量和任务需求。详细边界、公式与公开状态见[模型合同](docs/model-contract.md)。设计可行性、模型边界测试、正常操作回合和浏览器验证分别记录；软件浏览器验证不代表实体电视或手机测试。
