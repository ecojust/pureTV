# 量杯转运：独立规则复核

规则复核以公开的 [模型契约](model-contract.md) 为依据，测试另写最大量倾倒公式和宽度优先搜索，通过 `create` / `step` 的普通输入执行，不写入模型状态。求解器仅在 tests 下，不进入 APK 资产。

```bash
node resource/apps/measure-pour/tests/independent-check.mjs /absolute/scratch/measure-pour/independent
```

本次 15 组检查通过，共核对 2,616 次普通模型输入产生的成功倾倒。完整模型哈希、结果、路线和末态见 [independent-report.json](independent-report.json)。

| 关卡 | 独立最少倾倒数 | 额度 | 搜索状态数 | 从可继续状态核对的来源／目标组合 |
| --- | ---: | ---: | ---: | ---: |
| 对半分装 | 7 | 9 | 16 | 135 |
| 长程倒量 | 9 | 11 | 20 | 171 |
| 三杯配额 | 11 | 13 | 24 | 207 |

逐次独立计算转移量 `min(来源水量, 接收杯剩余容量)`，核对整数水量、容量界限、守恒、选择位置、来源清除、一次计费、回执前后值与胜负。每关分别完成最短路线、先往返两次后恰好用完额度的胜利，以及来回倒水耗尽额度的自然失败；终局继续输入完全不改变状态。空杯、同杯、满杯阻止操作不消耗额度。另验证持续按 A 不重复、B 免费取消，以及取消 epoch 后必须中立再产生新按键边沿。

该报告是模型层执行证据，不代表浏览器实际输入、视觉审查、正式签名或实体电视／手机测试。浏览器专项使用 `tests/browser-checks.mjs`；录像与公共 QA 使用 `tests/automation.mjs`，仅从只读快照规划、通过真实键盘事件操作。最终浏览器和签名结果另行归档，不能由本报告推断。
