# Measure Pour art direction

The original navy laboratory uses copper bench fittings and cyan water. Three straight-sided jugs have independent capacity scales; the README explicitly explains that equal rendered liquid heights across different capacities are not equal volumes. Actual volumes/capacities, per-jug targets and tick marks accompany the liquids. All gameplay labels are at least24 logical pixels.

The top operation banner identifies source selection versus destination selection and shows the last actual transfer. A copper border marks the current jug; a separate S and top rule mark the chosen source. Dashed copper lines locate exact target levels, including zero/full targets. The footer exposes the current A action, cancellation and remaining pour allowance. Chinese instructions and resource meters use the common DOM interface.

Warehouse artwork is not reused. Four custom atlas sprites paint the laboratory, clear measuring glass and copper handle, water gradient and elliptical surface once during initialization. Live liquid heights and target lines derive directly from current state and immutable layout values. The matching64px SVG and Android vector are original measuring-jug emblems. No external imagery or third-party artwork is used.

This design record does not itself claim completed visual, browser or physical-device verification.
