# 量杯转运 / Measure Pour

三只不同容量的量杯，只有一份固定总量的水。通过在量杯之间倒水，使三杯水量同时符合公开目标。每次必须倒到来源杯空或接收杯满，不能中途停止，也没有外部加水或排水。

## 操作

| 输入 | 动作 |
| --- | --- |
| 左 / 右 | 循环选择三只量杯 |
| A | 没有来源时标记当前非空杯；有来源时向当前杯执行一次最大倒水 |
| B | 取消已选来源，不改变水量 |

键盘方向键 / A、D 选择；空格、Z、Enter 为 A，X、B 为 B。手机右侧上半区为 A，下半区为 B。P / Escape / START 暂停，R / SELECT 重新开始。长按不重复，每次操作后松开再按；同时触发时 B 优先于 A，A 优先于方向。取消输入、后台或断线后须松开控制再继续。

亮框是当前选择，S 是已标记的来源。当前量 / 容量显示在杯子上方，虚线标出目标水位。三只杯分别采用自身容量刻度，数字与标记共同说明目标，不能通过比较杯子的绝对高度推断相同水量。

| 配额 | 容量（1 / 2 / 3 号） | 初始水量 | 目标水量 | 最多倒水 |
| --- | --- | --- | --- | --- |
| 对半分装 | 8 / 5 / 3 | 8 / 0 / 0 | 4 / 4 / 0 | 9 次 |
| 长程倒量 | 10 / 7 / 3 | 10 / 0 / 0 | 5 / 5 / 0 | 11 次 |
| 三杯配额 | 12 / 7 / 5 | 12 / 0 / 0 | 6 / 1 / 5 | 13 次 |

只有实际转移了水才花一次额度。选择、取消、空杯作为来源、倒向满杯或同一只杯都不扣次数。用完额度时，若三杯均符合目标则获胜，否则立即失败；最后一次倒对仍然获胜。没有倒计时，总水量始终守恒。
