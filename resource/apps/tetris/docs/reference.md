# Tetris TV：玩法依据与实现范围

这是一款独立编写的下落方块游戏，以 Nintendo NES 版本的 A-TYPE 马拉松与 B-TYPE 25 行挑战为规则参考。没有加载 ROM，也没有复制游戏程序或提取商业游戏图像、字体、音乐。

## 经典规则

| 项目 | 本应用行为 |
| --- | --- |
| 棋盘 | 10 列 × 20 可见行；活动块允许暂时伸入上方两行 |
| 方块 | T、J、Z、O、S、L、I 七种，每块四格，显示下一块与各形状出场计数 |
| 生成与旋转 | 使用右手 Nintendo Rotation System 的明确朝向表；生成枢轴对应 `(5,0)`，新块全部可见。S/Z/I 各两种朝向、O 不旋转；没有 SRS 踢墙、踢地、Hold 或幽灵块 |
| 手机操作 | 浮动摇杆左右移动、下拉软降；A 顺时针，B 逆时针；不提供硬降 |
| 同帧输入顺序 | 先横移、再旋转、最后下落；从墙边横移腾出位置后，同帧旋转可以成功，仍不提供踢墙 |
| 横移 | 新按一次移动一格；持续按住等待 16 帧后，每 6 帧一格。撞墙时保存满蓄力；入场和消行动画期间不蓄力 |
| 自动下落 | 固定 NTSC 60.0988 次逻辑更新/秒。0–9 级每格分别为 48/43/38/33/28/23/18/13/8/6 帧；10–12 级 5 帧，13–15 级 4 帧，16–18 级 3 帧，19–28 级 2 帧，29 级及以后 1 帧 |
| 软降 | 只在新按下方向且没有左右输入时启动：首次第 3 帧下降，此后每 2 帧一格；新块出现后须松开下方向再按下。左右输入会取消软降；更快的自动重力继续生效，同帧最多下降一格。锁定时给最后一段实际软降经过的格数计分 |
| 锁定 | 一次下落尝试受阻即锁定；没有可无限移动的现代锁定延迟。锁定后入场等待 10–18 帧，按块落点高度变化 |
| 消行 | 满行同时消除；从中间向两边呈现五步动画，耗时随全局帧相位为 17–20 帧。首次全局四帧边界之前保留完整行，随后从中心成对擦除；完成后整体压下上方行 |
| 计分 | 单/双/三/四行分别为 40/100/300/1200 × `(消行后的等级 + 1)`，无现代 T-spin、连击或完美清场加分 |
| 升级 | 起始等级 `s` 的第一次升级在 `min((s+1)×10,max(100,s×10−50))` 行；此后每 10 行升一级 |
| 结束 | 下一块生成位置被占据时结束。锁定在可见区上方的格子不写入棋盘，与 NES 的抽象隐藏行处理一致 |

标题画面用左右选择起始等级 **0–19**，上下可跳 10 级；SELECT 切换单人/双人；START 开始。标题 A/B 切换 A-TYPE 与 B-TYPE。B-TYPE 左右选固定等级 0–9，上下选初始障碍高度 0–5；每档预填 3 行独立生成的障碍，各行至少一格为空，消满 25 行后停止落块并显示通关。双人初始障碍和出块序列一致，已通关者断线不影响另一人继续。

游戏中 START 暂停/继续，SELECT 开关原创音乐。最高分仅保存在电视本机。控制器断线时冻结游戏，重新连接后恢复；不会补算断线期间的时间。

## 局域网双人模式

双人并排棋盘是本应用提供的扩展，并非声称 Nintendo NES 原版存在此模式。两名玩家在同一局中获得相同的随机序列，但按各自进度取块；不互发垃圾行，分别累积分数。一人结束后，另一人可以继续；仍在游玩的控制器断线时暂停整局，避免连接问题造成劣势。

## 本轮规则校正

- **下拉手感**：对照 [MeatFighter 的 Dropping Tetriminos](https://meatfighter.com/nintendotetrisai/#Dropping_Tetriminos) 对 `autorepeatY` 的行为说明：计数从一次新 Down 按下开始，首次到 3 才落一格，之后重置为 1；生成新块清零。当前实现按这些行为独立建立软降状态，不会因一直下拉而把下一块也送到底。左右输入会取消此状态，松开左右而仍按下不能重新启动软降。
- **组合操作**：同一资料的输入总结明确为 shift → rotate → drop；本轮纠正先旋转再横移的旧顺序，墙边“先横移一格并同时旋转”的操作现在按新位置判定。
- **消行画面**：按 [TetrisWiki 的全局四帧动画说明](https://tetris.wiki/Tetris_(NES)#Details)，修正了在首个四帧边界之前提前擦除中间两格的问题。动画与模型使用同一消行计时。

以上依据是公开的行为与时序描述；没有复制资料中的汇编、Java AI 或 Lua 控制代码。测试覆盖首降/重复、持续下拉跨入场、左右与下方向组合、29 级高速重力、双人独立软降、墙边组合旋转及动画首步时机。

## 独立重写的边界

- 随机选块保留“0–7 第一次抽取，遇上次同块或虚值再从 0–6 抽一次”的机制，允许重复、长 I 块空窗；不是现代七袋随机。底层采用可复现的本地随机数生成器，而不是按原机每帧执行的 16 位 LFSR，因此不声称能重放同一 ROM 的完整序列。
- B-TYPE 复现固定等级与 25 行目标；初始障碍使用独立种子生成和每档 3 行的高度映射，不声称复刻原机随机布局、结算奖励或通关演出。
- 不复刻原作 BCD 软降计分 bug、整数溢出、乱码等级配色、原机演出。分数与等级使用正常整数，后续高等级仍可运行。
- 开局第一块目前直接进入正常重力，没有复刻原版约 1.6 秒的首块悬停；锁定后的常规入场延迟保持上述规则。
- 使用上述游戏帧规则，但不是逐 CPU 周期模拟。输入读取与浏览器绘制会受到真实电视和局域网延迟影响。
- 图形、像素字体、旋律和音效为本应用绘制/编写；保留经典信息布局，不把它们称为原作素材。见 [素材与声音](artwork-audio.md)。
