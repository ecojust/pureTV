## Exact public rendering API

`transmission(cycles)` is the scalar periodic mask law; `sampleAt(state,x,y)` returns both masks' cycles/phases/transmissions and their product at an actual world point. The model contract defines finite input bounds and null results. Helpers work read-only on actual current or terminal state; no API accepts a hypothetical alternate layer placement. `state.optics.layers` provides the exact normal, tangent, angle, phase and frequency used to render each mask, plus fixed guide geometry and current signed guide errors. `state.optics.probes` contains complete target and current sample data; optics.matched means all five **now**, not any past success.

Render one isotropic world square and two fine sinusoidal masks using the public normal/phase equation. A baked sine-opacity tile can call transmission for every texel, with black alpha=1−T; endpoint texels duplicate the periodic seam. Repeat it at world pitch1/f, shift by the actual wrapped phase and rotate around the world origin. Drawing both black-opacity layers over white yields brightnessT0*T1 through ordinary alpha-over. Smooth bilinear raster interpolation is allowed; adding a different beat-only display formula is not. Clip both layers to the same board. If using discrete sampled strips, their alphas must likewise come from the exact transmission/sample API at documented world coordinates. Preserve phase wrap across tile boundaries without a seam or jump.

Fine mask strokes, large overlap bands and individual layer plates must all use the same orientation sign and x-right/y-down coordinates. Do not separately rotate a texture in screen coordinates and then evaluate probes in another origin. Show exact probe live swatches/readings from sampleAt; target swatches use immutable targetBrightness. Five tolerance bars compare current to target with full-precision matched flags, although displayed percentages may round. A marker can cover its point visually, but its readout still corresponds to that exact underlying world coordinate. Do not color the light table in a way that claims a tinted decorative pixel is the judged brightness.

The fixed reference tangent and crest pin are public bench geometry. Show selected-layer TURN and SLIDE error, actual angle and phase detent, both layer identities and current five-pass count. Explain “rotate to reference, then slide crest onto pin”; guides are aids only. A passing optical arrangement may be accepted before both guides look exact. The player must see all five probes at once, remaining seconds and remaining permitted errors. No persistent check mark can imply a prior probe success was banked.

Art should be smooth optical instrumentation rather than pixel art: etched glass, pale transmitted light, ink-blue bench, cyan/amber physical rims, small shaded knobs and clean instrument cards. Essential ASCII text≥24 logical pixels, Chinese instructions/results in DOM. Preserve shared actual blurred modal backdrop. Use one local atlas and existing batched sprites/lines; keep the intended quads below8192 then measure actual draw calls. Capture original960×540 and1280×720 images for layout/legibility; do not substitute enlarged crops or image-generated acceptance artifacts.

## Ordinary public-feedback pilot

Use only each actual observation's visible guides, selected layer, phase and five current check flags. If all probes match, release then press A and inspect the result. Otherwise, find the first layer with a nonaligned turn guide; use B if needed, release, then make one Up/Down edge opposite the signed turn error. If no turn error remains, find the first nonaligned crest guide: a positive phase error asks for one Right edge, a negative error for one Left edge. Left increases phaseTick, moving the visible stripe left; Right decreases it, moving the stripe right. Inspect fresh feedback after each command. Do not repeat a held direction or replay a prepared action list. If all guides are aligned but probes do not match, preserve that failure/uncertainty; do not force success or add a privileged fallback.

This is an ordinary current-feedback policy, not a future search. It does not enumerate controls, evaluate proposed sample arrangements, import model helpers in a pilot, read reference target controls or use stored answer routes. The public pin/line cues are physically shown to the user; the pilot may consume their published signed current errors. Read-only production helpers remain renderer/model APIs, not a license for a pilot to simulate futures. Stop on actual terminal outcome and preserve errors, retries and unsuccessful first attempts.

Natural rejection loss: leave the fresh initial controls unchanged, release and press A four separate times; public center measurements prove all starts fail. Natural timeout loss: allow a fresh unchanged round to run until90 admitted active seconds; preserve actual full calls in model evidence or actual browser observations without inventing the hidden steps. A normal success recording should show the initial task, understandable adjustments to both masks, the visible change in overlap/probe readings, accepted A and true result in30–90seconds. Do not pad it with title cards or idle slides, and do not inject a solution.

## Evidence boundaries and public corpus

A complete ordinary model run records creation and every actual call through terminal, including invalid/no-op calls. Preserve the complete origin state/config, exact dt/input, actual before/after snapshots, original source hashes, UTC observation times and a declared monotonic clock. Invocation seq starts at1 and includes no-ops; it is distinct from saturating admitted calls. Adjacent actual snapshots must agree. An independent auditor can recompute current fields and each admitted transition from public equations without importing Model/pilot/solver code. Reconstructed continuation is not an observation.

Final recording retains setup and capture observations as distinct source streams with their original clocks/read windows/frame manifest. Converting milliseconds to seconds or adding source-index aliases must be labeled, without claiming exact frame/state pairing or an inferred shared origin. Actual recorded input, retry, unsuccessful attempts and startup/helper failures remain intact. Provenance links and sparse endpoint arithmetic do not prove all-call input lifecycle.
