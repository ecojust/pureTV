# 纹幕校准 / Moiré Atelier

在发光台上滑动、旋转两层细密条纹膜，观察它们叠加后的明暗变化。五个测点要求不同的亮度；只有同一次验收时全部合格，才能完成校准。

这是 pureTV 百款游戏计划的第44款，包名 `com.ecojust.moireateliertv`，版本 `0.1.0`。支持电视遥控器、键盘和局域网手机手柄。本页介绍游戏规则，实际验证与发布结果由随包报告记录；完成验证并逐款推送后才计入完成数量。

## 操作与目标

- 左右：滑动当前膜的条纹，每次移动一个相位刻度，共24格并循环。
- 上下：旋转当前膜，每次3°，范围−12°至+12°。
- A / Space / Z / Enter：同时验收五个测点。
- B / X：切换两层膜。手机右侧整个三分之一区域分成上半A、下半B。
- P / Escape / START 或独立暂停按钮：暂停、继续。R / SELECT：重新开始当前任务。

方向和A/B都按新按下的边沿生效，长按不连续操作。松开再按，或明确改变方向，才进行下一次调整。同时按下时优先B，其次A，最后方向；其余动作不会排队。暂停、输入取消或手柄重连之后，先真实松开仍按住的键，再开始新操作。

先让所选膜的条纹方向平行于固定参考线，再把亮纹移到标针。`TURN` 显示当前方向偏差，`SLIDE` 显示亮纹偏移：正数分别向上、向右调整，负数向下、向左调整。左键增加相位刻度，让可见条纹向左移动；右键减少相位刻度，让条纹向右移动。旋转会改变标针读数，所以先调方向、后调滑动。B切换另一层继续检查。

参考标记帮助定位，但最终只检查五个实际亮度。每点的允许误差为完整亮度范围的±3.5%；画面百分比会四舍五入，判定使用完整精度。某点此前合格不会保存进度，必须让五点在同一组合下同时合格，再按A验收。两层膜以真实透射率相乘产生光纹，画面与测点采用同一公开公式。

每局有90秒有效时间，并允许四次错误验收。正确验收不扣错误额度；第四次错误或时间耗尽即失败。同一模型步内恰好到时，超时优先于按键。暂停冻结计时，重试恢复两层初始相位、方向、剩余时间和全部记录。

| 任务 | 校准主题 |
| --- | --- |
| 平行光纹 | 两层平行细纹，认识多种目标亮度 |
| 交织细幕 | 两个相反的小角度与不同标针位置 |
| 斜光习作 | 更大的相对角度，检查空间分离的测点 |
