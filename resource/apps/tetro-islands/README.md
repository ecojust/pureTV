# 四格岛群 / Tetro Islands

LITS 区域逻辑谜题。每个公开编号区域恰选四个黑格，须构成 I、L、T、S 四连块之一，旋转与镜像同型（L/J 同类、S/Z 同类），O 方块禁止。全部黑格正交相连，不得出现 2×2 全黑；不同区域的黑块若正交接触，其类型必须不同。斜角接触不连接，也不触发异型限制。

方向键移动光标。A 在未知、黑、白三态之间循环。B 手动检查：有未知格时只给免费提示；全部标明黑白后消耗一次机会。共三次完整检查，第三次正确仍获胜。不会自动完成，没有时间限制和撤销操作。检查之后编辑会保留旧报告并标为过期。

三张原创公开区域图为 5×5/3 区、6×6/4 区、7×7/6 区。每区相连且大于四格，均有至少两个合法候选四连块。测试专用完整枚举分别证明唯一黑白解；候选数量分别为 `8/5/10`、`3/64/5/21`、`5/31/7/12/6/3`。这些统计不代替浏览器验收。生产资产只有区域图与通用规则验证，不含解答、候选枚举或求解器。最大全局黑格数为 24。

画面用粗边界和重复编号区分区域；深色加号格、空心圆、问号分别表示黑、白、未知。右侧显示 I/L/T/S 图示、当前区域四格计数和类型、完整检查次数。所有黑格必须连通，白格没有连通要求。

自有测试包括三局普通输入求解、完整唯一性枚举、八种对称变换、O 与断开四格、逐项孤立的全局约束反例、免费未完成提示、三次完整错误失败、正确第三次检查、取消输入和终局冻结。单一区域几何夹具明确属于合成模型测试；正常胜负与反例均通过公开棋盘和普通输入。

独立浏览器验收、实际录像、双尺寸目视检查及发布签名由集成流程补齐。未进行实体电视或手机测试。本目录是源码候选，不据此增加完成计数。
