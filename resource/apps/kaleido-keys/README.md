# 万花钥匙 / Kaleido Keys

在一个源扇区的六个插槽中摆放有限的珐琅图符，让镜面复制出完整花钥。阶数可选 3、4、5，分别产生 6、8、10 个交替镜像扇区。只有源扇区可编辑；复制图符不消耗库存。

对照完整目标图与放大的检查窗口，调整阶数、空位、图符和四分之一圈朝向。普通窗口保留左右与朝向；镜像窗口左右交换、旋转方向相反，图符本身也会反射。朝向数字 0–3 以源扇区朝上的坐标框为准，每次顺时针转 90°。

在 CHECK 格按 A 验收。整幅钥匙的阶数、全部插槽的占用、图符、朝向和镜像状态必须精确一致。窗口相似或局部匹配不会累计进度。每个任务第四次错误提交即失败；前三次错误后仍可正确提交获胜。没有时限，计时仅供参考。

## 操作

方向键在下列 3×3 焦点板中移动，每次一格，边缘不循环。标为 SOURCE GRID / 源扇区展开的编辑区是逻辑展开图：左两列对应两条角向通道，行由内向外自上而下排列。完整实时圆盘另行高亮真正朝上的源扇区，展示实际插槽位置和镜面副本。

| 行 | 左通道 | 右通道 | 工具 |
| --- | --- | --- | --- |
| 内圈 | 插槽 0 | 插槽 1 | ORDER 阶数 |
| 中圈 | 插槽 2 | 插槽 3 | GLYPH 图符 |
| 外圈 | 插槽 4 | 插槽 5 | CHECK 验收 |

| 焦点 | A | B |
| --- | --- | --- |
| 空插槽 | 有库存时放入所选图符，朝向为 0 | 无编辑 |
| 已占插槽 | 将原图符顺时针转 90° | 取回图符并返还库存 |
| ORDER | 3→4→5→3 | 反向切换 |
| GLYPH | 钩 HOOK→旗 FLAG→芽 SPROUT→钩 | 反向选择 |
| CHECK | 提交整幅钥匙 | 清空六格并返还全部图符 |

替换图符需先 B 取回，再 A 放置。库存耗尽时不能放置，不扣错误次数。改变阶数保留源图符和朝向；清空保留当前阶数、所选图符、焦点、用时和错误记录。重新开始才会恢复该任务的空棋盘、初始阶数、全部库存和提交额度。

所有方向与 A/B 均只响应新的按下，长按不连续触发；换到另一非零方向可移动一次。同时按下时优先级为 B、A、方向，其余输入不排队。开始、恢复或输入取消后，先松开所有控制再按。

- 键盘：方向键 / WASD 移动；空格 / Z / Enter 为 A；X / B 为 B。
- 暂停：P / Escape / START；重新开始：R / SELECT，均由共享宿主独立提供。
- 手机：右侧整整三分之一区域分为上方 A、下方 B。

## 三个固定任务

每次从六个空插槽开始。库存按实际源图符计数；镜像副本无需额外图符。三个任务各自使用四次错误提交额度，种子仅记录，不随机生成目标。

| 任务 | 初始→目标阶数 | 目标检查扇区 | 库存：钩 / 旗 / 芽 |
| --- | --- | --- | --- |
| 初见花钥 / FIRST ROSETTE | 4→3 | 0，普通 NORMAL | 1 / 1 / 1 |
| 镜中花钥 / MIRROR BLOOM | 3→4 | 1，镜像 MIRROR | 2 / 1 / 1 |
| 五重冠钥 / FIVEFOLD CROWN | 4→5 | 3，镜像 MIRROR | 1 / 1 / 2 |

目标阶数与六格目标检查窗口在游玩中持续公开。完整目标表、图符轮廓与镜像公式见 [公开设计](docs/public-design.md)，状态和精确判定规则见 [模型契约](docs/model-contract.md)，宿主约定见 [公共接口](docs/public-interface.md)。
