# Kaleido Keys — public model contract

Public specification; implementation and execution evidence are recorded separately. The [public design](public-design.md) defines every task, polygon and transformation; [public interface](public-interface.md) defines host and evidence scope. Implementation, tests, browser work and builds follow the applicable source/specification acceptance.

## Pure API and immutable configuration

Expose exactly `create(seed,level)`, `step(state,dt,input)` and deeply immutable `config` through CommonJS and `window.PureModel`. Create allocates fresh state; step mutates and returns the same state. No randomness, clock, I/O, alternate constructor, fixture setter, hidden desired source, replay route or solver is part of this API. External malformed/mutated states are unsupported. Tests may label deliberately corrupted states as synthetic boundary fixtures, never ordinary play.

Config is `{defaultSeed:745,orders:[3,4,5],radii:[0.42,0.66,0.90],glyphScale:0.007,glyphs,attemptLimit:4,maxElapsed:86400,maxCounter:2147483647,tasks}`. Glyph descriptors in hook/flag/sprout order are `{id,name,nameZh,polygons}` with the exact public labels/vertices. Task descriptors in public order are `{id,name,nameZh,initialOrder,inventory,target}`. Inventory is `{hook,flag,sprout}`. Target is `{order,sector,window,cells,instances}`: window is the six explicitly published visible cells; each is null or `{glyph,turn,mirrored}`. Cells and instances are the entire target plate generated by the public inverse-window and forward-mirror rules below. No extra desired-source array is stored in config or state.

Seed accepts only a JavaScript integer0..4294967295, otherwise745. Level accepts only integer0..2, otherwise0. Seed is recorded only. Fresh state, immutable config, caches, input records and all receipts share no mutable references.

Canonical editable data is only order/source/focus/selectedGlyph. Stock and pattern are derived, not alternate authority. Source turns are integers0..3; a glyph consumes exactly one corresponding source piece. `stock[g]+count(source,g)=task.inventory[g]` at all times, and stock never negative. A reflected copy consumes nothing. All task inventories total at most4; state source length6; source placement count≤4; each full cell array length12n≤60; each instance array≤40; inspection arrays length6; events≤1; receipts≤4. No undo stack, accrued per-cell progress, growing event history, held-repeat timer or internal fixed-step accumulator exists.

Counter increment is min(maxCounter,old+1); `counterSaturated` becomes true only if old+1 exceeds maxCounter. On an admitted call `nextElapsed=oldElapsed+dt`, elapsed=min(maxElapsed,nextElapsed); elapsedCapped becomes true if nextElapsed>maxElapsed and remains true. Reaching or exceeding this informational cap never settles play or changes input behavior. All numeric state remains finite. One action counter increments for each successful corresponding command; blockedActions increments only for blocked navigation, empty removal or depleted placement. Clear counts as a command even when already empty.

## Exact full-plate derivation

For each sector j=0..2n−1 and local socket k=0..5, `cells[j*6+k]` is null or `{glyph,turn,mirrored}` in that sector's upright inspection frame. For a canonical source at row r/lane c with glyph g and turn q, its generated sector cell has row r, lane c for even j or1−c for odd j; glyph g; turn q for even j or(4−q)%4 for odd j; mirrored=(j%2===1). These are exact integer/boolean semantics; floats do not judge acceptance.

Instances contain only occupied cells, ordered by ascending sector then local slot, each `{sector,slot,row,col,glyph,turn,mirrored,x,y,angle}`. Row=floor(slot/2), col=slot%2. Given the actual source q,c and public radius, compute α=π/n, t=(2c−1)*α/4, p=(radius*sin(t),−radius*cos(t)); transform center by `R(jα)*F^parity`. Angle=`j*α+(mirrored?-1:1)*q*π/2`. Render the ordinary or left/right-reflected glyph polygon at this angle and scale0.007. `turn` is the normalized local semantic turn even when angle has a negative component. Config target instances use the identical geometric law after the public inverse of target.window, without retaining an implied source answer as another field. Cells/instances are detached, including target window versus target cells.

For every emitted instance x/y/angle, apply `Math.round(value*1e12)/1e12` only after the complete expression, then normalize negative zero to zero. Intermediate angles, sine/cosine and coordinates are unrounded. This12-decimal display representation is public and applies identically to target/current instances; exact semantic matching never reads these floats. The formula specifies JavaScript Math.round behavior, including negative values. State.target is copied visible context only; submission authority is the immutable configured target, never a potentially stale display copy.

`pattern={order,sectorCount,cells,instances,inspection,windowMatches,windowMatchedCount,orderMatched,matched}`. Order is current order; sectorCount=2*order. Inspection is a detached copy of six current cells at the fixed target.sector, valid for all three orders. WindowMatches contains six booleans comparing current inspection to the public target.window, including both-null equality; windowMatchedCount is their count. OrderMatched is strict order equality. Matched is orderMatched AND equality of every current full cell against target.cells in the same sector/local-slot indexing, including occupancy, glyph, turn and mirrored. A whole-cell length difference fails. Window feedback alone never decides matched. It is possible for windowMatchedCount=6 while orderMatched=false; that must not pass.

Recompute stock and pattern at create, after each source/order edit, and on every submission. Focus/palette moves need no geometric recomputation. Never trust cached stock/pattern as judging authority: a submission regenerates from canonical source/order and the fixed public target. Decorative coordinates, rounded text, glyph color or historical matches cannot decide a result.

## Admitted time and input normalization

1. Terminal state returns exact no-op before reading dt/input. All fields, events and receipts stay byte-for-byte unchanged.
2. Admit only a finite JavaScript-number dt with0<dt<=0.25. All other durations are exact no-ops without coercion. There is no clock-based victory or loss.
3. Within one try/catch, classify input and atomically collect own descriptors for `x,y,a,b,cancelEpoch,cancelled,paused` before mutation or paused handling. A non-null non-array object may supply own data values only. Never invoke accessors, inherit input properties or write input. Classification/descriptor exceptions discard all partial reads and yield wholly empty neutral. Use a null-prototype temporary. A nonthrowing Proxy descriptor trap may execute; there is no side-effect-free Proxy claim.
4. Only literaltrue enables a/b/cancelled/paused. A normalized pausedtrue makes the entire call exact no-op. Finite numeric axes clamp to[-1,1]; everything else becomes0. A valid epoch is a nonnegative safe integer; otherwise ignore it. Ignore aPressed/bPressed, raw direction names, start/select and all other fields.
5. Direction is none when both axis magnitudes<=0.5; otherwise choose the greater magnitude, vertical winning exact ties. Positive x/y is right/down. An unchanged held direction never repeats; a changed nonneutral token is a new edge.
6. Clear events; set lastCommandnone; increment calls; advance/saturate elapsed as above. Cancelled/unarmed calls still consume admitted active time. Host pause normally makes no calls; cancellation itself does not pause the model.
7. Apply the release gate, choose at most one command and store held input as below. Invalid/paused/terminal calls never arm, disarm, normalize into state or consume input.

Ordinary IEEE-754 addition applies, without timing epsilon; a tiny dt can increment calls while leaving the same rounded elapsed value. Input is sampled only once per actual call.

## Release gate and simultaneous priority

The first valid cancelEpoch establishes a baseline without independently cancelling. A later different valid epoch, or false-to-true cancelled edge, disarms input. Every cancelled sample suppresses commands. Store valid epoch and current cancelled flag. If still armed and not cancelled, derive A/B rises and changed nonneutral direction against previous lastHeld. Choose B rise>A rise>direction edge. Other fresh edges are consumed, not queued. Set lastCommand to the chosen a/b/up/down/left/right even if the corresponding action is blocked.

Store all normalized raw held fields in a fresh lastHeld after selection, including suppressed samples. Only a noncancelled neutral sample with Afalse/Bfalse/directionnone arms future calls. Newly arming neutral issues no command. Empty/malformed nonobject input normalizes neutral and can arm; the model cannot infer phone absence. The host must represent missing/cancelled sources appropriately. Synthetic cancelled neutral never acknowledges a physical release. The shared host also quarantines held local/remote A/B/confirm until actual keyup or raw remote false. Create/retry begins unarmed.

Examples: fresh A+B performs B only, so CHECK clears without submitting. Keeping A held after releasing B cannot submit. B with a new direction removes/cycles/clears at the old focus only; that held direction cannot move focus next call. Holding A while changing direction may navigate, but cannot place/rotate/submit again. Enter and the phone follow the same held-state rule.

## Commands and bounded receipts

Directions request focus.row/col±1. If beyond0..2, preserve focus and increment blockedActions, event `{type:'blocked',reason:'boundary',call}`. Otherwise update focus, increment moves, event `{type:'move',focus,call}` with detached focus.

At a source focus, slot=2*row+col. A on null checks freshly derived stock for selectedGlyph. If zero: no source/stock/failure change; increment blockedActions; event `{type:'blocked',reason:'stock',slot,glyph,call}`. Otherwise place `{glyph:selectedGlyph,turn:0}`, increment placements, recompute stock/pattern; event `{type:'place',slot,glyph,turn:0,call}`. A on occupied increments its turn modulo4, rotations and recomputes; event `{type:'rotate',slot,glyph,from,to,call}`. B on occupied removes it, increments removals and recomputes; event `{type:'remove',slot,glyph,turn,call}` describing the removed piece. B on null increments blockedActions, event `{type:'blocked',reason:'empty',slot,call}`. These never submit.

At ORDER, A/B cycle forward/backward through config.orders; increment orderChanges; recompute pattern/stock; event `{type:'order',from,to,call}`. At GLYPH, A/B cycle forward/backward through config.glyphs; increment paletteChanges; event `{type:'palette',from,to,call}`. At CHECK, B sets every source entry null, increments clears and recomputes stock/pattern; event `{type:'clear',removed,call}` with removed=old occupied count. None refunds failures or changes prior receipts.

At CHECK, A recomputes full stock/pattern. If matched: phasewon/reasonempty/score100; failures unchanged; event `{type:'win',call}`. If not: increment failures once; failures<4 stays playing/reasonempty/score0, event `{type:'reject',windowMatchedCount,orderMatched,call}`. At failures4: phaselost/reasonattempts/score0, event `{type:'collision',reason:'attempts',call}`. Exact full match may exist during play until explicit CHECK/A. No edit automatically settles victory.

Append one detached submission per actual CHECK/A: `{index,call,elapsed,order,source,stock,inspection,orderMatched,windowMatchedCount,cells,matched,failuresBefore,failuresAfter,remaining,phase,reason}`. Index is prior length; cells are the complete freshly judged semantic plate; remaining=4−failuresAfter. Maximum length4: the fourth submission either wins after three failures or is the fourth failure. No other command appends a receipt.

On a terminal transition preserve `{cause,call,elapsed,order,source,stock,cells,matched,failures,remaining,score,phase,reason}` as terminalReceipt, cause success/attempts. It is independently detached from caches and all submission objects. Every later call is exact no-op. Required identities: failures equals unmatched receipt count; a matching receipt exists only as the final won receipt; attempts loss has failures4 and final unmatched receipt; score100 iff won; terminal receipt agrees with the transition; clear/order/palette/navigation cannot erase receipts. Retry is a new create, restoring every field including empty source, original order/stock/focus, elapsed, gates and counters.

## Deterministic visible messages

An admitted call without an event preserves the previous message, including neutral/cancelled calls. Each event replaces message with the exact template below. Braced values interpolate ordinary base10 integers or fixed public glyph Chinese names 钩/旗/芽; braces are not displayed. FocusLabel is 内圈左槽/内圈右槽/中圈左槽/中圈右槽/外圈左槽/外圈右槽 at the six source foci, and 阶数/图符/验收 at tool rows0/1/2. Messages are display feedback and never judging input.

| Event | Exact message |
| --- | --- |
| move | `已选择{focusLabel}。` |
| blocked / boundary | `已到选择边界。` |
| blocked / empty | `此源插槽为空。` |
| blocked / stock | `所选{nameZh}图符库存已用完，先取回再放置。` |
| place | `已放置{nameZh}图符，朝向 0。` |
| rotate | `已将{nameZh}图符旋转到朝向 {to}。` |
| remove | `已取回{nameZh}图符，返还 1 枚。` |
| order | `镜面对称阶数改为 {to}；源图符与库存不变。` |
| palette | `已选择{nameZh}图符。` |
| clear | `已清空源扇区，返还 {removed} 枚图符；错误记录保留。` |
| reject | `整幅钥匙尚未匹配，剩余 {4−failures} 次错误额度。` |
| win | `完整钥匙匹配，验收成功。` |
| collision / attempts | `四次错误提交，花钥未能开启。` |

For palette, nameZh is the newly selected glyph; for other glyph events it is the event's glyph. On create/retry use the initial message in the state table. Invalid/paused/terminal calls preserve message with every other field. The host DOM uses state.message; the renderer separately derives contextual A/B labels from current focus and source occupancy.
