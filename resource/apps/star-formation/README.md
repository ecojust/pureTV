# 星阵防线 / Star Formation

原创编队入侵射击。战机只能横向移动；敌阵按节拍整体左右步进，触边转向并下降，敌人减少后步进加快。公开规则从仍存活列的最底部敌人轮流发射敌弹。三档为6/9/12架敌人，每架一击清除。

左右持续移动，A 按住连射（0.18秒冷却）。B 只在新按下时发射一枚穿透弹，共两枚；与 A 同时按可同时发射，持续按住 B 不会耗尽弹药。三座拱形掩体共18格，每格能挡一次双方普通弹并被摧毁；穿透弹会继续穿过多个格子和敌人。敌阵接触掩体也会压碎格子。子弹之间不相撞。

三点生命耗尽，或任何存活敌人底边抵达金色防线（y380）时失败。清空全部敌人获胜。同一物理步按友弹、敌弹顺序处理，然后优先检查敌阵清空，再检查生命耗尽，最后检查抵线；因此最后击杀与同时受伤/抵线时，清空优先。受伤后0.8秒内继续消耗命中的敌弹但不重复扣生命。

模型以1/120秒固定步长推进真实时间，竖直投射物采用扫掠矩形碰撞。A 连射、敌阵、敌弹都持续运行；取消输入隔离控制直到全部松开，但不暂停物理。暂停会完整冻结模型。没有生产解路线、自动瞄准或强制清关。
