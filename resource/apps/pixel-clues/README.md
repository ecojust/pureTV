# 像素线索 / Pixel Clues

用行、列两侧的数字推导像素图。每个数字是一段连续涂色格的长度，多个数字按顺序排列，段与段之间至少留一格。例如 `2 1` 表示连续两格、至少一格空白、再一格涂色。所有行列同时吻合即完成。

| 操作 | 作用 |
| --- | --- |
| 四个方向 | 移动一格，不跨行绕回 |
| A | 空白或叉号变为涂色；已涂格变为空白 |
| B | 空白或已涂格变为叉号；已有叉号变为空白 |

叉号只是留白笔记，不算涂色，不必把所有白格都标叉。匹配的行列线索变灰，未匹配的保持墨蓝色。游戏仅按公开行列线索验收，不存放或比对隐藏答案图片。

三张图纸：箭羽（5×5，60 秒）、双翼（6×6，90 秒）、门楼（7×7，120 秒）。计时只统计有效游玩时间，暂停时冻结；未操作或输入取消期间仍计时。在截止瞬间完成最后一笔仍算成功，晚于截止的输入不执行。时间耗尽但未完成则失败。

- 每次按键需松开再按，长按不连续涂画或移动。同帧触发时 B 优先于 A，A 优先于方向。
- 键盘：方向键 / WASD 移动；空格 / Z / Enter 涂格；X / B 标叉；P / Escape 暂停，R 重试。
- 手机扫码：左侧摇杆移动，右上 A 涂格、右下 B 标叉；开始、恢复和取消输入后先松开。
