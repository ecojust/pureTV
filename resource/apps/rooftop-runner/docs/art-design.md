# 天台疾跑美术与信息设计

晨光铜色天空、青绿城市剪影和暖色屋顶构成横向跑道。角色采用薄荷绿夹克、橙色头盔与飘带，站立有两个交替步态，另有独立弯腰下蹲姿势。箱子为木板斜撑，悬梁为青铜桁架与黄黑下沿，缺口为明确的深蓝空洞。

玩家固定画面x190，地面y414。模型世界单位与画布逻辑像素一一对应，能够看到前方约746单位。角色主身体在图集中按实际24×48或24×26范围绘制，细外框再次标明准确碰撞矩形；飘带属于装饰，不是碰撞体。跳跃真实最高约82单位，下蹲后与悬梁下沿保留8单位间距。

悬梁和箱子的绘制矩形直接使用公开bottom/top/width。缺口只挖去真实gap区间，不在空洞下面误画连续屋顶面。立面窗格随世界滚动，天空建筑不参与碰撞。各障碍上方保留JUMP/DUCK提示，它们说明动作类别，不提供具体按键时刻或答案路线。

顶栏展示RUN距离、速度、NEXT类别和实际前沿距离；进入障碍范围后显示CLEAR后缘离开距离。右侧显示POSE与已通过障碍数，避免只凭人物小幅变形判断下蹲。全场景宽屏展开，上方信息带与底部操作条最后遮盖，防止滚动内容覆盖文字；左右也保留明确边界。

图集roofCity(0,0,640,384)、runnerStride(640,0,128,128)、runnerCrouch(768,0,128,128)、roofCrate(896,0,128,128)、runnerStrideB(0,800,128,128)、suspendedBeam(128,800,128,128)避开共享图形与ASCII字符。字体最小24逻辑像素，中文由公共DOM呈现，所有动态绘制使用公共批次。

最终预览需检查两种分辨率中的腾空过箱／缺口、梁下下蹲与8单位间隙、前方距离和完整侧栏。此文不预先宣称完成截图验收、录像或实体硬件性能检查。
