# Independent mechanics review

`tests/reference.mjs` derives quadratic height roots, exact open-interval rectangle overlap, and local jump windows from public obstacle dimensions. The digital pilot chooses the center of the valid jump interval with a small observation margin; it uses no production collision helper, prescribed action route, model write or clock injection.

Fourteen ordinary groups and four explicitly labelled synthetic groups passed across1,107 ordinary steps. The66/73/80/87/91ms jitter pilot clears8/11/14 obstacles in17.517/19.515/21.189 active seconds, making5/7/10 jumps and3/4/4 crouch entries. Ordinary tests cover analytical jump trajectories, partitioned time, actual gap departure, idle box/fall losses, omitted crouch losses, releasing/cancelling crouch under a beam, pause and consumed/nonbuffered A edges. Synthetic tests separately cover exact collision entry, isolated tangent versus positive overlap, far-edge landing versus roof-edge fall, and airborne/below-roof finish precedence.

The initial independent report found an ordinary near-gap boundary discrepancy: a roughly4e-16s rounding residue moved the runner to330.00000000000006 and disarmed the intended exact-edge jump. `independent-initial-failure.json` preserves that result. Production now canonicalizes physical boundary/frame-end coincidences only within eight scaled machine-epsilon units while preserving admitted target time. The final test proves exact-edge A works and a separate following1e-12 step still moves into the gap and starts gravity. This is not a general positive-dt cutoff.
