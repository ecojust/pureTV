# 障碍构造与验证范围

三条路线使用8／11／14个独立障碍，包含矮箱、悬梁、缺口三类。长度2540／3220／3920，速度145／165／185；箱高32／35／38、箱宽34／39／44；梁下沿34、上沿100，宽84／96／108；缺口宽72／86／100。相邻类型交替组合，留下可由观察反应的间距，不要求记忆隐藏动作序列。

作者驾驶器只读取当前状态和前方最近障碍：按距离判断是否新按A或持有B，不写入模型位置、速度、通过数或终局。66／73／80／87／91毫秒循环采样验证三关分别在17.52／19.52／21.19活跃秒到达终点；跳跃5／7／10次，下蹲3／4／4段，与障碍类别对应。测试程序不随生产资源打包。

自然失败覆盖挂机、观察跳跃但遗漏下蹲、观察其他障碍但遗漏跨缺口，以及真实跑入梁下后松开B。专用合成状态明确标注：箱子横向扫掠、落向箱顶、梁下抛物线恰好相切、近侧边界起跳／立即失去支撑、远侧恰好落地与低于屋顶、碰撞与终点优先级。

精确相切夹具曾产生8.000000000000005单位的浮点顶点，导致身体上沿被当成高于34。矩形重叠比较已加入契约明确的1e-10空间容差；真正超过边界的8.1单位顶点仍正确失败。地面事件另有1e-8高度归零容差，用于正确接受理论精确的远沿落地，不允许明显低于屋顶的角色被抬回。

模型每个小段以真实抛物线求出与障碍上下边的二次根，以横向匀速求左右边时间，把区间分开检测正重叠。不是只在端点采样，也不是把曲线当直线后宣称精确。独立配对审查另行推导接触、支撑与普通驾驶输入，验收结果独立归档。
