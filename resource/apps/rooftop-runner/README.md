# 天台疾跑 / Rooftop Runner

角色沿屋顶自动前进，不能左右走位。用跳跃高度和下蹲时机越过矮箱、悬梁与屋顶缺口。三关分别有 **8／11／14** 个决策障碍，速度为 **145／165／185** 单位每活跃秒。

## 操作

- **新按 A 起跳**：键盘空格、Z、Enter，遥控器确认或手机右上区域。必须站在屋顶上，且没有按住 B。
- **按住 B 下蹲**：键盘 X 或手机右下区域。在空中也能缩短身体，但不会改变跳跃速度或重力。
- 方向键不使用，前进速度固定。
- P / Escape / START 暂停整个场景；R / SELECT 重试。

按住 A 不会连跳。空中按 A 不会预存下一次跳跃，落地后仍须松开再按。A 与 B 同按时保持下蹲，该次 A 也需要重新松开。

## 三种障碍

| 障碍 | 如何通过 | 失败条件 |
| --- | --- | --- |
| 矮箱 | 提前跳过 | 身体撞到箱子；箱顶不是可站平台 |
| 悬梁 | 按住 B，直到身体完全穿过 | 身体碰到梁，包括梁下松开 B 后站起 |
| 屋顶缺口 | 从近侧起跳，落到对侧屋顶 | 坠得过深，或低于屋顶时撞到对侧边缘 |

金色屋顶边线标出缺口，悬梁的下沿有条纹。角色外框与实际身体宽高对应，下蹲时明显变矮。上方显示前方障碍、到达距离和当前动作；`CLEAR` 是身体后缘离开当前障碍还需的距离。

抵达终点即获胜，可以腾空越过终点线。碰撞或坠落会立即结束。暂停不会补跑时间；取消、断开输入会停止按键动作并松开下蹲，自动奔跑仍继续，重新释放控制后才能再次操作。

## 真实几何与验证

身体宽24，站立高48，下蹲高26；重力980，起跳速度400。箱子和悬梁都有公开碰撞矩形，屋顶支撑根据脚部中心判断。物理按固定小段推进，并用抛物线和直线分段求实际矩形重叠区间，没有依据按键序列表直接判定通关。

每关地图只包含障碍位置、尺寸、类型、长度与速度。测试驾驶器观察前方障碍，按66～91毫秒的抖动间隔发送普通 A／B 输入，三关完成时间约17.5／19.5／21.2活跃秒。路线或驾驶器不打包进游戏。
