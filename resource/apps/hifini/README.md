## 搜索与播放

- 输入歌曲或歌手名称搜索，搜索需要先登录 HiFiNi；也兼容包含静态播放器数据的官方帖子链接，例如 `https://www.hifini.net/thread-6544.htm`。
- 在「搜索结果」与「本地歌曲」之间切换。搜索结果可直接点播；本地列表提供「顺序播放」和「随机播放」，随机模式一轮内避免重复。队列最多 50 首，不是对整个站点曲库随机抽样。
- 搜索使用 `musicparse-search.htm?keyword=...`，保留网易云／酷我的来源 ID，以及歌名、歌手、封面和时长。包括没有关联帖子的歌曲。
- 新歌曲通过 `musicparse-play.htm?source=...&id=...` 下载，完整下载后保存到电视私有曲库，再由 Android 系统播放器读取本地文件，不依赖网址是否以 `.mp3` 结尾。下载时显示水平进度条、百分比及已下载／总大小，服务器未提供总大小时显示不定进度和已下载大小，可取消或重试；已有本地歌曲直接播放，不重复下载。
- 歌曲名旁显示本次用于下载的远程音频地址二维码，失败后仍保留。按确定可放大二维码，查看完整地址及播放错误，便于用手机验证；该地址是下载请求入口，不是电视上的私有缓存路径。
- 每个音频文件最多 64 MiB；持续收到数据的慢下载不再受原来的 90 秒限制，连续 45 秒没有进度或单次下载达到 30 分钟时才超时；未完成的临时文件在取消、切歌或停止服务时清理。完整保存的歌曲会保留，退出或重启应用不会删除。HTTP 仅允许网易云和酷我公共音乐 CDN，登录与搜索仍通过 HTTPS；不会向第三方 CDN 转发 HiFiNi 登录 Cookie。
- 显示来源提供的封面和歌手，右侧为原生律动动画：播放时运动，暂停、停止或离开页面后静止。它是视觉动画，不采集麦克风或分析音频频谱；不提供歌词。
- 支持播放／暂停、上一首、下一首、进度调整、后台播放、系统媒体按键和播放通知。

方向键选择，确定键操作；搜索过程中按返回可取消。界面跟随系统语言，支持中文和英文。

## 慢下载与中断恢复

下载超时或失败只在当前播放页面显示原因和重试入口，不主动关闭页面或返回电视桌面。

取消下载只立即更新状态，网络连接的关闭在后台处理，避免等待慢连接时阻塞遥控器操作。应用可见且正在下载或播放时保持屏幕唤醒，离开页面后解除屏幕保持。

搜索词、搜索结果、当前栏目及列表位置会保存在电视本机。下载或播放队列只保存歌曲的来源 ID、名称等必要信息，不保存会过期的音频链接或登录 Cookie。如果应用或服务被系统结束，再次进入可恢复曲目信息并手动重试；不会自动下载或自动播放。重试会重新取得音频地址并从头下载，不将未完成的文件列为本地歌曲。

## 本地歌曲与 50 首上限

「本地歌曲」列出已经完整保存的音频，并显示数量。可以离线点播或随机播放，无需先登录；歌曲名、歌手和时长随音频一起保存。封面仍使用来源图片地址，离线加载不到时显示默认插图。

播放按钮位于本地列表内。支持勾选、多选及全选，删除所选歌曲时会同时移除音频文件和列表记录；如果包含当前歌曲，会先停止播放。删除后的歌曲也会退出当前播放队列。

曲库按首次保存的顺序保留最多 **50 首**。下载第 51 首新歌前，会先删除最早保存的歌曲文件并更新列表，然后开始下载；如果这次下载失败或取消，列表会暂时剩余 49 首。重复播放已有歌曲不会占用新名额，也不会改变先后顺序。只有完整下载的文件才会进入本地列表；卸载应用或清除应用数据会移除曲库。

## 登录与记住账号

从首页右上角「账号」进入单一账号面板。这个入口不表示当前未登录，应用不会在每次打开时强制重新登录。上方提供扫码注册二维码，下方依次为用户名、密码和登录按钮。有账号可直接登录；没有账号可用手机扫描二维码，打开官方注册页面 `https://www.hifini.net/user-create.htm`。二维码只包含该网址，在本机生成，没有额外的注册跳转按钮。账号页不展示官网网页或网页导航按钮；按遥控器返回键退出。

用户名和密码使用 Android Keystore 的 AES-GCM 加密后存储在电视本机，不记录到日志，不随系统备份导出。点击「登录并记住」后，在后台填入并提交官方 HTTPS 登录表单。确认登录成功后，面板显示「登录成功」，1500 毫秒后返回播放页面。失败或需要网站验证时留在当前页面并显示提示；应用不会跳过网站验证。已保存的账号密码会自动恢复到原生输入框，仍需用户点击登录才提交。

官方网页的 Cookie 会保存在本机，并与原生搜索请求共享。会话仍有效时无需重复登录；会话到期、网站要求验证或账号状态变化时，仍需按网站提示完成登录。可以重新填入已保存的账号密码，也可以删除本机凭据或退出会话。

账号密码不会交给管理器或 agent。应用不把登录 Cookie 附加到第三方封面和音频地址。原生播放页面不执行站点脚本；账号页使用不可见的系统 WebView 处理官方登录表单。

## 构建与验证

```bash
cd resource/launcher/puretv
./gradlew :hifini:testDebugUnitTest :hifini:lintDebug :hifini:verifyReleaseSize
```

在仓库根目录运行 `node --test resource/apps/hifini/src/test/js/login-autofill.test.mjs` 可验证实际自动填充脚本的表单及域名检查（Node.js 22）。

Release 构建产物位于 `resource/apps/hifini/build/outputs/apk/release/`，发布资源使用 pureTV 证书另行签名。设置 `HIFINI_UI_CAPTURE_DIR` 可从原生 UI 测试导出中英文截图。解析测试使用用户提供的脱敏搜索片段及合成边界样本，来源说明见 [测试样本说明](src/test/resources/hifini/README.md)。

生产依赖为 jsoup（解析 HTML）与 ZXing Core（本机生成注册及音频地址二维码）；音频交给 Android MediaPlayer。Release 开启代码和资源压缩，大小上限 5 MiB。封面缓存上限 4 MiB，单次图片下载上限 2 MiB；歌曲列表最多 50 首。第三方许可见 [NOTICE.md](NOTICE.md)。

**在线验证状态：** 用户已确认电视端能够搜索，并确认 0.1.2 的“先下载再本地播放”能够正常播放。开发环境仍无法访问 HiFiNi，尚未独立验证真实账号登录和在线音频播放；0.1.4 的慢下载、取消、界面与服务重建恢复使用自动化测试验证；尚未取得用户电视的崩溃日志，不能将原先退回电视桌面的现象断定为某一个原因，修复效果仍需电视实测。原生界面、解析样本和播放器状态测试不能替代电视实测。网站结构、验证要求、音频链接格式或地区网络限制可能影响使用；应用使用官方搜索／播放入口与页面明示的数据，不执行解密脚本或接入第三方解析服务。
