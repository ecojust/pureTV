# 口袋接龙 / Pocket Solitaire

四列全部可见的牌、两个暂存格、四个固定花色归位区。三副牌分别包含每花色 1–3、1–4、1–5，共 12／16／20 张，步数上限 50／70／90。

每次只能移动一张牌列顶牌或暂存牌。牌列只接收**颜色相反且点数恰小 1**的牌，空列可放任意牌。暂存格只能放一张。归位区只接收本花色的下一点数，从 1 开始；归位牌不能直接移出。

- C 梅花、S 黑桃为黑；D 方块、H 红心为红。牌面同时显示点数、花色字母和图形。
- 左右循环选择全部区域：T1–T4 牌列、F1–F2 暂存、四个 HOME 归位区。上从牌列跳到对应上排位置；下从上排回到牌列，靠右归位区回第四列。
- A 选起点，再选目标并按 A 放牌；同一起点按 A 取消。错误目标不会换选起点，也不消耗步数。
- B 使用一张撤销票，恢复上次牌位并清除选牌。每局仅两票，**撤销不返还已用步数**。撤销是归位区回退的唯一例外，终局后不能撤销。
- 全部牌归位获胜，恰好最后允许一步完成也算获胜；否则次数用完失败。没有计时或自动归位。

三副牌已分别通过 20／24／39 步普通输入完整通关，其中含 8／8／19 次临时放置；这是可解路线见证，不声称都是最短路线。测试还通过合法可逆转移，把三关分别延至恰好 50／70／90 步获胜，并验证正常耗尽步数失败。

键盘：方向键 / WASD；空格 / Z / Enter 选牌；X / B 撤销；P / Escape 暂停；R 重试。手机左摇杆选区域，右上 A 选牌，右下 B 撤销。开始、恢复和输入取消后先松开；长按不重复。
