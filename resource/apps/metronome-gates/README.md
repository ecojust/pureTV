# 节拍闸道 · Metronome Gates

先排方向，再随节拍过门。蓝色玻璃球每 1.2 秒只走一格，收齐所有标记后进入出口即可过关。二拍门与三拍门共用同一拍号，观察门牌的当前、下一拍状态和未来预览，安排移动与等待。

**方向排队，A 等待，B 撤尾。** 手机摇杆或方向键直接把方向加入最多 6 项的队列；摇杆必须先回中、方向键必须先松开，再次拨动或按下才会加入下一项，长按不会连发。A 在队尾加入一拍等待，B 撤销尚未执行的最后一项；手机沿用上区 A、下区 B 两个大操作区。满队拒绝新项，B 不能撤销已经走过的格子。

键盘空格或 Z 为 A，B 或 X 为 B；Enter／手机 START 开始，P／START 暂停或继续，R／手机重试重新开始。

球只在拍点取队首并移动，两拍之间输入只编辑队列，不提前移动。空队也会等一拍并消耗预算。恰好在拍点输入时，先处理 B、方向、A，再执行队首；满队不能预借本拍即将释放的空位。

进入关闭的门或踩中陷阱立即失败；碰墙只会留在原地并花掉一拍。站在门上时门随后关闭不会夹伤球，离开也不受限制。提前到达出口不会过关；收齐标记后，最后一个预算拍仍可以进入出口获胜，否则预算耗尽失败。

| 关卡 | 地形与目标 | 拍数预算 | 预算时长 |
| --- | --- | ---: | ---: |
| 双桥庭院 | 绕庭院外环收集 3 个标记 | 48 | 57.6 秒 |
| 三岔采样 | 探索树状支路并折返，收集 4 个标记 | 64 | 76.8 秒 |
| 交错闸室 | 在十字回廊与外环间选路，收集 4 个标记 | 62 | 74.4 秒 |

预算时长不含暂停。菜单中选择关卡后开始，使用固定暂停入口暂停或继续，终局可重试。暂停保留位置、队列和距下一拍的余量；恢复不会赶拍。重试会重置地图进度、拍号、门相位与队列。

**输入取消与暂停不同。** 首次开始、输入取消、切换手柄或重新连接后，先松开全部操作并让摇杆回中，才能接收新的方向和按键。取消不会清掉已排队的命令，也不会停止拍钟；只有真正进入暂停才停止推进。
