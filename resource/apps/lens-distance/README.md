# 焦距实验室 / Lens Distance

把凸透镜和屏幕沿光学轨道移动，为不同位置的物体拍出清晰底片。屏幕必须接到实像；还要调节光阑，使清晰度与亮度分别达到要求。光阑越大越亮，但大光阑也会放大离焦与本游戏明确简化的像差，开到最大无法通过清晰度检查。

三个可选光台各有两张连续底片。完成两张即可获胜；切换底片时，物体位置、透镜、屏幕、光阑、调节范围和本张资源都会按题面重置。没有隐藏目标摆法，任何满足公开成像条件的设置都能通过。

## 操作

| 输入 | 动作 |
| --- | --- |
| 左 / 右 | 把当前选中的透镜或屏幕移动一格 |
| B | 切换当前选中的透镜 / 屏幕 |
| 上 / 下 | 将光阑增大 / 缩小一档，与当前选择无关 |
| A | 曝光，验收实像、清晰度和亮度 |

每张底片有 **4 次曝光电量**，每次 A 消耗一次。最后一次电量正确曝光仍能完成底片或获胜。每次实际移动透镜、屏幕或改变光阑消耗一次调整；黄铜、长距、精密光台每张分别允许 **24、22、16 次**。正好用完调整次数后仍可曝光，再做一次实际调整才失败。触碰范围边界而未移动、B 切换选择都不消耗资源。没有倒计时。

长按不连动，每次操作后松开再按。同时触发时 B 优先于 A，A 优先于方向，其余新输入不排队。拍完第一张后，持续按住的 A 不会误拍第二张。

- 键盘：方向键 / WASD；空格 / Z / Enter 为 A；X / B 为 B。
- 暂停：P / Escape / START；重试：R / SELECT，由宿主独立提供。
- 手机：右侧整个三分之一区域分为上方 A、下方 B。开始、恢复或取消输入后，先松开控制。

## 看懂光台

凸透镜焦距固定为 4，物距是物体到透镜的距离。物距大于 4 形成倒立实像；小于 4 形成正立虚像，屏幕不能接收；等于 4 时出射光线平行，没有有限像点。光路图展示实际位置、焦点和成像方向，虚像使用反向虚线延长线。

两项质量要求分别显示：亮度必须落在本张底片的公开区间内，模糊指数必须不超过 1，并且必须是实像。理想薄透镜负责几何位置；亮度和像差使用明确公开的教学游戏指标，并非完整物理相机模拟。显示小数可以四舍五入，验收始终使用精确整数交叉乘积。

| 光台 | 底片 | 每张调整额度 |
| --- | --- | ---: |
| 黄铜光台 / BRASS BENCH | 箭羽、叶片 | 24 |
| 长距光台 / LONG BENCH | 星芒、钥匙 | 22 |
| 精密光台 / PRECISION BENCH | 花瓣、塔尖 | 16 |
