# 渡河守则 / River Guard

船工驾驶小船，把全部物品从左岸送到右岸。每关列出若干**无向冲突对**：只有船工不在场时，同一岸上的冲突对才会造成失败；有船工照看时可以共处。规则以编号图例为准，不要求玩家了解动物或食物关系。

| 渡口 | 物品与冲突 | 货位 / 次数上限 |
| --- | --- | --- |
| 经典渡口 | 1狐狸、2母鸡、3谷物；冲突 1–2、2–3 | 1 / 12 |
| 菜园小舟 | 1山羊、2卷心菜、3萝卜、4豆苗；冲突 1–2、1–3、1–4 | 2 / 14 |
| 连环照看 | 1猫、2鸟、3虫、4叶子、5山羊；冲突 1–2、2–3、3–4、4–5 | 2 / 18 |

方向键按固定物品编号循环选择：左／上为前一件，右／下为后一件。A 勾选或取消同岸货物；B 开船，也可不载货空船返回。船工有独立座位，不占货位。勾选只是在安排装载，物品在开船时才同时换岸。

每次开船后清空货物选择，先检查无人看管的出发岸，再检查是否全部抵达右岸，最后检查次数上限。冲突立即失败，全部抵达则获胜，次数用尽仍未完成则失败。没有计时、撤销或自动阻止危险航行。

独立最短图搜索证明三关分别需要 7／5／7 次渡河。全部胜利与失败回归均通过普通输入；只有明确标注的规则边界夹具修改模型状态。由于起点在左岸、胜利要在右岸，正常胜利只能发生在奇数次，而本游戏的次数上限是偶数；“获胜优先于耗尽”的通用判定用合成计数边界验证，不声称正常路线可恰在偶数上限获胜。

- 键盘：方向键 / WASD；空格 / Z / Enter 勾选；X / B 开船；P / Escape 暂停；R 重试。
- 手机：左侧摇杆选择，右上 A 勾选，右下 B 开船。开始、恢复或输入取消后先松开；长按不重复。
- 同帧输入按 B、A、方向的顺序处理。输入取消会保留已勾选的货物。
- [公开模型契约](docs/model-contract.md)；模型检查：`node resource/apps/river-guard/tests/model-test.cjs`。求解器和路线不进入 APK。
