# 石箱归位 / Stone Bay

在石墙庭院里绕到箱子后面，把每个石箱推上圆形石座。石箱只能推，不能拉，也不能连推两个箱子。任何石箱都能放上任何石座；全部落座即可过关。箱上编号只用于辨认货箱，不对应特定石座。

| 操作 | 作用 |
| --- | --- |
| 四个方向 | 行走一格；前方有箱时尝试推一格 |
| A | 撤回最近一次成功步行或推箱，但不退已用推力 |

步行、撞墙和无效推箱免费，每次实际推动消耗一次推力。最后一次推力让全部箱子落座仍算成功，否则额度耗尽立即失败，结算后不能撤回。没有倒计时。误推死角时可在额度耗尽前撤回，或用宿主重试重新开始。

三座固定庭院：双石门庭（2 箱、8 次推力）、柱影庭院（3 箱、11 次）、曲径石场（3 箱、13 次）。石座空置时显示金色圆环，石箱落座后显示青绿色边框。

撤回只保留最近 **128 步**成功移动；更早记录会自动移除，界面会显示移除数量。撤回不会返还推力或累计步数；重新推同一箱仍然花费推力。B 无操作。

- 方向每次只走一格，长按不连走，松开再按。同帧触发时 A 优先于方向。
- 键盘：方向键 / WASD 移动；空格 / Z / Enter 撤回；P / Escape 暂停，R 重试。
- 手机：左侧摇杆四向移动，右侧整个操作区撤回；开始、恢复和取消输入后先松开控制。
