# 六角连线 · Hex Connection

原创界面的六角棋残局游戏。你执金色、带横向刻线的棋子，目标是连通棋盘左边和右边；蓝色、带竖向刻线的对手连接上边和下边。任意一条同色相邻棋链到达目标两岸就获胜，棋子数量不决定胜负。

每格与 `(x±1,y)`、`(x,y±1)`、`(x+1,y−1)`、`(x−1,y+1)` 相邻，共六个方向；`(x+1,y+1)` 和 `(x−1,y−1)` 不相邻。界面按此关系排列为真实六角格。边缘彩线标记目标，棋子刻线和侧栏文字同时提供颜色之外的辨认方式。

## 操作

- 方向键按行、列移动光标，每次按下移动一格。斜置棋盘的上下行在屏幕上也会横向错开。
- 空格、Z、遥控器确认键或手机整个右侧执行 **A 落子**；键盘字母 A 属于左移键，不是动作 A。
- 只能落在空格，落子后不能移动、吃子或撤回。已有棋子的格子不会消耗回合。
- B 不使用。长按不会连续落子。没有计时器。

你落子后先判定是否已连通；未获胜时对手立即应手一次，再判定对手是否连通。满盘不会产生人为和局。重试从该残局固定开局恢复。

## 三道固定残局

| 残局 | 棋盘 | 初始空格 | 对此固定对手的最少获胜落子数 |
| --- | --- | --- | --- |
| 琥珀弯道 | 5×5 | 11 | 4 |
| 象牙渡口 | 5×5 | 13 | 3 |
| 钴蓝长桥 | 6×6 | 14 | 3 |

三个开局的双方棋数相等、均未连通，轮到玩家，符合从空盘交替落子得到的合法中局。固定残局与完整空盘对局不同，不含交换执色规则。每题都有真实的获胜与失败路线；关卡难度由残局结构决定。

所有棋子都公开可见。对手使用固定策略，依次选择：立即获胜的位置；阻挡玩家立即获胜的位置；令自身连接代价最小、再令玩家连接代价最大的位置。同等条件始终选行优先编号最小的位置。连接代价将己方格计 0、空格计 1、对方格视为不可穿越，不是未来必胜预测。

## 验证与构建

`node resource/apps/hex-connection/tests/model-test.cjs` 运行 14 组模型检查，包括三关普通输入获胜及失败、最短获胜路线穷举、六邻接/边界、对手策略、满盘连通性、占位保护、输入取消与终局冻结。仅测试文件中的求解器不会随 APK 打包。人工构造的几何和对手策略夹具在报告中明确标记。

独立 QA 从公开棋盘重新实现规则与搜索，文件与报告位于 `tests/`、`docs/`。实际浏览器操作、画面检查、录像和签名记录在完成后由交付流程归档；模型模拟不能代替它们。未进行实体电视或手机测试。
