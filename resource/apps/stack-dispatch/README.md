# 序栈货运 / Stack Dispatch

用一台只能吊起一箱的吊机，在三个有限容量货栈之间安排货物，按货单顺序完成出港。货栈只能从顶端取放，压在下面的箱子必须先挪开上面的货物。所有来货和出货次序始终公开，第三关需要为被压住的早期货箱腾挪空间。

## 操作与规则

| 输入 | 动作 |
| --- | --- |
| 左 / 右 | 循环选择进货口、货栈 1、2、3 |
| A | 吊机空闲时取下一箱或栈顶箱；有货时放到选中货栈顶端 |
| B | 将吊起的货箱按货单出港，在任意位置均可操作 |

每次成功吊起或放下消耗一次搬动额度。恰好用完仍可选位置、出货；再成功取放一次才失败。满栈、空栈、空进货口或吊机已有货时的无效操作免费，货物不能退回进货口。出错货单时箱子留在吊机上，累计三次错序出货失败；空吊机按 B 免费。全部货物按序出港即获胜，没有倒计时。

| 关卡 | 箱数 | 每栈容量 | 搬动额度 | 出货顺序 |
| --- | ---: | ---: | ---: | --- |
| 首班分拣 | 6 | 2 | 24 | 4 → 1 → 5 → 2 → 6 → 3 |
| 交错货单 | 7 | 3 | 28 | 5 → 2 → 7 → 1 → 4 → 6 → 3 |
| 逆序回港 | 8 | 3 | 32 | 8 → 1 → 7 → 2 → 6 → 3 → 5 → 4 |

长按不连动，每次操作需松开再按。上、下方向没有操作。同时触发时 B 优先于 A，A 优先于方向，其余动作不排队。

- 键盘：方向键 / WASD；空格 / Z / Enter 为 A；X / B 为 B。
- 暂停与恢复：P / Escape / START；重试：R / SELECT。
- 手机扫码操作：左侧摇杆左右选位置，右侧上半区为 A、下半区为 B；开始、恢复和取消输入后先松开控制。

精确规则、输入生命周期和证据边界见 [模型契约](docs/model-contract.md)。模型回归通过 `node resource/apps/stack-dispatch/tests/model-test.cjs` 执行。测试求解器只在 tests 目录，不随游戏打包。浏览器验证和录像通过正常键盘输入推进，不能代替实体电视或手机测试。
