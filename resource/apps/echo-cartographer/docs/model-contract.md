# Echo Cartographer model contract (implementation candidate)

`PureModel.create(seed=1,difficulty=0)` creates an independent serializable round. `step(state,dt,input)` mutates it; input `{x,y,a,b,aPressed,bPressed}`. Rules run at 60 Hz, frame dt is capped at 0.25s. Shared runtime owns pause/menu/retry. Terminal `phase='won'|'lost'` freezes exactly; there is no solution/win command.

Coordinates are 960×540 logical pixels, y down. `grid={cols:19,rows:11,cellSize:40,x:100,y:50}`. `cells` is 209 row-major `{id,col,row,x,y,type:'wall'|'floor',seen,visible,revealedUntil}` records, with x/y at cell centers. Unknown cells MUST NOT be drawn according to their type or read as route information by the observational pilot. `seen` persists as a faint chart; `visible` permits bright detail and expires. The entrance is a permanent navigation marker.

- `player={x,y,vx,vy,angle,radius:10,col,row,tileId,speed,quiet,noiseRadius,shield,maxShield,invulnerable}`. Normal speed60px/s; held B selects34px/s and reduces moving noise radius180→35px. Zero input emits no movement noise. Wall collision uses bounded substeps and sliding; no diagonal corner tunnelling.
- `entry={x,y,col,row,tileId,radius:18,unlocked}`; `beacons=[{id,x,y,col,row,tileId,collected,visible,seen}]`. A beacon can be memorized only after it is visible; collection persists. `collected/target` are counts. Only all collected plus physical return within entry radius wins; starting at entrance does not win.
- `hazards=[{id,x,y,radius:11,angle,visible,alerted,...}]`. Art and pilot may read/draw current position only when visible; no hidden patrol/path hints. Floor-path movement noise within the player's noise radius gives 1.2s alert and a last-heard target; otherwise patrol. Speeds22/42px/s. Contact costs one shield, with1.4s invulnerability; player starts with3. Noise and hit feedback are actual state.
- `waves=[{id,x,y,originTileId,age,radius,speed,maxDistance,frontier:[cellId],...}]`, at most2. Origin stays fixed when player moves. Four-neighbor floor shortest-path travel (40px/edge), plus distance from emission point to its tile center. Walls are revealed only when reached from an adjacent floor, and stop propagation. Each wave travels200px/s up to320px. `frontier` lists only cells reached in its latest40px band: draw an occluded segmented front, not a circle through walls. Near light48px also uses wall line-of-sight. Echo visibility lasts4s after arrival, while seen memory persists.
- `battery/maxBattery`, `batteryDrain`, `sonarCost=3`, `cooldown/cooldownMax=1.1`, `reserve/maxReserve=10` seconds, `sonarCount`. A rising edge or genuine runtime pulse emits once only if cooldown is zero and battery≥cost. No recharging. Battery passively drains1.6/1.7/1.8 units/s from initial120/128/136. At battery0 the10-second reserve begins to drain; scans are disabled and near light shrinks to24px. Battery and reserve exhausted loses with `lostReason='darkness'`. `remaining=battery/batteryDrain+reserve` is estimated idle light time, reduced by scans; `timeLimit=maxBattery/batteryDrain+maxReserve` is initial maximum lifetime, not a separate timeout.
- Common fields: `level`1..3, `difficulty`0..2, `levelName`, `width,height`, `phase`, `elapsed,tick`, `score,message,lostReason`, bounded `events`, `revealedCount`, `sonarCount`. Menu names: 入门回廊 / 双厅追踪 / 折返迷宫. Handcrafted layouts use2/3/3 beacons and1/2/3 moving hazards. Geometry may be balanced before source freeze; field names remain fixed.

Per tick: integrate player/hazards; resolve shield contact; drain battery/reserve; advance echoes and visibility; reject shield/darkness failure before collecting beacons or awarding return. Beacons give500 points each; victory adds`500+round(remaining*10)+shield*100`. No partial bonus on loss. Collected beacons never reset when light fades. Retry creates the original battery, lamp reserve, shield, fog, beacons, patrol positions and input edges.

Renderer renders unknown cells as uniform darkness, remembered terrain dimly, currently visible terrain in detail, and hazards only while visible. Wave expiry does not erase memory. Model visibility applies to beacon/hazard art as well as walls. The pilot uses only seen floor cells, previously visible beacon observations and visible hazard observations; private wave distances/patrol targets are not route oracles.

Moving entity visibility is tested at its actual x/y: either its floor tile still has an unexpired sonar reveal, or its actual point is within the near-light radius with an unobstructed point-to-point line. Near-light visibility of a tile CENTER alone must not reveal a hazard around a wall corner or outside lamp range. Conversely a near entity may be visible before its tile center is lit; its visible flag is authoritative for its body, not a permission to expose that whole tile.

Hearing distance is a conservative grid approximation: for different floor tiles, shortest four-neighbor center path plus BOTH entity-to-own-center offsets; inside the same tile, actual Euclidean separation. Compare against noiseRadius inclusively. Disconnected floor regions are inaudible. This differs from sonar, whose source tile is immediately reached; no source-tile shortcut is applied to hazard hearing. A quiet stationary player has noiseRadius0 and does not refresh alerts.

Quiet movement is proactive stealth:34px/s outruns an unalerted22px/s patrol, but not an alerted42px/s pursuer. Once detected or hit, release B to use60px/s and create distance; resume quiet approach before the next detection. Collision/loss messages state this distinction.
