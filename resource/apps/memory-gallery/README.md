# 记忆陈列 / Memory Gallery

记住短暂亮相的展品位置，盖牌后找出相同图形与编号的两张。全部配对即可完成巡展。每种图形恰好出现两次，图形旁的数字帮助区分相近颜色。

| 操作 | 作用 |
| --- | --- |
| 四个方向 | 选择展品，不跨行绕回 |
| A | 翻开一张尚未配对的卡片 |

相同的两张立即锁定并保持正面；不同的两张保持正面一秒，然后盖回并增加一次错配。最后一次允许的错配也会完整展示一秒，再结束游戏。预览或比较期间不能翻牌，等待结束后松开再按；方向仍可移动。不能拿一张牌和它自己配对，B 无操作。

| 展厅 | 陈列 | 开场预览 | 错配上限 |
| --- | --- | ---: | ---: |
| 小厅初展 | 4×3，6 对 | 2.5 秒 | 4 |
| 方厅巡展 | 4×4，8 对 | 2 秒 | 5 |
| 长廊终展 | 5×4，10 对 | 1.5 秒 | 6 |

预览与错配比较按有效游玩时间推进，暂停时冻结；中立输入和输入取消期间仍计时。没有整局倒计时。卡片顺序按种子确定，重试同一关可以重新观察同一陈列。

- 每次按键需松开再按，长按不会连翻。A 与方向同帧触发时先执行 A。
- 键盘：方向键 / WASD 选卡；空格 / Z / Enter 翻牌；P / Escape 暂停，R 重试。
- 手机扫码：左侧摇杆选卡，右侧整个操作区翻牌；开始、恢复与取消输入后先松开。

公开规则见 [模型契约](docs/model-contract.md)。隐藏牌面只在模型私有 WeakMap 中保存，快照只含当前能看到的牌面；测试通过记忆开场预览完成操作。`node resource/apps/memory-gallery/tests/model-test.cjs` 运行模型回归。软件浏览器验证不能替代实体电视／手机测试。
