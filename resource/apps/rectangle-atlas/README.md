# 矩形图册 / Rectangle Atlas

Shikaku 矩形划分谜题。三张 4×4、5×5、6×6 图册只公开数字位置与面积，分别需要 4、5、6 个矩形。每张都包含细长矩形和面积大于一的正方形。

用互不重叠、与格线对齐的矩形铺满全部格子。每个矩形必须**恰含一个数字，面积等于这个数字**。圆圈数字是固定线索；R1、R2 等小标签只是你绘制的区域编号，不参与解题。

- 方向键逐格移动光标，不绕边。
- A 在空格设第一角，移动后再 A 设第二角；两角均包含在矩形内，任意方向都可绘制。同格按两次可画 1×1。
- 无选角时，A 点任一已画格会移除整块矩形，可无限次修改。
- B 先取消未完成的选角；没有选角时才检查完整图册。

重叠矩形会免费拒绝，保留第一角供调整。无数字、多数字或面积错误的矩形允许先画入，完整检查时反馈。尚未铺满的检查免费；完整但错误的一次检查只记一次错误，三次失败。编辑会清除旧检查标记。正确布局只在按 B 后获胜，没有倒计时或移动额度。

模型只读取公开数字和玩家绘制的矩形，不保存隐藏答案。测试专用求解器枚举含单个线索的矩形，再做精确覆盖搜索，证明三题各有唯一解；普通方向/A/B 输入可完成三题，也覆盖自然三错失败和两错后改正。求解器与解答不进入 APK。

键盘：方向键 / WASD；空格 / Z / Enter 绘制或移除；X / B 取消或检查；P / Escape 暂停；R 重试。手机左摇杆移动，右上 A，右下 B。开始、恢复或输入取消后先松开；长按不重复。
