# 气闸值守

在三舱救援站安排三组人员撤离。用有限储氧和一台共享泵，在省氧的回收与快速排气之间选择，赶上每组各自的安全期限，并封堵漏气支路。

- **抢修撤离**：留意工程队的紧迫期限与最终储备。
- **医疗优先**：医疗组需要最早抵达，不能照搬上一关安排。
- **满罐困局**：储罐容量会限制回收速度，实际余量和时间都很紧。

左右或上下选择人员/漏点；空闲时 **B** 切换回收或快排，**A** 执行。任务运行时可提前选择下一项，当前任务的人员和方式不变；**B** 停止设备，**A** 继续原任务。停止设备不会停止人员耗氧、漏气或期限；**P** 才是整局暂停，**R** 重试。手机扫码控制使用左摇杆和右侧上下两块大触控区，遥控器方向与确认键也可操作。

气闸自动执行排气、载入、充气与送达，压差和双门互锁始终有效。只有真正抵达安全舱的人员才停止本任务的耗氧；全员安全、漏点已隔离、罐内储氧达到任务底线才算成功。三关每局最多90秒。

画面使用原创空间站剖面、人员、金属门与管路烘焙图集，复用单批次WebGL渲染器。源码不包含商业游戏素材、ROM或隐藏通关接口。电视界面使用中文说明和英文仪表；手机控制器支持中文/英文。
