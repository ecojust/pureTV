# Art and propagation view

Original cream circuit desk with dark teal chips, copper/green labeled input nets, ivory port plates and rose selection frame. Complete DAG connections are represented as named network terminals A/B/C/G1... at every port, avoiding unreadable crossing wires across six nodes. Every row has its gate ID, both fixed source IDs and signal values, visible connector, operation label and actual output; the right title explicitly identifies the final output gate. Sources cannot be hidden by selecting another slot.

Six slots fit in56px rows; input/source labels21px, gate labels27px, output27px. Ports are110×21, chip120×49. NOT's second port says OFF and its connector bears an X, independent of color. Unknown signals use '?', zeros and ones show digits. Selected input row appears both in top A/B/C strip and highlighted among all eight table rows. Changing table row is a view action, not a check or edit.

The285px sidebar holds all eight input/target/actual rows, live match count and remaining checks. Dynamic notes distinguish free incomplete hint, current complete check and edited stale check; live signals continue to update after edits. All header/sidebar/footer strings are width-fitted. Numbered port labels are full fixed wiring, not a simplified hidden topology.

Atlas chip/port painting at0..256×128 avoids runtime reserved areas. SVG/Android icon shows a generic circuit illustration, not any puzzle's configured solution. All art is original vector/Canvas work, with no external image assets.

Actual960×540 and1280×720 partial/NOT/full-six-slot previews still require serialized browser visual review. Dimensions and parser success alone do not constitute that acceptance. No physical television or phone was tested.
