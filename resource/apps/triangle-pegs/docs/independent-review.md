# 三角跳珠：独立规则复核

以 [公开模型契约](model-contract.md) 为依据，测试自行构造三角格点、六方向跳跃几何及位掩码搜索，通过 `create` / `step` 普通方向和按键输入执行，不改模型状态。生产资产只含棋盘几何，搜索和路线均位于 tests。

```bash
node resource/apps/triangle-pegs/tests/independent-check.mjs /absolute/scratch/triangle-pegs/independent
```

9 组检查通过，核对 79 次真实模型跳跃和 9 次撤回。完整哈希、路线和末态见 [independent-report.json](independent-report.json)。三个初始空孔 1／5／8 均独立找到并通过普通输入完成 13 跳一珠胜利。

每跳独立计算来源、中间、落点三个孔的变化，核对实际珠数、历史、合法跳跃缓存、累计跳数与撤回额度。每关另走一条自然死路，确认有撤回额度时仍可操作；撤回并重走最后一跳三次，实际耗尽额度后进入失败。撤回必须恢复正确两珠、清空落点、把光标移回来源，且不能返还额度。胜利和失败后的按键均不能改变终局。

空孔选源、相邻而非跨两格的落点、免费取消、长按不重复和取消 epoch 后重新武装也分别检查。报告属于模型层证据，不代表浏览器输入、画面审查、签名 APK 或实体设备测试。浏览器脚本另通过真实按下／释放并等待可见状态响应，不能强制成功或修改时钟。
