# 三角跳珠 / Triangle Pegs

在十五孔三角棋盘上，把棋珠沿直线跳过相邻的一颗棋珠，落入两格外的空孔，并移除被跨过的棋珠。水平和两条斜线共六个方向均可跳跃；最终只剩一颗棋珠即可获胜，最后一颗可以停在任何孔。

三个开局分别空出 **1 号、5 号、8 号孔**，其余十四孔都有棋珠。目标与规则完全公开，没有隐藏目标孔，也没有倒计时。

## 操作

| 输入 | 动作 |
| --- | --- |
| 左 / 右 | 在当前行左右选择孔位，到边界停止 |
| 上 / 下 | 沿斜边换到上一行 / 下一行；上移越界时选择该行最右孔 |
| A | 未选珠时选中当前棋珠；已选珠时尝试跳入当前孔 |
| B | 已选珠时取消来源；未选珠时撤回上一次跳跃 |

键盘方向键 / WASD 选择，空格、Z、Enter 为 A，X、B 为 B。手机右侧上半区为 A，下半区为 B。P / Escape / START 暂停，R / SELECT 重新开始。长按不重复，每次操作后松开再按。同时输入按 B、A、方向的顺序取一个，其余不排队。

方形角标表示光标，金色圆环表示来源棋珠，青色圆环表示该来源当前可跳入的空孔。来源与光标可以位于不同位置。相邻移动、空珠起跳、跨过空孔、落入已有棋珠的孔均无效；无效尝试会保留来源选择，且不消耗撤回次数。

每局有 **3 次撤回机会**。B 取消选珠免费；只有未选珠时 B 才撤回一步，恢复起点与中间两颗棋珠，并清空落点。撤回后重新跳同一步仍需保留已消耗的撤回机会。

若还有多颗棋珠却没有合法跳跃，仍有撤回机会时可以按 B 恢复；无法撤回时才失败。只剩一珠立即获胜。终局后重试会重建完整开局。

精确棋盘坐标、状态及输入边界见 [模型契约](docs/model-contract.md)。测试目录的求解器只用于验证，不随游戏打包。浏览器键盘录像和软件渲染验证不等同于实体电视或手机测试。代码与原创棋盘素材采用 [MIT 许可证](LICENSE)。
