# 球道击柱 / Lane Bowling

俯视简化保龄击柱。三种公开的 6／8／10 瓶布阵，分别限 2／3／3 球；清空全部瓶获胜。没有预设命中角度或按选项直接奖励，倒瓶必须来自实际碰撞速度或位移。

左右每次调 3°，范围 −24°～24°；上下调四档力度，A 发球。投球中只能等待；停稳后继续瞄准。掉沟照样消耗一球，最后一球清空仍获胜。虚线只显示初始方向，不预测答案路线。

模型采用圆形刚体、质量加权冲量、摩擦和固定 1/120 秒子步，限制最高速度。球瓶与瓶间使用相同碰撞定律，瓶间可产生连锁推倒。被撞至速度阈值或从原位移动足够远的瓶记为已倒；每个倒瓶都保存物理收据。已倒瓶在本球内仍参与碰撞，扫瓶后不再阻挡；站立瓶保留实际位置。

每球停稳 0.1 秒后结束，最长滚动 6 秒后机械扫瓶；扫瓶本身不奖励倒瓶。白瓶站立，橙色 X 表示已倒，右侧瓶架持续记录全部状态。这是明确简化的游戏物理，不模拟旋转、专业瓶体姿态或专业保龄得分。

测试专用搜索通过普通调角、调力度、发球和有效 dt 等待，得到三关实际碰撞通关路线；还覆盖自然掉沟耗球失败、最后一球获胜、连锁、冲量／摩擦、无穿透正面碰撞、时间分片一致性及暂停取消。隔离物理夹具明确标为合成，不冒充正常通关。求解器与路线不进入 APK。

键盘：方向键 / WASD 瞄准；空格 / Z / Enter 发球；P / Escape 暂停；R 重试；B 不使用。手机左摇杆瞄准，整个右侧 A 发球。开始、恢复或输入取消后先松开；长按不重复投球。暂停冻结物理，普通输入取消不会停止滚动。
