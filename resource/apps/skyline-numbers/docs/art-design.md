# 数塔天际美术组织

深色背景承托浅色城市地块；每个非零格绘制有侧面、屋顶和立面线条的建筑，建筑绘制高度随该格数值实际升高。数字独立放在建筑右侧，不因矮楼而缩小。固定塔使用铜色底座及锁标记；重复冲突另用红框，当前光标用金框。

棋盘逻辑区域固定360×360，四周各自显示对应方向的线索；4、5、6阶自动采用90、72、60像素格子。最大6×6时数字约28像素，边缘线索27像素。无边缘条件用小圆点，避免把0误读为要求看见零栋楼。完整行列的当前可见数符合时标绿，不符合时标红；行列未完整时保持中性色。

右侧显示已填数、重复格数、三次验收机会以及所选格是否固定。几何和颜色仅表达模型的公开状态；没有读取答案棋盘。中文正文通过公共DOM层显示，建筑与格板在本款图集初始化时烘焙。
