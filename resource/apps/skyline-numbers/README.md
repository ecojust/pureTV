# 数塔天际 / Skyline Numbers

在方形城市里安排楼高，每行、每列都恰好使用一次 `1…N`。棋盘四边的数字不是楼高，而是从该方向看进去能看见的楼数：高楼挡住后面的矮楼，只有比之前所有楼都高的楼才会再次出现。

例如从左看 `1、4、2、3`，只能看见 1 和 4，共 **2 栋**；从右看同一排，能看见 3 和 4，也有 2 栋。边缘小圆点表示该方向没有提供线索。

| 操作 | 动作 |
| --- | --- |
| 方向键 / WASD / 手机方向区 | 选择格子 |
| A：空格 / Z / 确认 / 手机右上 | 将本格楼高循环为 `0→1→…→N→0`，0 表示空格 |
| B：X / B / 手机右下 | 消耗一次机会，验收整座城市 |
| P / Escape / START | 暂停／继续 |
| R / SELECT | 从本关给定楼高重新开始 |

铜色底座并带锁标记的楼高是固定条件，无法修改。编辑期间允许重复，涉及重复数字的格子会标红；填满一行或一列后，其边缘线索符合时变绿，不符合时变红。**填好后不会自动胜利，必须按 B 验收。**

每局有三次验收机会。空格未填完、行列重复或可见楼数不符都算一次失败；第三次验收正确仍能通过，第三次仍错则结束。没有倒计时或编辑次数限制。长按不会重复修改，每次操作后先松开再按。

| 城市 | 棋盘 | 固定楼高 | 非零边缘线索 |
| --- | --- | ---: | ---: |
| 庭院小城 | 4×4 | 1 | 8 |
| 运河新城 | 5×5 | 2 | 10 |
| 台地都会 | 6×6 | 10 | 12 |

三关均由仅使用公开给定条件的测试求解器验证为唯一解。去掉全部边缘线索后，每关都有多个合法数字方阵，因此必须结合城市视野推理。游戏只保存公开条件，不包含答案棋盘或求解器。
