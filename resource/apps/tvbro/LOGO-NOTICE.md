# TV Bro logo SVG adaptation

`logo.svg` is a hand-drawn 64×64 vector adaptation of the TV Bro app identifier. It retains the blue background, white TV/BRO lettering, browser controls and globe motif of the upstream icon.

- Author and copyright: Fedir Tsapana / TV Bro contributors.
- Upstream version: [v2.1.6](https://github.com/truefedex/tv-bro/tree/v2.1.6).
- Reference: `metadata/en-US/images/icon.png` in the bundled, unmodified `source.tar.gz`.
- License: [the upstream TV Bro redistribution license](LICENSE), including its original copyright notice and restrictions on modified binary redistribution.

Changes: the raster identifier was redrawn with plain SVG paths, using the original blue `#5FACFF` and white. Fine details were simplified for a 64×64 launcher icon. This is a local SVG adaptation, not an official upstream vector file. The file identifies the original, unmodified TV Bro APK included in this folder; it does not rename or modify the third-party application. The APK and source archive remain byte-for-byte unchanged. This adaptation does not grant permission to use the TV Bro name or icon for a modified application.
