# 交叉数和 / Sum Crossings

Kakuro 数和填格。三张不规则黑白棋盘为 4×4、5×5、6×6，含 8／13／16 个白格；每个连续横段和纵段长度为 2–4。

黑色线索格斜分两半：**右上数字和右箭头表示右侧横段之和；左下数字和下箭头表示下侧纵段之和**。各段填入 1–9，段内不得重复，且合计等于线索。不同数段允许相同数字，不要求整盘数字唯一。

| 操作 | 作用 |
| --- | --- |
| 方向键 | 沿同一行或列选择下一白格，跳过黑格，不绕边 |
| A | 空白→1→2…→9→空白；带方钉的固定格不可修改 |
| B | 提交完整棋盘，检查所有横纵数段 |

填数和清空都不扣错误次数。还有空白时按 B 会提示补全，也不扣次数。完整棋盘若任一段重复或和数不对，该次检查只记 **1 次错误**，三次错误失败；满足所有公开约束则获胜。填满后必须按 B 才会结算，没有倒计时。

三关只公开黑白布局、各段数和以及 0／1／1 个固定数字，没有隐藏答案表。测试求解器从公开约束验证唯一解，再通过普通方向键、A、B 完成输入；测试解和求解器不进入 APK。

绿色线索表示该段已满足公开条件。错误提交后的红色线索指出失败的段，继续改数会清除旧的错误标记；它不提供隐藏答案。

键盘：方向键 / WASD；空格 / Z / Enter 改数；X / B 检查；P / Escape 暂停；R 重试。手机左摇杆选择白格，右上 A 改数，右下 B 检查。开始、恢复或输入取消后先松开；长按不连填。
