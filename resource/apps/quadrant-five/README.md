# 旋盘五子 · Quadrant Five

在6×6棋盘中落子，再旋转一个3×3棋区。白棋是玩家，蓝棋是自动对手；每一完整回合都包括一次落子和一次任意棋区的90度旋转。横、竖、斜线连续至少五枚同色棋获胜，但只在旋转后判定。

## 两阶段操作

1. 落子阶段：方向键选空格，A放一枚白棋。
2. 旋转阶段：方向键按2×2布局选四个棋区，B在顺时针CW和逆时针CCW间切换，A确认旋转。

不能跳过旋转，也不能撤销已放的棋子。落子后默认选中该格所在棋区、顺时针；可以改成任意棋区。A必须松开后重新按下才能确认下一阶段，长按不会连动。暂停或输入取消保留待旋转局面，不会悄悄完成回合。

A对应空格、Z、遥控器确认或手机右上；B对应X、B或手机右下。键盘字母A属于左移键，不是动作A。落子阶段B没有作用。

旋转后若双方同时连五，本局和棋，需重试；满盘而无人连五也需重试。只要白棋单独连五就通过，蓝棋单独连五则失败。蓝棋仅在玩家完整回合未终结时应手。

## 公开残局与对手

三关均以白14枚、蓝14枚、空格8个的固定公开位置开始。测试中保存28个完整回合的合法交替开局历史，每一步旋转后都未终局，最终精确得到该棋盘。这是规则可达性证明，不声称历史中的蓝棋选择遵循当前残局自动对手的策略。

公开搜索证明，每关对白棋至少需要4个完整回合才能获胜；每关也有普通操作失败路线。自然对局还能到达双方同时连五及满盘和棋，不靠强制改写棋盘制造结局。

对手穷举所有空格、四个棋区和两种方向的合法完整回合。它先按结果优先级排序：蓝棋单独获胜、继续对局、双方同时连五、满盘和棋、白棋单独获胜；同级比较未被对方占据的长度5窗口分数，蓝方分数减白方分数。窗口0..5枚己方棋子的权重为0/1/4/12/40/1000。最后按格子行优先、棋区1..4、顺时针先于逆时针确定平局。没有随机数或秘密搜索路线。
