# 防火带

在山火蔓延前清理林格，规划能保住村落与森林的防火带。行动点有限，而且主动砍掉的树同样不计入存活森林；把所有路径都清空不是答案。

- **山口初防**：一座村落、两次清理机会，辨认风口与林带的连接。
- **双村岔口**：两座村落面对分岔的火路，留意天气转向后的累积热量。
- **湿地守望**：两处粗木火点与湿地，既要辨认天然阻隔，也要保护相连林地。

方向键或手机摇杆移动选格；**A** 清理尚未燃烧的林格，每格消耗一个行动点；**B** 切换当前热力图。**P** 暂停或继续，**R** 重试。手机右侧两块大触控区分别执行 A/B，遥控器方向和确认键也能操作。

火势每两秒同时更新。顺风传热更快，多个邻火会共同加热，达到热量5就会起火；新火从下一轮开始传播，最后一份燃料仍会传热。天然空地、湿地和清理后的防火带阻断传播。粗木火点有更高且可见的燃料，不需要人为等待结算。

所有村落完整、至少70%的原始林格仍然站立，并且余火全部熄灭才算胜利。正在燃烧、烧毁和主动清理的林格都计入森林损失。热力图显示现有残热，查看它不会暂停火势；界面分别标明上一轮实际风向与下一轮传播风向。每局最多90秒。

画面使用原创林地沙盘与烘焙图集，共用单批次 WebGL 渲染。源码不包含商业游戏素材或隐藏通关接口。电视说明使用中文，手机控制器支持中文和英文。
