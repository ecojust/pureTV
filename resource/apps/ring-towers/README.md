# 环塔迁移 / Ring Towers

把左柱上的整座环塔迁到右侧目标柱。一次只能搬动一枚顶环，而且大环不能压在小环上。利用中间柱暂存，安排大小环的移动次序。

| 操作 | 作用 |
| --- | --- |
| 左 / 右 | 循环选择三根柱子 |
| A | 未选来源时标记来源柱；已选来源时，把它的顶环搬到当前柱 |
| B | 取消来源标记，不搬环、不扣次数 |

标记来源不会提前拿走环，来源柱的顶环仍清楚可见。金色框表示当前选择，珊瑚色标记表示来源；目标是右侧第 3 柱。环的数字就是大小，数字越大，环越宽。

只有合法搬环才消耗次数；选空来源、同柱落环、大环压小环都免费且不会改变环的位置。选错落点时来源仍保留，可换柱重试或 B 取消。**没有撤回**，B 只能取消尚未完成的来源选择。

| 关卡 | 环数 | 搬动额度 |
| --- | ---: | ---: |
| 铜环初阶 | 3 | 11 |
| 钴蓝四环 | 4 | 21 |
| 珊瑚五环 | 5 | 39 |

最后一次允许搬动完成目标仍算成功；否则额度耗尽立即失败。没有倒计时。长按不重复，每次操作需松开再按，上下方向无操作；同帧输入按 B、A、方向的优先级执行。

- 键盘：左右方向键 / A、D；空格 / Z / Enter 确认；X / B 取消来源。P / Escape 暂停，R 重试。
- 手机扫码：左侧摇杆左右选柱，右上 A 确认、右下 B 取消；开始、恢复和取消输入后先松开。
