# 渡河跃步 / River Hopper

Frogger 式实时过路渡河。三档需要抵达 **2／3／4 个不同家位**，各有三条生命和 **45／60／80 秒活动时间**。四个家位均公开，任意未完成家位都可作为下一目标。

方向键一次跳一格：左右从当前连续横坐标加减 60，上下换一行并保留横坐标。乘木后不吸附回整数格。A、B 均不使用。绿色起点与中间河岸安全，可以观察等待。

- 车辆横向移动，与角色接触会扣一命。
- 河道需要整个脚步被原木托住，脚步半径 10；原木以真实速度携带角色。
- 原木环绕边界时，角色只按速度继续漂，不会瞬移到另一侧；随木漂出边界扣一命。
- 进入新的家位计一次并回起点；重复家位或落在家位之间会扣一命。
- 手动尝试跳出棋盘会免费拒绝。失误或到家后回起点短暂停步 0.3 秒，期间车、原木与活动时钟继续运行。

角色与场景使用固定 1/120 秒子步。暂停冻结所有运动和时钟；普通输入取消只隔离按键，活动场景仍继续。三命耗尽或活动时间耗尽失败。全部目标完成后冻结终局。

模型只包含公开车道、原木、家位及几何规则，不带通关时间表。测试专用公开场景搜索通过普通方向输入在 80 毫秒采样和 70–90 毫秒抖动下完成三档；自然车撞、落水、随木出界、重复家位、家位落空及超时均有验证。精确边界的合成夹具单独标记，不冒充普通游玩。

键盘：方向键 / WASD；P / Escape 暂停；R 重试。手机使用左侧摇杆，右侧动作键不使用。开始、恢复、输入取消或短暂回起点后先松开方向；长按不自动连跳。

[公开模型契约](docs/model-contract.md)。模型检查：`node resource/apps/river-hopper/tests/model-test.cjs`。原创河岸、波纹、原木、车辆、角色、家位、生命与时钟图标采用 [MIT 许可证](LICENSE)。浏览器仅用正常按键和墙钟；软件结果不代替实体电视／手机测试。
