# 独立规则复核

独立测试仅消费公开配置和 `create/step` 接口，另写分段速度积分、边界反射和区间交集参考；没有读取求解答案或写入运行中状态。15组通过，包括720次运动对照、20秒不同步长等价、三关6/8/10层普通输入胜利、31次落点核对、落地后剩余时间、自然16与15.5宽度边界、自然落空及按住／取消／暂停。

复核曾发现按普通输入计算的16宽落点得到15.999999999999886并错误失败。实现已按公开约定在1e−10内规范到16，裁边和碎片共同使用规范化右边界；最终报告对应修正后的源码。最初失败报告保存在本次临时环境 `/workspace/scratch/tower-overlap/independent-initial/report.json`。最终可复查数据见 `independent-report.json`。

这些模型检查使用合法模型时间步；实际浏览器与录像另用正常墙钟和键盘验收，不代表实体电视／手机测试。
