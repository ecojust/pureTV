# 数字汇聚 / Merge Tiles

向四个方向滑动整盘数字，把相邻的相同数字合成更大的块，在有效步数用完前形成目标数字。每个数字每次滑动只能合并一次：`2 2 2 2` 向左得到 `4 4`，不会直接变成 `8`。

| 操作 | 作用 |
| --- | --- |
| 四个方向 | 全盘向该方向压实，并按顺序合并相同相邻块 |
| A | 用一张撤回券恢复上次棋盘与出块进度，不退已用步数 |

没有改变棋盘的方向免费，也不生成新块。有效滑动消耗一步；未达目标时生成一个公开规则决定的 2 或 4。合并到目标立即胜利，即使恰好是最后一步，也不会再添加新块。无路可走或步数用完则失败，结算后不能撤回。

| 关卡 | 目标数字 | 有效步数 |
| --- | ---: | ---: |
| 琥珀初聚 | 32 | 30 |
| 青玉汇合 | 64 | 40 |
| 钴蓝高阶 | 128 | 55 |

每局两张撤回券。撤回同时恢复合并得分、出块序号和棋盘；重做同样的方向会得到同样的新块，但还会消耗一步。B 无操作，没有倒计时。颜色只作辅助，所有数字都直接显示。

出块数值按 `2,2,4,2,2,2,4,2` 循环。滑动后把空格按行从上到下、从左到右编号，空格序号为 `(种子 + 出块序号×7) mod 空格数量`。出块序号从 0 开始；默认种子 766。界面显示下一个数值，实际落格取决于你滑动后的空位。

- 每次方向需松开再按，长按不连走；A 与方向同帧触发时优先撤回。
- 键盘：方向键 / WASD；空格 / Z / Enter 撤回；P / Escape 暂停，R 重试。
- 手机扫码：左侧摇杆四向滑动，右侧整个操作区撤回。

公开初始棋盘和精确规则见 [模型契约](docs/model-contract.md)。测试：`node resource/apps/merge-tiles/tests/model-test.cjs`。测试求解器与路线不进入游戏资源；软件浏览器验收不代表实体电视或手机测试。
