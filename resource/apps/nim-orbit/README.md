# 取石回合 / Nim Orbit

每回合从**一堆**取走至少一颗石子，可取到该堆全空。你行动后，对手按公开、确定的最优规则立即回应。

| 关卡 | 初始石堆 | 最后一颗规则 |
| --- | --- | --- |
| 初始轨道 | 2、3、4 | 取最后者胜 |
| 四月列阵 | 3、5、6、2 | 取最后者胜 |
| 留下一颗 | 1、3、4、5 | **取最后者负** |

左右循环选择石堆，上增加、下减少本次取量，A 确认，B 不使用。取量保持在当前堆的合法范围；空堆显示 0，确认不消耗回合。金色且带减号的石子表示本次计划取走的数量。顶部中文规则与棋盘右侧 WINS／LOSES 同时明确本局最后一颗的归属。

每次取石后立即判定是否全空，再决定是否轮到下一方。没有倒计时或回合上限，石子总数严格减少，自然保证终局。实际三关最短获胜分别需要 4／7／5 个玩家回合，也均有正常操作下的失败路线。

对手按堆编号、取量从小到大找首个让下一方处于败势的行动；普通局使用石堆 XOR，反规则在所有非空堆只剩一颗时改用奇偶判定。没有必胜行动时，从最大堆取一颗，数量并列选编号较小者。完整定义和终局优先级见 [模型契约](docs/model-contract.md)。测试独立递归枚举局面结果，未复用生产 XOR 判定。

- 键盘：方向键 / WASD；空格 / Z / Enter 确认；P / Escape 暂停；R 重试。
- 手机：左侧摇杆选择堆和数量，右侧整块区域确认。开始、恢复或输入取消后先松开；长按不重复。
- 模型验证：`node resource/apps/nim-orbit/tests/model-test.cjs`；求解器和路线不进入 APK。
- 原创分面陨石带有逐颗数字，堆底还有不同形状标记；图形和数字补充颜色信息。
