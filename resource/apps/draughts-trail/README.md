# 跳吃棋径 / Draughts Trail

在 6×6 棋盘上执浅色棋子，与公开规则的深色对手对弈。吃光对手或让对手无合法行动即可获胜；己方被吃光或无路可走则失败。

普通子沿斜线向前走一格，跳过相邻敌子并落到空格即可吃掉它。**普通子走与吃都只能向前**：浅色向上，深色向下。王棋带皇冠，可向前或向后走一格／短跳，不能远距离飞跳。

| 操作 | 作用 |
| --- | --- |
| 四个方向 | 移动光标，不跨边绕回 |
| A | 选择浅色棋子，再选择标记的合法落点 |
| B | 取消尚未开始跳吃的选择 |

全盘只要有子能吃，就必须跳吃，不能另走普通步。一次跳吃后若还能跳，必须由同一枚子继续，不能取消或换子。普通子到达最远一行时升王，并**立即结束回合**，不能在刚升王的同一回合反向续吃。

三道固定残局：初渡棋径（各 3 子）、断阵棋径（各 4 子）、王冠通路（各 5 子，双方各含一枚王）。对手在你完整回合结束后立即完成回应，画面显示对手最近完整路径。对手有吃必吃，优先吃最多子，再优先升王，最后按位置固定排序；没有吃时优先升王及向前推进。具体排序见公开契约。

每次双方各走一回合计两个半回合，80 个半回合仍未分胜负视为和局，本关按失败处理。吃光或困住对手的结果优先于回合上限。没有倒计时。

- 长按不重复操作；同帧按键依次按 B、A、方向优先级执行。
- 键盘：方向键 / WASD；空格 / Z / Enter 确认；X / B 取消选择；P / Escape 暂停，R 重试。
- 手机：左侧摇杆移动光标，右上 A 确认，右下 B 取消；开始、恢复或输入取消后先松开。

全部残局、对手规则和输入边界见 [模型契约](docs/model-contract.md)。模型测试：`node resource/apps/draughts-trail/tests/model-test.cjs`。测试求解路线不进入 APK 资产；软件浏览器验证不代替实体电视或手机测试。
