# 口袋果岭 / Pocket Golf

俯视迷你高尔夫。静止时选择角度、五档力度，A 击球；之后球的位置由真实时间、摩擦和圆球碰撞积分决定。边墙与矩形石障会反弹，球停稳后可从新位置再击。没有预设角度命中、路线判定或自动进洞。

左/右每次调5度，上/下调一档力度。0度向右，90度向下，180度向左，270度向上。A 击球，B 不使用。所有按钮都要松开才能重复；运动中操作被消耗，不会等停稳后自动执行。暂停冻结运动；取消输入只隔离控制，球继续按物理规则滚动。

球半径8，球杯外圈半径18，有效球心捕获半径12；球心处于捕获圈内且即时速度≤65才进洞，高速越杯不算。球杯速度以实际路径交点计算，不用子步末速度代替。五档初速80/155/230/305/380，摩擦减速度95，弹性系数0.9，速度降至8及以下后停稳。有限杆数用尽后仍允许最后一杆滚动；先判断低速进洞，再在停稳未入杯时失败。

三洞分别为开放果岭（4杆）、回弹湾角（6杆）、曲径花园（6杆）。后两洞起点到球杯的直线被障碍阻挡，需绕行或反弹。作者通过普通输入以1/3/2杆完成；独立策略从公开几何另行求得路线，不读取作者路线。测试路线与规划器只在 tests，生产资产只有公开几何和通用物理规则。

```sh
node resource/apps/pocket-golf/tests/model-test.cjs
node resource/apps/pocket-golf/tests/independent-check.cjs
```

自测覆盖三洞正常胜利、全部最后允许杆数胜利、三洞自然耗杆失败、普通高速越杯、真实摩擦和时间分区一致性、墙角/圆角障碍碰撞、防穿墙、释放门控、暂停取消和终局冻结。边界物理夹具明确标为合成模型测试；普通路线和正常耗杆测试没有修改运行状态。

原创果岭、石障、旗杯、球与瞄准点由本目录绘制。瞄准点只表示当前角度和力度，不显示未来球路。实际浏览器键盘、双尺寸目视检查、录像与正式签名由集成验收补齐；没有实体电视或手机测试，源码候选不计入交付数量。
