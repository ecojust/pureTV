# 马步巡游 / Knight Circuit

用国际象棋中“马”的走法，访问棋盘上的每个可走格子，**每格恰好一次**。起点已经访问过，无需跳回起点。三个棋庭分别是完整 5×5、中心留白的 5×5 和完整 6×5；起点和留白格全部公开。

马一次横走两格、竖走一格，或横一竖二，共八种方向。它直接跳到落点，中间跨越的格子不算访问，也不会阻挡跳跃。

| 操作 | 动作 |
| --- | --- |
| 方向键 / WASD / 手机方向区 | 移动黄色光标，不移动马 |
| A：空格 / Z / 确认 / 手机右上 | 马跳到光标所在的合法、未访问格子 |
| B：X / B / 手机右下 | 花一枚回退券，撤回上一跳 |
| P / Escape / START | 暂停／继续 |
| R / SELECT | 从本关起点重新开始 |

每局有 **3 枚回退券**。回退会恢复上一个马位，并让刚离开的格子重新变成未访问；光标也回到马位。不能撤销最初的起点，不能退还回退券。非法落点和光标碰边都没有惩罚。

如果还没访问完就走进死路，有券时游戏会等待你按 B 回退；没有券又无路可走才失败。若已经访问所有可走格子，立即获胜，最后没有落点也不影响完成。没有倒计时或额外跳跃额度；模型不会用隐藏求解器提前判定一个尚能继续的路线失败。

白马是当前位置，金框是光标；圆点是当前合法落点，圆圈数字表示访问顺序。长按不连动，恢复后先松开按键。

| 棋庭 | 起点 | 可走格数 |
| --- | --- | ---: |
| 月庭起步 | A1 | 25 |
| 中庭留白 | E5；C3 不可落脚 | 24 |
| 长庭巡游 | F1 | 30 |

精确规则和输入边界见 [模型契约](docs/model-contract.md)。测试用深度优先搜索证明三关均有完整巡游路线，搜索代码仅在测试目录，未打包进游戏。棋马图形、棋盘材质与图标均由代码绘制，按 [MIT 许可证](LICENSE) 提供。
