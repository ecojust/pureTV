# 马步巡游美术组织

采用深海蓝背景、象牙色棋格和原创白马棋子轮廓。浅深交错棋格、刻纹留白格和边缘字母／数字共同表达棋盘；中心留白通过斜线和叉号识别，不只靠颜色。

黄框表示自由移动的光标；白马表示实际当前位置；金色圆点表示当前合法落点；已访问格使用蓝圈和白色访问序号。三种标记分工明确。序号来自真实 path，未访问的格子不会显示未来路线。跳跃可以跨越留白格，渲染不把中间经过位置画成已经访问。

逻辑画布960×540，格宽72，访问序号27像素。最大6列棋盘仍与右侧状态栏分离；状态栏显示进度、当前马位、光标、合法落点和三枚回退券。全部图形在该游戏的自定义图集中烘焙，共用公共批次渲染器。

最终两种视口的截图与正常操作录像仍需实际检查，本说明不宣称实体电视验证完成。
