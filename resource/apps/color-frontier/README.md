# 染色连疆 / Color Frontier

从地图左上角的一片颜色开始，选择染料让整片疆域改色，连接相邻同色地块，直到整幅地图连成一体。只有上下左右相邻才能连入，斜角相碰不算相连。地图上的圆点表示已拥有的区域；每格同时显示颜色编号，避免只靠颜色区分。

| 操作 | 作用 |
| --- | --- |
| 左 / 右 | 循环选择珊瑚、金黄、青玉、靛蓝染料 |
| A | 改染已拥有区域，并吸收所有四向相邻的同色区域 |
| B | 撤回最近一次扩染，但不退还已用次数 |

选择当前颜色免费；改成其他颜色总会消耗一次，即使没有连入新格。最后一次扩染完成全图仍算成功，否则次数耗尽立即失败。撤回仅在进行中可用，不能救回已经失败的地图。没有倒计时。

三个固定关卡：春湾渗染（5×5，6 次）、三角洲纹（6×6，8 次）、岛链回染（6×6，9 次）。所有地图公开，没有隐藏目标摆法。撤回可修正选择，但重新扩染仍会消耗次数，先观察边界再落色。

- 每次操作需松开再按，长按不连动；上、下方向无操作。同时按下时 B 优先于 A，A 优先于方向。
- 键盘：方向键 / WASD；空格 / Z / Enter 为 A；X / B 为 B。P / Escape 暂停，R 重试。
- 手机扫码：左侧摇杆左右选色，右上 A 扩染、右下 B 撤回；开始、恢复和输入取消后先松开。

公开规则见 [模型契约](docs/model-contract.md)。执行 `node resource/apps/color-frontier/tests/model-test.cjs` 检查规则；独立求解与实际输入验证放在 tests，不随游戏资产打包。软件浏览器验证不能代替实体电视或手机测试。
