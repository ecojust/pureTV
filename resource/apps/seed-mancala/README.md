# 播子棋盘 / Seed Mancala

一块两排种穴、两端种仓的 Kalah 棋盘。你控制下排 P1–P6 和右仓；对手控制上排 E1–E6 和左仓。每局共 24 颗籽，收盘时己仓比对仓多即获胜，同籽按失败处理。

| 操作 | 作用 |
| --- | --- |
| 左 / 右 | 循环选择下排种穴 |
| A | 将所选非空穴的全部籽逐颗播出 |
| 上 / 下 / B | 不使用 |

播种沿下排向右、上排向左绕行，跳过对方种仓。末籽落入己仓可再播一次，期间对手不行动。末籽落入原本空的己方种穴，且正对穴有籽时，将末籽和对穴全部籽收入己仓；对穴为空则不吃。

任何一侧六穴全空时立即收盘，剩余穴籽归各自种仓。否则到 160 次双方累计播种仍未决，按失败处理；收盘结果优先于这个上限。空穴不消耗播种次数，没有倒计时。

对手采用公开确定规则：优先尚可再走的行动，再优先吃籽数、入仓增加数，最后选最低编号种穴。对手连走会一次完成，底部列出最近一次播种路径、吃籽数量和本轮对手播种次数。路径 P / E 表示双方种穴，PS / ES 表示双方种仓。

三道固定残局：琥珀丰收、一籽之差、回环收籽。最短获胜路线需要 5／5／6 次玩家播种，也均存在正常失败路线。模型、独立求解测试及路线只用于验证，求解器不进入 APK。

- 键盘：左右方向键 / A、D 选择；空格 / Z / Enter 播种；P / Escape 暂停；R 重试。
- 手机：左摇杆左右选择，右侧整块区域播种。开始、恢复或取消输入后先松开；长按不连播。
- 完整规则和 AI 排序：[模型契约](docs/model-contract.md)。运行 `node resource/apps/seed-mancala/tests/model-test.cjs`。
- 原创程序美术采用一张烘焙图集，数字与 P/E 标签补充颜色信息。软件浏览器检查不代替实体电视或手机测试。
