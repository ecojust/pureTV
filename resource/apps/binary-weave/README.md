# 二元织格 / Binary Weave

Takuzu 二元逻辑填格。三张 4×4、6×6、8×8 织格只提供固定的 0/1 线索，分别保留 **10、23、38 个可填写格**。

完整图须同时满足：

- 每行和每列的 0、1 各占一半。
- 不能横向或纵向连续出现三个相同数字。
- 任意两行不能完全相同；任意两列也不能完全相同。行可以与列相同。

三连不绕边，斜线不参与规则。数字本身和不同纹色同时显示，辨认不依赖颜色；固定格带锁标记，不可修改。右侧显示光标所在行、列的当前 0/1 数量。

方向键逐格移动；A 循环 **空格→0→1→空格**。空格显示短横线。所有格填写后 B 手动检查，编辑期间不自动获胜。尚有空格时检查免费；完整但错误的检查记一次，无论发现多少处问题，三次失败。可无限修改，实际修改会清除旧错误标记。没有倒计时或移动额度。

测试专用求解器枚举合法行模式并结合列约束，证明三题各有唯一解；生产模型只保存公开线索并检查规则，接受任何合法完整图，不保存隐藏答案。测试还分别隔离数量、三连、重复的行列反例，并用普通按键完成三题、自然三错失败和两错后改正获胜。

键盘：方向键 / WASD；空格 / Z / Enter 循环格值；X / B 检查；P / Escape 暂停；R 重试。手机左摇杆选格，右上 A，右下 B。开始、恢复或输入取消后先松开，长按不重复。
