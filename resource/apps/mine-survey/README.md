# 雷纹勘探 / Mine Survey

三道固定的 6×6 扫雷推理题，分别有 5、6、7 枚雷。开始时已有一片安全区域打开，数字表示周围八个格子中的雷数。每关都可以仅凭公开数字和总雷数完成，不需要猜测。

| 操作 | 动作 |
| --- | --- |
| 方向键 / WASD / 手机方向区 | 移动勘探光标 |
| A：空格 / Z / 确认 / 手机右上 | 探开未插旗的隐藏格 |
| B：X / B / 手机右下 | 插旗或收旗 |
| P / Escape / START | 暂停／继续 |
| R / SELECT | 重新开始本关 |

数字同时计算横、竖和斜方向的八个邻格。小圆点代表数字零：周围没有雷，会自动扩展到相连的零格及其数字边界。旗标保护的格子不会被自动或手动打开，须先按 B 收旗。

**旗标只是你的判断，不会验证该格是否有雷。** 旗数最多等于该关总雷数。只要探开全部安全格即可获胜，旗不必插完；错插在安全格上的旗会阻止该格被探开，需要收回。

初始安全区已经代你完成安全开局，后续点击雷会立即失败，没有再次免疫或自动搬雷。失败时显示全部雷位；未触雷前，界面与公开快照只包含已经看见的数字。没有倒计时或操作次数惩罚。长按不连动，每次操作后先松开再按。

| 勘探区 | 雷数 | 初始已探安全格 | 初始仍待探安全格 |
| --- | ---: | ---: | ---: |
| 铜丘台地 | 5 | 17 | 14 |
| 溪岸旧矿 | 6 | 9 | 21 |
| 玄岩坡地 | 7 | 8 | 21 |

精确规则、公开信息边界与输入约定见 [模型契约](docs/model-contract.md)。规则测试通过可见邻接约束、总雷数和约束集合差求解，测试策略不读取生产私有雷位。游戏资产没有求解器；私有棋盘绑定在模型闭包的 WeakMap 中，不放入配置、游玩状态或快照。
