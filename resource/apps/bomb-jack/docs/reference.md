# 炸弹杰克 TV：规则依据与重写边界

本项目选择 **1986 年 NES / Famicom《Mighty Bomb Jack》**，不是 1984 年单屏街机《Bomb Jack》。代码、地图、像素画、图标和音乐为独立重写；不包含 ROM、原作代码、拆包贴图或原声。APK 名为 BOMB JACK TV。

## 核对来源

- [Mighty Bomb Jack — Wikipedia](https://en.wikipedia.org/wiki/Mighty_Bomb_Jack)：16 个金字塔阶段；行动区和 Royal Palace；Mighty Coin 颜色能力；Mighty Drink 加时；Sphinx 秘密通道；贪心惩罚房；Pamera 王室及 Belzebut。
- [Mighty Bomb Jack — Video Game Den](http://www.videogameden.com/nes.htm?mbj)：NES 版本的房间探索和高跳设计参考。上面百科条目亦引用该版本资料。
- [Mighty Bomb Jack — StrategyWiki](https://strategywiki.org/wiki/Mighty_Bomb_Jack)：游戏版本与规则交叉索引。当前构建环境无法访问其完整玩法子页，未把未核实的逐帧数值、原关卡坐标或隐藏结局当作已复现内容。

## 本实现提供的完整流程

16 个独立绘制的行动区，各有自己的宽高、台阶组合、敌人路线与宝箱摆放；每关进入一间具有 24 枚炸弹的 Royal Palace，全部收集后从右门进入下一关。第 16 关后解救王室并进入结局。行动区包含横向长廊、双柱、纵井、阶梯、水道、塔楼等不同空间结构。地图属于重建作品，**不是原作地图逐格复制**。

每关行动区的钥匙箱须从上方落下开启；第 3 关起钥匙位于上层台阶，需要探索后返回地面出口。按 ↑ 进入已经打开的门。宝箱内还有 Mighty Coin、加时饮料、分数袋，以及打开 Sphinx 秘密房的奖励。秘密房离开后保留原房已开启的箱子，不能反复刷新奖励。

- A：跳跃；↑ + A：高跳；↓ + A：小跳；空中松开后再次按 A：立即制动跳跃，再按住 A 缓降。方向键可以在空中修正位置。悬停时展开披风提供状态反馈。
- 木乃伊先沿地面巡逻，经过闪光预警后变成蝙蝠、飞鸟或火焰追击；蝙蝠分段锁定目标，飞鸟和火焰持续追踪，形态与阶段相关。变身延迟、速度和加速度为独立调校值，未声称复刻原作逐帧 AI。绿色能力仍可把变身后的敌人转为硬币。
- B：消耗一枚 Mighty Coin 逐级变为蓝、橙、绿。蓝色允许打开橙色宝箱；橙色允许从侧面接触开箱；绿色把当前房间敌人变成硬币，持续 5 秒。蓝/橙的 20 秒有效期为本重写的平衡值。
- 普通炸弹 100 分；拾取后点亮下一颗。连续拾取燃烧炸弹增加奖励，完成一整房再结算连奖。这里的分数曲线为本实现设计，未声称复制原作所有燃烧顺序捷径及隐藏奖励。
- 加时饮料 +10 秒。持有超过 9 枚硬币或计时超过 99 秒进入惩罚房；跳满 12 次后重新开始当前行动区，硬币清零、计时恢复 60 秒。12 次为本实现的固定平衡数。
- 每 30,000 分奖励一条生命，最多 9 条；初始 3 条生命。碰到敌人或超时失命；每次失命当前阶段从行动区重试。
- START 开始/暂停。SELECT 在标题选择 1P/2P，在暂停时切换音乐；电视侧也提供音乐按钮。

## 局域网扩展与运行兼容

两台手机采用**轮流挑战**，不是原作同时双人玩法。每名玩家有独立生命、积分和关卡；失命轮到另一名尚存活玩家。已完成全部关卡的玩家退出轮次，另一名可继续。当前操作者断线自动暂停；等待轮次的手机断线不影响当前游戏。重新连接当前手机继续，手动暂停保持手动暂停。

电视资源使用 ES2017/Chrome 61 可用语法与 Canvas/Web Audio。音效和循环曲为原创合成波形，并非原作配乐。渲染或资源失败时显示具体启动错误；房间玩家状态更新独立于渲染循环。退出/进入后台由 Android 壳停止 HTTP/WebSocket、释放唤醒锁、销毁 WebView 和进程，页面销毁还会清理动画、轮询与 AudioContext。

## 验证

`node --test resource/apps/bomb-jack/tests/model.test.cjs` 覆盖跳跃/缓降、台阶碰撞、箱子能力、燃烧顺序、秘密房防刷、贪心房、玩家轮换、断线、全部 16 关和地图可达性。浏览器兼容与真实画面由项目公共浏览器验证脚本完成。16 个行动区另外逐关从出生点使用真实方向/A/↑ 输入走跳至钥匙、落下开箱、返回地面出口进入宫殿；该回放只移除敌人以隔离地形，不修改角色坐标或速度。宫殿的受控通关状态断言用于验证出口条件，不等同于人工逐关完成测试。
