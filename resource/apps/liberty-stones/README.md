# 围子夺星 / Liberty Stones

在 5×5、6×6、7×7 的公开合法中盘上执黑，进行一场小棋盘提子竞赛。黑白双方都从零提子开始，谁先提满四枚对方棋子，谁就获胜；黑方最多分别有 10、12、14 手。这里按提子目标判定，不进行围棋数目或地域计分。

## 操作与气

- 方向键：移动金色方框，到棋盘边缘停止。
- A：落下一枚黑子。键盘空格、Z、Enter，遥控器确认，或手机右上区域。
- B：停一手。键盘 X，或手机右下区域。即使有合法落点也可以停手。
- P / Escape / START 暂停；R / SELECT 重试。

横竖相连的同色棋子组成一块，相邻空交点是这块棋的“气”；斜向不相连。同一个空点只算一口气。光标指着棋子时，青色圈标记其整块与全部实际气点，右侧显示块大小和气数。白子中央的珊瑚色小点标记对手刚落的一子。

落子后，先移除所有相邻且无气的对方棋块，再检查自己的棋块；自己的新棋块仍无气则不能落子。已经有棋子的位置不能再下。无效落子不消耗手数，也不会让白方行动。

采用**简单劫**：不能立即走出与上一手之前完全相同的棋盘。合法落子和停手都会更新这份前一手棋盘；不采用全局超级劫规则。

## 胜负与公开对手

你落子提满四子就立即获胜，最后允许的一手也有效，白方不会再回应。否则白方行动一次，若先提满四子则你失败。双方连续停手，或你的手数已经用完，仍未完成目标也失败。停手消耗一手，思考没有倒计时。

白方只看公开棋盘，枚举同样合法的落点，依次比较：本手提子数、落子后新棋块的气数、到棋盘中心的平方距离，最后按从上到下、从左到右的位置编号打破平手。只有没有合法落点时才停手。这是固定启发式对手，没有宣称完美棋力。

每个初始局面和劫历史都能由测试目录中的正常交替落子前序重建。独立求解测试证明三关不能在前三手获胜，且均有第四手获胜路线。前序证明和求解器不随游戏资产打包，生产资产只包含公开棋盘与规则。
