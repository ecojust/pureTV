# Queen Constellation art direction

Original navy and brass astronomical artwork frames a chess grid as a star chart. Ivory crowned queens use a separately painted sprite; fixed queens have a brass tint, permanent cell frame and lock icon. Forbidden cells use both hatching and a cross. The active cursor is represented by mint corner brackets, distinct from fixed-cell and conflict outlines.

The grid retains a constant384logical-pixel square across6/7/8 boards. Even the8×8 board has48pixel cells and legible queen silhouettes. Row/column labels, all text panels and command labels use at least24logical pixels. Pairwise attack links are red and connect only currently conflicting queens, behind the pieces. No solution path or future hint is drawn.

The right ledger shows exact queen totals, remaining checks, conflict pair counts and whether the player may submit a valid board. Current row/column and fixed/blocked/queen/empty cell status help inspect the smaller board. The legend names movable queens, fixed queens, blocked cells and attack lines. Instructions explicitly require manual B submission.

Four original atlas tiles (observatory, queen, lock and star seal) are painted once. All live grid content, attack lines and counts derive from current public model state. The matching64px SVG and Android vector are original queen/star emblems. No external imagery or third-party artwork is included.

Actual screenshot/recording review is documented separately; this design does not claim completed physical-device testing.
