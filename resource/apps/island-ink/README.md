# 岛海墨图 / Island Ink

Nurikabe 岛海涂格。三张 4×4、5×5、6×6 墨图只公开数字种子，没有预填海格；分别保留 13／20／30 个格子供判断。

完整墨图须同时满足：

- 每个正交连通的岛恰有一个数字，面积等于数字，数字格本身计入面积。
- 两个数字岛不能正交接触；斜角接触可以。
- 所有海格正交连成一片，而且至少有一个海格。斜角不构成连通。
- 任何位置都不能出现 2×2 全海。

方向键逐格移动，A 循环 **未定→海→岛→未定**，数字格固定为岛。问号、波纹、叶纹分别表示未定、海、岛，数字独立显示，识别不依赖颜色。

全部格子决定后按 B 检查。填图不扣错误次数，尚有未定格时检查也免费；完整但错误的提交记一次，无论发现多少处问题，三次错误失败。修改后清除旧错误标记，合法完整图只在按 B 后获胜。没有倒计时。

测试求解器只从公开数字出发枚举合法岛形，证明三题各有唯一解，并通过普通方向、A、B 输入通关。游戏接受任何满足公开规则的完整涂色，不与隐藏答案比较；答案与求解器不进入 APK。

键盘：方向键 / WASD；空格 / Z / Enter 标记；X / B 检查；P / Escape 暂停；R 重试。手机左摇杆选格，右上 A 标记，右下 B 检查。开始、恢复或输入取消后先松开；长按不重复。
