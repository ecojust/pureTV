# 夜桥接力美术与信息设计

夜蓝色河谷、弯月与低山衬托一座木板吊桥。左右岸采用不同位置的可数旅人，跨桥过程直接移动当前队伍与火把，人物尚未落岸时不会提前出现在目的岸。火把使用烘焙暖光和两层火焰形状，旅人有帽子、背包、外套与脚步轮廓。

旅人固定 ID 贯穿场景标号和底部名单。颜色只是辅助，名单明确显示 ID、逻辑分钟与 L/R 所在岸；过桥中的旅人显示方向箭头。金框表示光标，金色侧条表示已选中，两者可同时观察。六人名单占两行，每卡宽 274、高 46 逻辑像素，主文字 26。

右侧将 LOGICAL MINUTES / USED / LEFT 与 PARTY / COST 分开。计划阶段注明 PLANNING FREE；动画阶段注明 CROSSING 0.4S。底部 NO TIMER、中文操作和结算说明都强调逻辑分钟不随思考或动画流逝。只展示真实队伍成本，不展示最优答案。

自定义图集：nightSpan (0,0,640,384)，traveler (640,0,128,128)，torchLamp (768,0,128,128)，rosterCard (896,0,128,128)。避开公共 white/disc 和 ASCII 字符区域。无外部图片或字体，中文由公共 DOM 绘制。

实际 960×540 / 1280×720 预览及冻结源码资源核对由串行 QA 执行。本文不宣称已做美术验收、正式签名或实体设备性能测试。
