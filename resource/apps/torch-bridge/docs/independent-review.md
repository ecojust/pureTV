# 独立规则复核

依据公开旅客时间与火把规则，另写加权状态图和Dijkstra，独立得到三局最低花费17／29／35分钟、5／7／9次渡桥。15组检查通过，157次普通 `create/step` 渡桥逐次核对出发岸、0.4秒动画结算、最大旅客耗时、火把位置、收据及终局；未注入运行中状态。

额外两分钟正常往返能在19／31／37预算恰好获胜。另行搜索出全部到右岸却超时的20／32／44分钟路线，验证完成不覆盖预算失败；反复单人渡桥也自然验证仍有人在左岸时超时。空选择、超容量、错误岸选择和闲置计划不收费；取消输入继续动画，暂停冻结动画，落地后必须松开再操作。

浏览器将使用真实墙钟和普通键盘，模型的合法时间步实验不代表实体电视／手机执行。详细结果见 `independent-report.json`。
