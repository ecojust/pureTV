# Four in Row art direction

Original blue arena artwork uses recessed board holes, raised golden ring tokens for the player and teal cross tokens for the opponent. Glyphs distinguish the sides independently of color. Seven columns and six rows use64logical-pixel spacing, keeping the late-game board clear at both requested viewport sizes.

A translucent column band, top chevron and numbered label identify selection. An empty-hole arrow marks the actual lowest landing cell. Full columns turn the selection warning red without consuming turns. A coral square marks the most recent AI token; winning tokens receive brass squares. The right ledger identifies both sides, current column, last move coordinates and the last three paired turns, making the synchronous opponent response visible.

The game uses only current public state. There is no predicted winning-move overlay or hidden-solution display. All logical text is at least24pixels. The four original atlas tiles are the arena, ring token, cross token and recessed socket; no external art or third-party resource is used. Matching SVG and Android icons are decorative ring/cross board emblems.

Screenshots and actual input recording need separate review; this design does not claim physical-device validation.
