# 四子列阵 / Four in Row

从三张公开的残局开始，在7列、6行的棋盘上与对手轮流落子。你使用金色圆环，对手使用青色叉形。棋子会落到该列最低的空位；先把自己的棋子横、竖或斜向连成四子即可获胜。

| 残局 | 开始时的空格 | 已有双方棋子 |
| --- | --- | --- |
| 港湾残局 | 10 | 各16枚 |
| 交错残局 | 12 | 各15枚 |
| 深叉残局 | 14 | 各14枚 |

三个棋盘都能由正常交替落子抵达，开局没有任何一方已经连成四子，均由你先走。它们不是隐藏答案摆放题；目标是在实际对弈中取得胜利。

## 操作

- 左 / 右：选择一列，到两端停止。
- A：落下一枚棋子。键盘空格、Z、Enter，遥控器确认，或手机右侧整个三分之一区域。
- P / Escape / START 暂停；R / SELECT 重新开始。

方向上／下与 B 不执行动作。每次落子后松开再按，长按不会连续走多步。选到满列不会落子，也不会让对手获得一次行动。

对手在你成功落子后立即回应。红色方框标记它最新放下的棋子，右侧记录双方刚才的落子列。棋盘内浅色箭头显示所选列的实际落点。你已经连成四子时直接获胜，对手不会再回应。

棋盘填满但无人获胜会和棋；本游戏的任务是取得胜利，因此和棋需要重试。

## 公开的对手规则

对手先选择立即获胜的一步，再阻挡你的立即获胜机会；否则进行固定深度的局面评估。所有决策只看公开棋盘，使用稳定的列优先级，不随机出手，也不读取隐藏答案。精确的三层评估、权重与平局优先级均写在 [模型契约](docs/model-contract.md)，没有宣称它是最强或完美对手。

测试会独立复现公开规则，验证三个残局的正常胜利和失败路线；求解器和初始局面的合法落子证明只存在于测试目录，不随游戏打包。浏览器操作和软件渲染不等同于实体电视、手机或模拟器测试。代码和原创棋盘／棋子素材采用 [MIT 许可证](LICENSE)。
