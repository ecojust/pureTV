# Packing Sculptor — public interface and evidence

This public specification precedes implementation or execution. [Public design](public-design.md) contains all pieces/tasks/extraction geometry; [model contract](model-contract.md) defines exact state and commands. There is no execution, performance or publication claim here.

## Shared host and controls

Use the unchanged shared runtime's create(seed,level), step(state,1/60,input), GameDef render/HUD/menu/pause/results and PureTVQA.snapshot. GameDef id=`packing-sculptor`, seed746, holdConfirmAsAtrue; game.json actions2. Phone right third is the full upper-A/lower-B surface, midpoint in B, with user-select/touch-callout suppression from shared controller. Chinese labels are `选取 / 落定 / 验收` and `取回 / 旋转 / 清空`; precise contextual actions are continuously shown on TV.

Rack navigation is bounded0..pieceCount with CHECK last: Up/Left previous, Down/Right next. In place mode, directions move the normalized bounding-box anchor, A places or cancels on the visible rightmost BACK strip, B rotates. B is never an implicit cancel in place mode. A failed preview commit is blocked without spending a submission; a legal commit may still block extraction until another edit. Rack B retrieves a piece; CHECK/B clears while preserving failure history. These meanings must be visible when mode changes. Pause/retry remain independent host actions, never hidden edit commands.

On start/resume, blur/hidden, input cancellation, disconnect/reconnect and source-session replacement, shared host quarantines stale held A/B/confirm until actual local keyup or raw remote false. Missing/cancelled neutral does not prove physical release. Model then needs a noncancelled full-neutral sample. Fresh-edge priority B>A>direction consumes other rises without queueing; holding does not repeat. Verify simultaneous A/B at CHECK, held Enter on menu transition, and cancelled held rotation/place. Host pause normally stops calls; admitted cancellation still consumes informational elapsed time. There is no timeout.

`PureTVQA.snapshot()` exposes the actual deep-copied wrapper `{id,phase,paused,tick,elapsed,level,best,model,renderer,frameTimesMs,connection}`. Model includes visible fixed container/piece IDs, actual placements, active preview, rack index, inventory, exact current geometry/exit verdicts, bounded receipts and input gates. `PureGame.key(name,down)` supplies ordinary held keyboard input. Neither API provides arbitrary state assignment, alternate origins, solution loading or a solver. Read-only renderer must not inspect pilot/QA private storage.

## Rendering the actual packing

Use one isotropic mapping from integer polygon coordinates into a large main box. `geometry.pieces` contains only actual committed polygons; `previewCheck` is a separate proposed pose. Do not let a preview spend inventory, erase the old pose, imply an accepted result or alter extraction obstacles. When editing an already placed piece, draw its old footprint as a labeled dim outline and the candidate as a translucent full polygon; other pieces remain solid. The active anchor is the top-left of the rotated normalized bounding box. Draw this exact anchor marker and turn0..3, not the center of a piece.

Render filled polygon unions and their true notches. A piece's bounding rectangle may contain empty cells and is not its solid silhouette. Show the floor rows and all notch walls; doors are finite open segments on the exact named bounding face, with distinct jamb marks, outward direction arrows and piece ID labels. The door endpoints and width must visually agree with public coordinates. A required exit status comes from its current geometry.extractions entry: UNPLACED/CLEAR/BLOCKED. A sweep overlay, if shown, uses the exact sweptRects, visibly extending through the specified mouth. Do not visualize a path that turns, rotates or removes another piece.

Rack cards list only actual task pieces in exact rack order, with their silhouettes, names/IDs, in-rack/placed status and required exit stamp. CHECK follows last. Every placed piece and opening is discernible without color alone. In place mode keep the BACK strip visible at x=W across the entire box height; its distinct styling must prevent confusion with a legal floor cell or east door. It is reachable from any preview by repeated right presses and reversible by left. At x=W show `A BACK`; elsewhere show `A PLACE` and valid/blocked state. B remains `TURN` throughout place mode.

Show placedCount/total, remaining rejection allowance, selected piece/turn, mode and all required exit statuses. During preview, display outside/overlap errors separately from extraction blockage: outside/overlap prevents committing, while a blocked exit prevents CHECK acceptance. CLEAR is not retry and never refunds failures. Exact contact is allowed; tiny antialiasing fringes do not move the integer snap grid.

Art direction is polished original packing-bench scenery with bevels, fasteners, machined surfaces and etched labels. Bake the six piece silhouettes and restrained highlights/shadows plus trim into one local atlas, then use the shared batched renderer. Avoid per-frame canvas textures, many material switches, or automatic pixel-art styling. Essential ASCII canvas labels≥24 logical pixels; Chinese instructions/results in DOM. Preserve genuine shared blurred menu/pause/results. Review full original960×540 and1280×720 screenshots for all text, piece vertices, door spans and BACK usability. Measure actual WebGL submissions and observer intervals; export FPS and software-browser RAF timing are not TV hardware performance.

## Ordinary visible-observation play

A normal pilot may use only the currently displayed box rows, shape silhouettes/cells, named doors/directions, actual placements, preview, focus/mode and current inside/overlap/exit feedback. It can reason geometrically about those public shapes and present free space, as a player can, including testing candidate local placement overlap or a straight corridor against the CURRENT observed board using independently written public-rule arithmetic. It must not import production model/helpers, call future step/create, read solved placement vectors, load a prepared route, replace state, or use a privileged fixture to win. No exhaustive future board/action-tree simulation or precomputed solved configuration is part of ordinary gameplay.

Choose a currently visible piece and a geometrically sensible free pocket while respecting visible reserved exit corridors. Navigate rack, pick, move/rotate one actual edge at a time, release and observe again. After committing, use new current feedback to decide the next edit; blocked previews or routes can be corrected through ordinary controls. If the observed rule differs from the public geometry, retain the failed attempt rather than forcing success. Mathematical feasibility reasoning is not an observed action trace. The public specification supplies no canonical target arrangement for the pilot to copy.

Natural loss starts from a fresh empty rack, navigates to CHECK and performs four real A press/release submissions. Missing pieces always reject. Success recordings should show task selection, the initially empty box, visible shape movement/quarter turns, genuine committed placement, at least one demonstrated exit comparison, accepted CHECK and actual result. Aim for30–90seconds of ordinary play, without fabricated intermediate states, title-slide padding or replay substitution. No human-play duration is guaranteed before actual recording.
