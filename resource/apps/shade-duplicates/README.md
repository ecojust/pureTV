# 去重留白 / Shade Duplicates

一款采用标准 Hitori 规则的数字涂黑谜题。三张数字盘为 4×4、5×5、6×6；只需决定哪些格子涂黑，所有原始数字始终可见。

一张完成的棋盘需要同时满足：

1. 每一行、每一列的**白格**数字都不重复。位于不同的行和列的相同数字可以保留。
2. 黑格不能上下左右相邻；斜向接触允许。
3. 所有白格必须横竖连成一个非空区域；仅斜向接触不算相连。

## 操作与检查

- 方向键：选择数字格，到边缘停止。
- A：在白格和黑格之间切换。键盘空格、Z、Enter，遥控器确认，或手机右上区域。
- B：手动检查整盘。键盘 X，或手机右下区域。
- P / Escape / START 暂停；R / SELECT 重试。

涂黑次数没有限制，思考没有倒计时。黑格用斜纹与深色底区分，原数字仍以浅色显示，随时可恢复为白格。金框标记当前格；白格红字表示所在行或列还有重复。

右侧分别列出重复数字组、相邻黑格对和白格区域数。若白格分成多块，光标所在白块用浅青色辅助标记，方便检查连通关系。相邻黑格的共边有短红标记。

满足规则不会自动结束，仍须按 B 确认。每次错误检查消耗一次试错机会，棋盘不会被清空；第三次错误结束本局。只剩一次机会时提交正确棋盘仍能获胜。

## 公开数据与验证

三盘均由独立约束搜索验证为唯一解。游戏运行时只检查上述三条规则，不保存答案掩码，也不按预设涂黑数量判定。初始盘都为白格。

4×4 棋盘在标准规则下最多只能有五个黑格，完整 65,536 种形状枚举与生成取舍记录在 [棋盘生成说明](docs/authoring.md)。后续尺寸保留更多推理空间；没有为增加黑格数量放宽规则。
