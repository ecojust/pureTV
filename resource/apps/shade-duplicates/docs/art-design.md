# 去重留白美术与信息设计

画面是一张放在浅蓝校样桌上的数字样张，配深蓝检查栏。背景烘焙细线纹理、纸张阴影和两条纸胶带；白格有轻微纸纹，黑格有清晰的斜线排纹。每个格子的原数字始终保留，黑底用浅色数字，白底用深色或重复警示色。

4／5／6 路分别采用86／72／60逻辑像素格距，数字字号40／36／34。即使涂黑，数字大小不变。金色双线方框表示光标；白格多个连通区时，当前白区以浅青底和细框区别。相邻黑格的共边加短红线，重复数字格用红色字，右侧同时用可读计数表达三条约束，颜色不是唯一信息渠道。

界面只展示当前棋盘事实，不展示唯一解、期望黑格数量或下一步答案。READY: B CHECK 明确表示仍须手动提交。CHECKS LEFT 是可失败检查数，切换格子不消耗它。

图集区域：proofDesk (0,0,640,384)，whiteSquare (640,0,128,128)，blackSquare (768,0,128,128)，checkSeal (896,0,128,128)。避开公共图形及 ASCII 字符区。最小画布标签24逻辑像素，中文由公共 DOM 绘制，无外部图片和字体。
