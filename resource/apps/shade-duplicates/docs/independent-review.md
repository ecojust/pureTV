# 独立规则复核

依据公开数字逐行枚举全部不相邻黑格掩码，检查每行白数唯一，再逐列排除重复、逐行排除上下黑格相邻，最后独立洪水填充核对非空白格连通。没有黑格数量限制或答案输入。三局分别搜索11／70／181节点，最终严格只有1个解，黑格数量5／7／10。

16组普通模型检查通过，71次真实A切换、25次B检查。普通输入验证三关完整解在提交前仍为playing，首次有效提交及只剩一次失败机会时均获胜；三次无效提交自然失败。还实际切换出相邻黑格、无黑格相邻但有白色孤岛、全黑无白格等状态，逐项对照全部违规列表和白格计数。

最初希望每局至少6黑格，但4×4在标准“不相邻黑格＋白格连通”下最多5黑格。独立位运算枚举全部65,536个掩码，按黑格数0–5的合法数量为1／16／92／224／193／36，没有6格以上；见 `geometry-bound-independent.json`。按主agent已确定的调整保留4×4／5×5／6×6和标准规则，第一局使用5黑格。

详细模型证据见 `independent-report.json`。浏览器与实际录像另行验收，不声称实体电视／手机测试。
