# 独立规则复核

依据公开边编号、四边围格及对手优先规则，另写纯测试参考。15组通过，482次普通 `create/step` 回合核对棋边、归属、得分、剩余边、完整AI连走和终局收据；没有向运行中状态写入测试局面。三局各找到正常胜利和自然失败路线，胜利分别用6／9／9次玩家画边，未宣称最短。

重建初始合法历史时保留围格继续行动规则，确认交回玩家。实际检查覆盖163次玩家围格继续行动、37次AI一次围两格、最长7边AI连走，以及951次贪心围格、60次被迫第三边和10次安全边选择。未在这些普通样本中观察到玩家一次围两格；双格几何由真实AI双格完成核对。详见 `independent-report.json`。
