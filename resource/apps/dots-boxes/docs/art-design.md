# 点线围格美术与信息设计

画面是一册摊开的方格手账：奶油色纸面、细灰绿格线、左侧装订孔与页中折痕。原创图集烘焙纸张、圆点以及两种印记；运行时只画当前真实边线、归属与预览，不提供答案路线。

珊瑚色圆环代表玩家，青色叉形代表对手，同时用颜色与形状编码。边线颜色记录画线者；格内印记记录完成该格的人，两者语义不同并在 README 说明。尚未画的边是灰色虚线，选中边用金色粗底加虚线覆盖，非法边用红色。金色圆点圈标记锚点，箭头区分向右／向下，右侧始终显示圆点行列、方向和边状态。

3×3 盘使用 100 逻辑像素格距，较高的两盘使用 84 格距；最长网格高度 336。数字和英文标签至少 24 逻辑像素。所有归属印记位于格中心，边与圆点位于格界；越界预览只有 32 像素，仍留在纸张内。比分、剩余边数、最近行动所得方格放在独立账栏。

Atlas 区域：graphBook (0,0,640,384)，circleStamp (640,0,128,128)，crossStamp (768,0,128,128)，graphDot (896,0,128,128)。避开公共 white/disc 与 ASCII 字符区域。无外部素材或远程字体。中文界面由公共 DOM 绘制，Canvas 只用 ASCII。

实际 960×540 / 1280×720 预览和源码哈希核对由串行 QA 执行；本文不宣称截图已验收、已签名或实体设备性能。
