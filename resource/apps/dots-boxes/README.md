# 点线围格 / Dots and Boxes

用一条条边线围住方格，与公开规则的对手争夺更多区域。你拥有的方格盖上珊瑚色圆环，对手的方格盖上青色叉形；线条颜色表示谁画了那条边，方格内的印记表示最终归属。

三张残局分别有 3×3、3×4、4×4 个方格，剩余 10、12、14 条未画边线。初始比分为 2∶0、2∶3、2∶4，均轮到你行动。每张局面都能由正常轮流落笔抵达，之前围成方格后获得的连续行动也遵守同一规则。

## 操作与胜负

- 方向键：移动金色圆点，在边界停止。
- A：切换向右的横线／向下的竖线。键盘空格、Z、Enter，遥控器确认，或手机右上区域。
- B：画出当前预览边。键盘 X，或手机右下区域。
- P / Escape / START 暂停；R / SELECT 重试。

金色虚线预览是将要画的边；红色表示越界或已经画过。无效画线不消耗回合。每次动作后松开再按，长按不会连续画线。

完成一个或两个方格，就把这些方格全部收入自己名下，并继续行动；没有围成方格，才轮到对手。对手也享有相同的连续行动规则，因此可能一次画出多条边。右侧显示它上一次连续行动的画线数与所得方格，棋盘上的浅色细线标出它最后画的边。

所有边画完才结算。你的方格严格多于对手才获胜；平分和较少都需要重试。提前取得多数也仍需完成剩余边线。

## 公开的对手规则

对手优先画出能立即完成最多方格的边；否则尽量避免给任何方格留下第三条边。如果没有安全边，就画最先的一条。所有平手按固定边编号处理：先按行枚举横线，再按行枚举竖线。每次连续行动都会重新判断；对手没有隐藏信息、随机选择或答案表。

精确的边编号、输入与状态接口见 [模型契约](docs/model-contract.md)。测试会独立计算公开策略、核对初始局面的合法前序，并通过正常控制证明三关胜负路线。求解器及前序证明仅在测试目录，不随游戏资产打包。
