# 翻面棋局美术组织

纸色背景、深绿棋盘和象牙白／碧绿两种棋子构成植物主题。棋子分别刻有单叶和分枝线纹，颜色之外仍可区分。所有图形在每款游戏的图集中由代码一次性绘制；运行时使用同一纹理批次。

逻辑画布960×540。左侧6×6棋盘每格64，外侧有A–F／1–6坐标；合法空格显示1–36行优先编号，右侧重复显示当前光标坐标与编号。黄色矩形表示光标，浅蓝框表示电脑上一手，金点表示玩家上一手。右侧使用大号棋子和数量对比，单独显示让行要求、剩余空格及双方让行次数。棋盘状态全部来自真实模型，不画预定答案。

正文通过公共DOM层显示中文；图集仅用ASCII标签。有效边界和数字标记由模型计算，美术不参与胜负判定。尚需依据最终浏览器截图确认低分辨率文字完整可见；本文件不宣称已完成目视或实体设备验证。
