# 翻面棋局 / Reversi Relay

三道 **6×6 翻面棋残局**，分别从剩余 8、9、10 个空格的公开棋盘开始。你执象牙白棋，与碧绿棋对手轮流落子；这是残局策略题，不是从标准开局开始的完整对局。

在空格落子，沿横、竖、斜八个方向，用新棋子和已有白棋夹住连续绿棋，所有被夹住的棋子一起翻成白棋。至少翻一枚才能落子。绿棋随后自动选择翻子最多的合法位置，数量相同时按 A1 到 F6 的行优先顺序选择；对手规则完全公开，不会随机改变。

| 操作 | 动作 |
| --- | --- |
| 方向键 / WASD / 手机方向区 | 移动黄色光标，一按一格，不跨越棋盘边缘 |
| A：空格 / Z / 确认 / 手机右上 | 在光标处落下白棋 |
| B：X / B / 手机右下 | 仅在白棋没有合法落点时让行 |
| P / Escape / START | 暂停／继续 |
| R / SELECT | 重新开始当前残局 |

数字标记是当前合法空格的编号，左到右、上到下为 1–36；右侧同时显示光标坐标。浅蓝框标记绿棋上一手，小金点标记白棋上一手。非法落子和仍能落子时按 B 都不消耗回合。绿棋无棋可下时自动让行；白棋无棋可下则需要按 B。长按不连动，恢复后先松开控制。

棋盘填满或双方都没有合法位置时结束。白棋数量更多才获胜；少于绿棋或和棋需要重试。没有倒计时、随机惩罚或隐藏目标步序，任何合法的获胜路线均有效。

- 角隅新叶：8 个空格，争取角落带来的稳定收益。
- 边线交织：9 个空格，观察让行和边线翻转。
- 蕨冠回合：10 个空格，避免只看眼前翻子数量。

精确棋盘、夹击规则、电脑决策、输入行为和验证边界见 [公开模型契约](docs/model-contract.md)。全部图形为代码绘制的原创棋盘与棋子纹样。按仓库 [MIT 许可证](LICENSE) 提供。
