# 手机证书设置 / Phone certificate setup

[返回游戏说明](../README.md) · [English](#english)

0.1.2 的手柄由电视 APK 在局域网内提供，不需要公网域名或互联网。虚拟摇杆可以直接使用；陀螺仪需要先让手机信任这台电视的 HTTPS 证书，再单独授予浏览器运动传感器权限。这两种权限不是同一件事。

本指南对应源码目标版本；实际下载包的版本及验证结果见 [resource.json](../resource.json)。Android 厂商系统、浏览器和 iOS Safari 的完整流程仍需实机验证。

## 首次连接

1. 手机和电视连接自己可信的同一局域网，在电视上启动游戏，扫描「首次连接」二维码。
2. 在手机手柄中点「陀螺仪」，打开「首次连接陀螺仪手柄」引导。此时手柄会释放已按住的转向和踏板。
3. 通过系统证书详情或可信证书查看器，核对**下载证书本身**的完整 SHA-256 指纹与电视上「核对电视证书」显示的指纹一致。HTTP 引导页中的摘要仅供对照，不能独立证明下载证书的身份。证书详情入口因系统而异；无法确认来源时先继续使用摇杆。电视上按返回键可用较大字号查看完整证书指纹，核对后选择「取消」返回游戏。
4. 按下面对应系统的步骤安装并信任证书，再回到引导点击「已信任，进入安全手柄」。
5. 在 HTTPS 手柄中点击「陀螺仪」，按浏览器提示允许运动权限。舒适横握、稍立起手机并校准中立；随时可选「虚拟摇杆」切换回来。

证书属于系统级信任，可能供手机上的浏览器及遵循系统信任设置的应用使用。仅安装自己电视生成且来源已确认的证书。下载描述文件只包含这台电视的公开根证书，不包含电视私钥，也不会注册设备管理服务。网页无法自动安装或信任证书；在浏览器证书警告中点击「继续访问」不能代替这些步骤，也不能保证运动传感器可用。

### Android

1. 点击「Android：下载 CA 证书」，保存证书文件。
2. 在系统设置中搜索「安装证书」「CA 证书」或「凭据」。通常位于安全、隐私或更多安全设置中；菜单随厂商和 Android 版本不同。
3. 选择安装 **CA 证书**，按系统提示验证锁屏身份并选择刚下载的文件。不要把它当作 Wi-Fi 用户证书或 VPN 客户端证书安装。
4. 返回手柄并打开安全手柄入口。若浏览器仍报告证书不受信任，检查该浏览器是否使用系统用户 CA，以及证书指纹是否与当前电视一致。

### iPhone / iPad

1. 点击「iPhone：下载证书描述文件」，允许下载。
2. 打开系统设置中的「已下载描述文件」，或「通用 → VPN 与设备管理」，查看并安装这台电视的证书描述文件；具体入口随系统版本不同。
3. 再打开「设置 → 通用 → 关于本机 → 证书信任设置」，在「针对根证书启用完全信任」中启用该电视证书。仅安装描述文件不会自动获得 SSL 信任。
4. 返回安全手柄，点击「陀螺仪」并允许浏览器访问运动与方向传感器。

Apple 的[官方证书信任说明](https://support.apple.com/zh-cn/102390)解释了安装描述文件与开启完整信任的区别。

## 后续连接与重新配对

- 这台电视的 CA 未改变时，后续通常可以直接扫描电视上的「已信任证书」二维码，进入 HTTPS 手柄；运动权限是否需要再次确认由浏览器决定。
- 电视内网 IP 变化时，应扫描新二维码。游戏会在原 CA 下更新服务器证书，通常无需重新安装根证书。
- 清除电视应用数据、卸载重装或重建证书身份可能改变 CA。以电视当前显示的指纹为准，移除不再使用的旧证书，再按首次连接步骤配对。
- 若证书仍报错，确认手机和电视日期正确、手机与电视在同一网络、使用当前二维码，而非旧的书签或截图。若系统提示证书日期无效，先校准手机与电视时间；如果 CA 是在错误日期生成的，再按返回键选择「重新配对手机」，重新安装并信任新 CA，不要反复信任旧证书。HTTPS 未成功连接前，不能宣称陀螺仪已经可用；可返回 HTTP 手柄使用虚拟摇杆。
- 两位玩家分别在自己的手机完成设置，各自选择转向方式。游戏输入直接通过局域网 WSS 到达电视，不依赖另一张后台网页或公网中继。

## 修复电视证书身份

证书损坏、过期或本机密钥异常时，游戏不会静默把已信任的 CA 换成另一个。先确认电视与手机的日期正确；如果首次生成证书时电视日期错误，仅修正日期可能还不够，需要明确重置证书身份。

1. 在电视上按返回键，在退出对话框选择「重新配对手机」。
2. 阅读「重新配对所有手机？」确认框。确认会**结束当前比赛、断开所有 HTTP/HTTPS 手机连接，并生成新的电视证书**；游戏本地记录保留。取消会保留当前房间和原证书。
3. 确认重置成功后，手机移除不再使用的旧证书，再扫描电视的「首次连接」二维码，核对新指纹并重新安装、信任。
4. 如果电视提示重置失败，可使用 HTTP 虚拟摇杆；排查电视日期、存储或密钥服务问题后，再手动尝试。不要将显示失败的 HTTPS 入口当作已完成配对。

## 移除信任

不再使用这台电视时，可以移除它的证书。先核对证书名称或指纹，避免删除其他用途的凭据。

- **Android**：在系统设置的用户凭据、用户证书或受信任凭据的用户部分找到对应 CA，删除它；入口因系统而异。
- **iPhone / iPad**：可在证书信任设置中关闭该 CA 的完整信任，并在「通用 → VPN 与设备管理」中移除对应证书描述文件。

移除后虚拟摇杆仍可使用，陀螺仪的 HTTPS 手柄需要重新建立信任。

## English

[Back to the game](../README.en.md)

The 0.1.2 controller is served by the TV APK on the LAN. It needs no public domain or internet connection. The virtual stick works immediately. Gyroscope steering needs two separate steps: trust this TV’s HTTPS certificate in the phone’s system, then grant the browser motion access.

This guide describes the source target version. See [resource.json](../resource.json) for the downloadable package and its verification status. The complete process still requires physical-device testing on Android browsers and iOS Safari.

### First connection

1. Connect the phone and TV to your own trusted LAN, launch the game, and scan the TV’s First connection QR code.
2. Choose Gyroscope on the phone to open the first-connection guide. Held steering and pedals are released while setting up.
3. Use system certificate details or a trusted certificate viewer to compare the full SHA-256 fingerprint of the **downloaded certificate itself** with the TV’s Check TV certificate panel. The HTTP guide’s displayed summary is only a reference and cannot independently authenticate the downloaded file. Certificate details are presented differently by each phone system; continue with the virtual stick if you cannot establish the certificate’s origin. Press Back on the TV to view the full certificate fingerprint in larger text, then choose Cancel to return to the game.
4. Install and trust the certificate using the relevant instructions below, then return to the guide and open the secure controller.
5. On the HTTPS controller, choose Gyroscope and grant motion access. Hold the phone horizontally and slightly upright to calibrate center. Choose Virtual stick whenever you want touch steering again.

A CA certificate creates system-level trust that browsers and other apps following system trust settings may use. Install only the certificate generated by your own TV after checking its origin. The downloaded profile contains only this TV’s public root certificate: it contains no private key and does not enroll the phone in device management. A website cannot install or trust it automatically. Proceeding past a certificate warning is not a substitute for system trust and does not guarantee sensor access.

### Android setup

1. Download the CA certificate using the Android button in the guide.
2. Search system settings for “Install a certificate,” “CA certificate,” or “Credentials.” It is often under security, privacy or additional security settings; menus vary by manufacturer and Android version.
3. Choose the **CA certificate** installation option, authenticate with the phone’s lock-screen method if requested, and select the downloaded file. Do not install it as a Wi-Fi user certificate or VPN client certificate.
4. Return to the guide and open the secure controller. If the browser still reports an untrusted certificate, check whether it uses user-installed system CAs and whether the installed fingerprint matches the current TV.

### iPhone / iPad setup

1. Use the iPhone certificate-profile download button and allow the download.
2. Open Profile Downloaded in Settings, or General → VPN & Device Management, and inspect/install the TV’s certificate profile. The entry depends on the system version.
3. Open Settings → General → About → Certificate Trust Settings and enable full trust for the TV’s root certificate. Installing the profile alone does not automatically establish SSL trust.
4. Return to the secure controller, choose Gyroscope, and allow motion and orientation access when requested.

Apple’s [certificate trust instructions](https://support.apple.com/en-us/102390) explain profile installation and the separate full-trust setting.

### Later connections and pairing again

- While the TV’s CA stays the same, a phone normally needs installation only once. Scan the Certificate trusted QR code for direct HTTPS access. The browser decides whether motion permission must be requested again.
- When the TV’s LAN IP changes, scan its current QR code. The game reissues the server certificate under the same CA, so the root certificate normally does not need reinstalling.
- Clearing app data, reinstalling the TV app or rebuilding its certificate identity may change the CA. Use the fingerprint currently shown on the TV, remove old certificates no longer in use, and pair again.
- For certificate errors, check both devices’ date/time, their LAN connection and the current QR code. Avoid old bookmarks or QR screenshots. If the system reports invalid certificate dates, correct both clocks first; if the CA was generated with an incorrect clock, press Back on the TV, choose Pair phones again, and install/trust the new CA instead of repeatedly trusting the old certificate. Gyroscope access is not established until HTTPS works; the HTTP controller remains available for the virtual stick.
- Two players set up their own phones and choose modes independently. Input goes directly to the TV through LAN WSS, without a second background browser page or public relay.

### Repairing the TV identity

The game does not silently replace an already trusted CA when its certificate is damaged, expired or inconsistent with the local key. First check both devices’ date/time. If the TV’s clock was wrong when the certificate was created, correcting the clock alone may not repair the saved identity.

1. Press Back on the TV and choose Pair phones again in the exit dialog.
2. Read the Pair all phones again? confirmation. Confirming **ends the current race, disconnects every HTTP/HTTPS phone and generates a new TV certificate**, while preserving local game records. Cancel keeps the current room and certificate.
3. After the TV reports success, remove the old certificate if no longer needed. Scan First connection, verify the new fingerprint, and install/trust the new certificate on each phone.
4. If reset fails, use the HTTP virtual stick. Check the TV’s clock, storage or key-service issue before manually trying again. An HTTPS entry showing an error is not a completed pairing.

### Removing trust

When you stop using a TV, remove its certificate after checking the name or fingerprint so you do not delete unrelated credentials.

- **Android:** find the CA under user credentials, user certificates or the user section of trusted credentials and delete it. The path varies by system.
- **iPhone / iPad:** disable full trust for that CA in Certificate Trust Settings, then remove its certificate profile under General → VPN & Device Management.

The HTTP virtual stick remains usable after removal. Gyroscope access through the HTTPS controller requires trust to be established again.
