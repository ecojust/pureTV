# 极品二手车：设计与物理说明

## 比赛结构

每场固定六个车位，支持一至两名真人，其余为电脑车手。玩家先在检车台阅读随机车型、动力和车况，再进入赛道。相同随机种子用于复现模型测试；正式游玩产生新的抽取结果。

车辆造型、赛道、品牌呈现和音效均为原创。六类车身分别对应紧凑车、轿车、跑车、旅行车、肌肉车和拉力车，不使用真实车厂标识。三条道路使用同一米制中心线数据供动力学、AI 路径和三维路面绘制，减少画面与物理边界不一致。

## 输入与虚拟力

手机转向区域提供连续的 -1 至 +1 输入；油门和刹车采用大面积触区。赛中 SELECT 短按切换追车／引擎盖镜头；低于 1.2 m/s 时长按约 0.8 秒切换 D/R，再通过油门驱动。刹车按住后模拟踏板力逐步上升，释放时快速回落。普通手机触摸输入不提供可靠的真实力值，因此 N 是游戏中的虚拟力单位。

脆弱刹车踏板的断裂阈值为 1600 N。达到阈值即触发不可逆的本场故障，松开、暂停、重连均不能修复；下一场比赛重新生成车况。正常车辆不会因这个特定阈值断裂。故障与当前受力应同时显示，避免玩家只能通过失控猜测车辆状态。

## 动力学边界

车辆模型采用小固定步长的平面动力学，结合低速响应、前后轮侧偏力、摩擦圆抓地力约束与载荷转移。发动机和自动变速箱驱动车轮，空气和滚动阻力消耗速度；路面、坡度、温度与车况改变响应。AI 使用相同车辆状态与赛道数据。

模型侧重让刹车距离、弯道极限、转向迟滞及车辆差异可感知。它是有明确参数与可重复测试的游戏模型，未经过真实车辆遥测标定；不应把展示的踏板力、抓地力或极限速度视为实际车型测量结果。屏幕车身侧倾与悬挂表现用于反馈模型状态，并非完整四轮多体悬挂求解。

## 渲染与兼容

场景使用本地 Three.js r124（WebGL 1）渲染。道路几何、地形、建筑及车辆模型由项目代码生成，无需联网加载地图。手机和电视的房间通信只在局域网进行。

Chrome 61 / ES2017 语法检查用于发现新语法依赖；现代 Chromium 软件渲染用于检查实际三维路径、截图和生命周期。二者都不能替代真实旧 Android WebView、电视 GPU 和手机网络延迟测试。
