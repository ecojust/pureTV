# 镜光接力 0.2.1 光学说明

此版纠正器件的物理含义和画面，沿用六关初始布局、四向网格光路、旋转输入、充能与胜负规则。旧版安装包、视频、测试报告和文档保留原始内容，仅代表原版本。

## 镜片与分光模块

斜置平面镜依照入射角等于反射角工作。屏幕坐标 x 向右、y 向下，`/` 镜片将右、下、左、上的入射分别转为上、左、下、右；旋转 90° 后的 `\` 镜片分别转为下、右、上、左。镜片不改变所含 RGB 通道。

方形 RGB 分光模块含二向色分束元件、转向镜、单向光隔离器与吸收端。分色镜按波段选择反射和透射，内部转向镜将出口排成红左、绿前、蓝右，均相对于入口方向。缺少的通道不会生成。单向光隔离器终止输出口返照，非入口方向的光被隔离或吸收；这种单向性不能仅由被动镜组产生。

默认入口在左侧、光向右传播。器件示意中的第一块彩色 `/` 分色镜把 R 反射向上，另一块彩色 `\` 分色镜把 B 反射向下，G 继续向右；银色转向镜将 R/B 对齐到顶部与底部出口。四个端口的箭头标记允许传播方向，整体旋转后各端口方向同步旋转。示意图表达连接关系，不是比例施工图或玻璃棱镜的折射路径。

为兼容旧存档字段、测试和关卡数据，模型内部类型仍为 `prism`；对外名称为“分光模块”，第五关改名“双模块四色港”。

## RGB 与模型边界

光束用三个通道是否存在表示：R=1、G=2、B=4。黄色光源表示 R+G 的组合，青色表示 G+B，白色表示 RGB；没有把单色黄光转换成两种其他频率的过程。显示颜色使用平衡 RGB 三基色的加色约定，接收器只检查通道集合，不比较光功率。

光束相交不改变每束光原来的方向或所含通道。接收器汇总抵达的通道；这不等于否认相交处的电磁场叠加，也不把相交后的光束自动替换为混合颜色。

模型不计算连续光谱、材料折射率、强度衰减、相位、偏振、隔离器内部结构或光传播延时。网格光路与理想通道分离是解谜近似；20 个 10 Hz tick 充能、吸收器热量计数和倒计时是游戏规则，不是实测功率或温度单位。

## 验证范围

现有回归检查全部入射方向、四种模块朝向和七种 RGB 子集，核对非入口阻断、通道守恒、镜面反射、交叉独立传播、接收器汇总、六关唯一安全解以及普通输入通关。0.2.1 增加独立反射向量公式检查，并检查渲染只使用新的模块素材、端口图示和六关名称。浏览器画面与正式安装包须使用本版冻结源码重新验证，旧 0.2.0 录像不作为新版证据。
