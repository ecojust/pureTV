# 舰队账册 · Fleet Ledger

根据行列船格总数、舰队长度多重集和少量固定船/海线索，填完海图。每艘船由上下左右相连的船格组成，必须是一条没有转弯的直线；不同船之间不能正交或斜角相邻。

相邻船格自动属于同一艘船，不能把连续4格私自拆成相邻的3格船和1格船。最后的组件长度必须逐艘匹配舰队清单，不能只核对船格总面积。行列数字中的0同样有效。

## 操作与检查

- 方向键选择任意格；A循环未知?→船→海→未知。锁形角标表示公开固定线索，不能改动。
- A对应空格、Z、遥控器确认或手机右上；B对应X、B或手机右下。键盘字母A是左移键，不是动作A。
- B检查：还有任何未知格时，只给免费提示，不扣机会；所有格都标为船或海的完整图，每次检查消耗一次机会。
- 完整检查共3次，第三次正确仍然获胜，第三次错误失败。填图不会自动获胜。

外侧数字为“当前船格数/目标数”。编辑后会保留旧检查并标记OLD CHECK / EDITED；未知格免费提示和已扣次的完整检查有不同标题。没有计时器，长按不连动。

## 原创公开谜题

| 海图 | 尺寸 | 舰长清单 | 固定线索 | 待填格 |
| --- | --- | --- | --- | --- |
| 港湾清单 | 5×5 | 3、2、1 | 2 | 23 |
| 航道账页 | 6×6 | 3、2、2、1 | 3 | 33 |
| 外海锚地 | 7×7 | 4、3、2、1、1 | 3 | 46 |

三题的唯一船格占用解由独立枚举验证。公开数据只含行列数字、舰队长度和固定格；生产规则不读取答案表，会接受任何完整合法布置。作者答案只在本次临时工作目录，测试求解器也不打包进游戏资产。

## 验证与构建

运行 `node resource/apps/fleet-ledger/tests/model-test.cjs`：15组检查包含唯一占格解、三关普通输入通关、固定线索保护、免费未完成提示、行列分别违反的反例、弯船、斜角接触、舰长多重集、第三次正确/失败、取消输入与终局冻结。测试求解器枚举整船放置；独立QA采用行位掩码枚举，避免共用算法。

实际浏览器操作、960×540/1280×720画面、录像、签名和发布证据由交付流程后续归档；模型模拟不等于浏览器或设备测试。未进行实体电视或手机测试。
