# 弹板清砖 / Brick Paddle

控制弹板接住小球，利用反弹清空所有砖块。三组原创砖阵分别有 6、8、10 块砖；后两关加入需要两次命中的耐久砖，砖上的数字直接表示剩余命中次数。

| 操作 | 动作 |
| --- | --- |
| 左 / 右、A / D、手机方向区 | **持续**移动弹板 |
| A：空格 / Z / 确认 / 手机整个右区 | 发出停在弹板上的球 |
| P / Escape / START | 暂停／继续 |
| R / SELECT | 重开当前砖阵 |

这里的“操作 A”是右侧发球动作；键盘字母 A 仍是向左移动，与其他游戏的 WASD 方向约定一致。B 和上／下不产生游戏动作。

击中弹板中间时，小球接近垂直向上；击中左右边缘时，它会向对应方向更斜地弹出。提前移动弹板，不仅能接球，也能把回球送向剩余砖块。

每局有 **3 次机会**。漏接一次后，球回到当前弹板，先松开再按发球键重新发球；一直按住不会自动连发。第三次漏接结束本局。全部砖块被击破立即获胜，没有倒计时，也不会随时间自动加速。

| 砖阵 | 砖块数 | 两次命中的砖 | 总命中需求 |
| --- | ---: | ---: | ---: |
| 玻璃码头 | 6 | 0 | 6 |
| 铜色拱廊 | 8 | 2 | 10 |
| 翡翠工坊 | 10 | 3 | 13 |

模型使用有限小步长处理球与墙、弹板和砖块的接触，保持固定球速并限制近乎水平的反弹。圆角和同一时刻碰到相邻砖块也会按几何关系处理。精确规则和验证边界见 [模型契约](docs/model-contract.md)。

模型测试以公开球／板位置反馈控制，三个正常输入流程均已清砖；它们不是实体电视或真实手机测试。浏览器录制与签名发布仍由各自验证记录说明。所有砖块、弹板和球的素材由代码绘制，按 [MIT 许可证](LICENSE) 提供。
