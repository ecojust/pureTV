# 弹板清砖美术组织

深蓝色球场以细网格衬托彩色玻璃砖，砖块使用斜光、边缘高光与数字耐久值；两点耐久另有亮色内框，受击后数字真实变为1。弹板带中央握槽与青色金属表面；金色球芯匹配模型16像素直径，外侧柔光仅作装饰。

720×450的真实游戏坐标直接映射到960×540画布的左侧，不缩小碰撞场地。右侧显示剩余砖、三次机会、有效命中及触点改变反弹方向的示意。等待发球时球场有明确A提示；手机右侧整区对应唯一发球动作。模型球位置、砖HP和弹板位置直接用于绘制，不使用预定碰撞动画。

当前速度方向生成短暂的视觉拖影，不作为物理路径或验证证据。场地纹理、砖、板、球在游戏专属图集中一次烘焙，共享批次提交。中文规则在DOM层，画布只用ASCII标签。

实际浏览器截图、运动录像、性能采样和实体设备测试须分别记录；此设计文档不声明尚未执行的检查已经完成。
