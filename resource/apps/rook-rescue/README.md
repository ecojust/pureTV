# 王车合围 / Rook Rescue

你执白王 **K** 与白车 **R**，在 5×5、6×6、7×7 棋盘上合围黑王。黑方只有一枚王，双方国王都不能被吃掉。**将军且黑王没有合法落点，才是将死获胜。**

三关白方手数分别为 12、16、20。选子、移动光标、取消与非法尝试不计手数，思考没有倒计时。

## 操作

- 方向键移动金框，到边缘停止。
- A 先选择白王或白车，再移动光标按 A 走子。指向另一枚白棋按 A 可以换选。键盘空格、Z、Enter，遥控器确认或手机右上区域。
- B 取消选子，手数不变。键盘 X 或手机右下区域。
- P / Escape / START 暂停；R / SELECT 重试。

青框表示选中的白棋，青点只表示它当前合法的落点。珊瑚框标出黑王末步；右侧 `LAST` 给出同一格的行列。棋子具有王冠或城垛轮廓，并标注 K / R，黑白明暗也不同。

## 走法与结算

白王可向八个方向移动一格，不能落在棋子上，也不能与黑王相邻。白车沿横竖直线移动任意正距离，不能越过任何国王，不能吃王。

黑王同样移动一格，不能靠近白王或进入白车攻击线；白王会挡住白车射线。黑王可以吃掉没有白王保护的白车。合法白方走子后黑王立即应手。

黑方策略完全公开：优先安全吃车，否则选择应手后合法落点最多的位置，再选择离白王平方距离最远的位置，最后按从上到下、从左到右的格序破同分。这个固定策略便于推演，**不宣称完美棋力**。

- 白方将死黑王，立即获胜，不再让黑王走棋。
- 黑王没有合法走法，但并未被将军，是逼和，本游戏判为目标未完成。
- 白车被黑王合法吃掉，失败。
- 黑王应手后白方手数已用尽且未将死，失败。

最后允许的一手将死仍然获胜。不能通过吃掉国王来结束游戏。
