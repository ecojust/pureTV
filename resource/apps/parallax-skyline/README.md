# 视差天际 / Parallax Skyline

沿着两条深度不同的轨道移动建筑板，让两个观察点都出现指定的天际线。近层移动一个世界单位，投影移动两格；远层只移动一格。正面看似严丝合缝的建筑，换个角度可能暴露错误。

这是 pureTV 百款游戏计划的第 41 款设计，包名 `com.ecojust.parallaxskylinetv`，版本 `0.1.0`。单人游玩，支持电视遥控器、键盘和局域网手机手柄。完成验证并推送后才计入完成数量。

## 操作

- 上下方向：依次选择近层 NEAR、远层 FAR、观察点 VIEW。
- 左右方向：移动所选建筑板一个世界单位；选中 VIEW 时，左选观察点 0、右选观察点 1。观察点选择不改变建筑位置，两个视图始终同时显示。
- A：验收当前完整布局。键盘使用 Space、Z、Enter；手机点击右侧上半区。
- B：撤销最近一次成功移动，恢复当时近远两层的位置。键盘使用 X、B；手机点击右侧下半区。撤销不退还已消耗的容错。
- 方向与 A/B 都按边沿生效，长按不连续移动或提交。松开再按或明确改变方向才执行下一步。A/B 同时按下时优先撤销，其他同时按下的动作不会排队。
- P、Escape、START 或独立暂停按钮：暂停/继续；R 或手机 SELECT：重试。菜单中的 B 切换声音。

手机右侧整个三分之一区域分成上下两半，无需寻找小按钮。暂停、输入取消或手柄断线之后，请先真实松开仍按住的按键，再进行新操作。暂停冻结整个局面，重试恢复初始布局、容错和撤销记录。

## 怎么通过

两幅图分别显示完整目标轮廓和一个指定的屋顶锚点。亮色轮廓和空心菱形是目标，填充建筑与实心菱形是当前状态；叉号表示锚点被遮挡。`SKY` 与 `MARK` 分别显示该视图的轮廓和锚点是否合格。

只有两个视角的轮廓与锚点这四项全部匹配，按 A 验收才会通关。布局已对齐但尚未按 A 时仍在游戏中。远层锚点被同高近层屋顶挡住，也不算合格。选中的观察点只改变高亮，不会跳过另一视角的检查。

每局允许四次错误验收，第四次错误后失败。**剩余容错**指还允许几次错误；正确验收不会消耗它。没有超时失败。撤销只恢复位置，不倒退用时、验收历史或容错。

| 任务 | 特点 |
| --- | --- |
| 庭院遮挡 | 近层遮住远层，正面一致也未必通过第二视角 |
| 河岸交错 | 两层建筑高低交织，逐一对齐屋顶与锚点 |
| 双塔视差 | 高塔在两个观察点产生不同相对位置 |

每个任务都是独立的一局谜题。两层各有五列建筑，投影采用公开的离散模型，不宣称精确复现真实透视。近层位置范围为 2–5，远层为 4–14；超出范围的移动无效。撤销最多保留最近 32 次成功移动。

## 画面与公开规则

画面采用建筑模型与制图桌风格，近层为铜色、远层为青蓝色，配有局部烘焙的窗格、材质和高光。两个投影直接读取模型的公开轮廓与屋顶归属；所有判定用的轮廓和锚点都由同一状态显示。

- [公开设计](docs/public-design.md)：三个任务的建筑数据、完整目标与操作。
- [模型规则](docs/model-contract.md)：投影、遮挡、撤销、输入边沿与验收规则。
- [观察接口](docs/public-interface.md)：完整模型调用与稀疏浏览器观察各自能验证什么。

共享 Android 宿主提供手机手柄、暂停和毛玻璃弹窗。图形与 ASCII 文字共用一个本地烘焙图集，中文说明使用 DOM。实际绘制次数、运行时性能与画面接受情况以发布报告为准。

## 构建与验证

在仓库根目录运行 `python3 resource/game-kit/build.py --game resource/apps/parallax-skyline --output /tmp/parallax-skyline-build`。构建工具生成 `game-config.json` 和 `assets-index.json`，`game.json` 中的 `actions: 2` 配置手机 A/B 上下触控区。

发布产物为 `parallax-skyline-0.1.0.apk` 和 `docs/gameplay-0.1.0.mp4`，每个文件均须小于 10,000,000 字节。发布验证、签名、录制和画面审阅分别记录在 `docs/verification.json`、`docs/signing-receipt.json`、`docs/gameplay-0.1.0.json` 与 `docs/art-review.json`。

模型边界测试与普通游玩分开，录像使用正常输入，不注入成功状态。浏览器截图和录像是稀疏观察，不能补造未记录的操作；浏览器软件渲染也不代表电视或手机真机性能。未做实体硬件测试时，报告会明确注明。
