# 纹码破译：独立规则复核

依据 [公开契约](model-contract.md) 另写多重集合计分与候选枚举，测试从实际提交返回的 exact／misplaced 两个总数筛选候选。没有读取私有 WeakMap，也没有复刻或使用私有码生成算法。所有模型运行均通过 `create` / `step` 的普通输入，不能把观察副本写回模型。

```bash
node resource/apps/codebreaker/tests/independent-check.mjs /absolute/scratch/codebreaker/independent
```

20 组检查通过，共执行 84 次普通完整提交；模型哈希、规划过程、反馈和末态见 [independent-report.json](independent-report.json)。三个关卡分别对种子 0、761、4294967295 通过公开反馈求解。默认种子需要 3／3／4 次，边界种子需要 4／4／5 次，都在公开额度内。

计分参考先去除正确位置，再对剩余重复符号取两边出现次数的较小值，防止重复计算。固定示例单独检查参考函数。随后先正常求解取得合法终局 reveal，再开同种子新局，核对重复猜测、旋转猜测、最后一次正确提交获胜，以及额度内持续错误最终失败；这些对照只使用已通过正常玩法获得的码。

同时核对不完整提交不计费、不泄露反馈，编辑／清空不消耗尝试，长按不重复、取消后重新武装，以及观察副本 `step` 完全无效而原状态继续可玩。游戏中 reveal 始终为空，终局 reveal 是独立数组；终局再次输入不改变状态。

这些是模型证据。浏览器真实键盘、画面、录像、签名及设备验证另行记录；客户端源码可检查的限制不应被表述为密码学安全。
