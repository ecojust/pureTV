# 纹码破译 / Codebreaker

推理四格密纹。每格从本关的符号集中选择，**同一符号可以重复出现**。你只能看到自己的猜测，以及每次提交后的两项总数：

- **E（全对）**：符号正确，位置也正确的数量。
- **M（错位）**：符号存在于密纹中，但位置不同的数量。

每个符号出现次数只能计一次，先计算 E，再从剩余符号中计算 M。反馈不会告诉你具体哪一格正确。例如，假设密纹为「1、1、2、3」，猜「1、2、1、1」得到 E=1、M=2；这只是说明规则的例子。

| 密匣 | 可选符号 | 格数 | 猜测次数 |
| --- | --- | --- | --- |
| 四纹密匣 | 4 种 | 4 | 7 次 |
| 五纹密匣 | 5 种 | 4 | 8 次 |
| 六纹密匣 | 6 种 | 4 | 9 次 |

每种符号同时有独立形状和数字编号，无需仅靠颜色区分。

## 操作

| 输入 | 动作 |
| --- | --- |
| 左 / 右 | 选择四格中的一格，到边缘停止 |
| 上 / 下 | 循环切换当前格的符号；空格首次上选1号，下选本关最后一个符号 |
| A | 提交全部四格 |
| B | 清空当前格，不清除历史记录 |

键盘方向键 / WASD 编辑；空格、Z、Enter 为 A，X、B 为 B。手机左侧摇杆选格／换符号，右上 A 提交，右下 B 清空。P / Escape / START 暂停，R / SELECT 重新开始。

填满四格才会消耗一次猜测；未填满提交免费且不会提供任何密纹反馈。提交后当前猜测保留，方便修改。猜中全部四格即获胜，最后一次猜中也算成功；次数耗尽才失败并揭示答案。没有倒计时。重试相同密匣会重建相同题目，便于重新验证推理。

长按不连动，每次编辑或提交后松开再按；同时触发时 B 优先于 A，A 优先于方向。修改当前猜测不会改变历史反馈。

精确输入、反馈、状态及信息边界见 [模型契约](docs/model-contract.md)。测试求解器只读取正常公开反馈，不随游戏打包。浏览器操作与软件渲染不等同于实体电视、手机或模拟器测试。代码与原创密纹符号素材采用 [MIT 许可证](LICENSE)。
