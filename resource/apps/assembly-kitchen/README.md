# 装配厨房

在关门前，把三份订单依次煮熟、冷却、装盒并正确交付。煮锅、冷却台和装盒机可以同时工作，但每个工位只能放一份食物；完成后仍会占位，直到你亲手取走。

- **午间三味**：蒸蛋、番茄汤与温果羹，熟悉流水线和不同交付温区。
- **热餐先行**：先送蒸蛋，再处理南瓜汤与炖菜，安排工位交接与保温时间。
- **晚间流水**：三张票据有不同加工时间和交付顺序，利用并行工作赶上晚间收单。

左右方向键或手机摇杆选择订单；**A 处理**执行当前工序：开始煮、取走、开始冷却、取走、开始装盒或交付。**B 风速**切换冷却台的快风与慢风，空台时也能提前设置。**P** 暂停或继续，**R** 重试；手机右侧两个大触控区分别执行 A/B，遥控器方向和确认键也能操作。

READY 只表示该工序完成，仍需取走；DELIVERY 标出真正交付时的温度要求。煮好后，食物在工位、托盘和餐盒内都会继续降温，保温期限不会因为转移工序而重置。快风降温更快，慢风便于细调。

按票据顺序、在温度范围内交付才算成功。交付时错温、错序，或食物过期会计一次失误并把该订单恢复为原料，已完成的订单保留；累计两次失误或关门时未完成全部订单则失败。无效的提前操作不扣失误，但时间仍在流逝。三关分别在75、80、85秒关门。

画面采用原创横向厨房工作台、烘焙图集与单批次 WebGL 渲染。每份食物只画在其实际位置，进行中、完成待取、装盒和已交付明确区分。电视说明使用中文，手机控制器支持中文和英文。

规则与公开状态详见 [模型合同](docs/model-contract.md)。规则边界测试、正常操作回合、独立核算和浏览器画面验证分开记录；软件浏览器验证不代表实体电视或手机测试。
