# Neon Rush development

Follow the repository AGENTS.md and current history entry first.

- Edit `source/*.mjs`; `src/main/assets/game-model.js` and `game.js` are generated by `npm run build`. Run `npm run build:check` before freezing/signing. Keep Three.js local and retain its license.
- Tracks, physics, camera and minimap share the same geometry and heading convention. Preserve ordered checkpoints, terminal freezing, cancellation without a rewarded drift release, and recovery without extra progress.
- Native TV remotes do not focus arbitrary HTML buttons. Keep the QR panel visible in native menus/pauses, and keep the primary action and complete instructions visible at 960×540 and 1280×720.
- The Android bridge permits the exact local entry URL. Native language changes must persist the preference and reload that same URL. Do not replace a real LAN address/error with placeholder text.
- Run meaningful model checks and actual normal-input browser races after relevant changes. Do not block the driving input loop while taking screenshots. Native bridge/layout fixtures are synthetic, not device execution.
- Browser acceptance, fixed-certificate signing and gameplay recording must refer to identical asset bytes. Keep failed reports and exact executed test scripts; see `docs/qa/` and the repository Game Kit QA guide.
