# 0.1.2 左右转向反转的独立复现

来源为冻结提交 `600b6addfda394e1a58b567d00d32731a387cccd`，不是当前正在修改的源码。`provenance.json` 保留各输入文件的 SHA256。

运行 `node reproduce.mjs`。脚本加载未修改的真实模型及赛道，按 60Hz 推进三个赛道的倒计时，再分别施加 LEFT=-1 / 0 / RIGHT=+1 共1.2秒。使用真实追尾相机公式和 Three.js lookAt 对应的投影基，所有轨迹投影到同一初始相机，以分离相机跟随运动。

结果 `result.json`：三个赛道的 RIGHT 输入相对直行均投影到屏幕左方（约 -0.076 NDC），LEFT 均到右方（约 +0.076 NDC）；RIGHT 之后车头方向在相机右基上的分量为约 -0.417。协议和菜单方向保持正确，问题在模型把逻辑向右轴直接当成世界正 yaw。

这是隔离其他车辆碰撞后的合成模型／数学投影验证，不是渲染截图、正常驾驶验收或实体 ESP32 验证。游戏源码与归档源文件均未改写。
