# 彩径连点 / Color Paths

把同号、同形的两个端点连成路径，并让每一个格子都属于一条路径。三关分别为 4×4／3 对、5×5／4 对、6×6／5 对端点。颜色同时配有数字和形状，辨认路径不只依赖颜色。

## 操作

- 方向键：移动金框，到棋盘边缘停止。
- A：当前普通格按“空白 → 1 → 2 → … → 最后号码 → 空白”循环。键盘空格、Z、Enter，遥控器确认，或手机右上区域。
- B：手动检查整盘。键盘 X，或手机右下区域。
- P / Escape / START 暂停；R / SELECT 重试。

端点带双框，号码固定，不能修改。普通格可反复改色；循环回空白就是清除。没有编辑次数限制或思考倒计时。

## 路径如何连接

**上下左右相邻的同号格会自动连线。** 没有单独选择边的操作，所以路径贴着自己经过另一格，也会增加一条连接。

- 每个端点必须恰好连接一个同号邻格。
- 每个有号的普通格必须恰好连接两个同号邻格。
- 每个号码只能有一个连通块，并连接其两个固定端点。
- 全盘不能留空格。

因此不能分叉、留下断路或孤立的环，斜向接触也不相连。不同号码不会共用一个格子。

每格显示号码与形状；双框表示固定端点，金框表示当前格。小珊瑚点提示该格连线数不符合要求，右侧显示当前度数及各路径是否完整。即使某条路径显示 `OK`，仍须完成其余路径并覆盖全盘。

达到条件不会自动结束，仍需按 B 提交。错误检查扣一次试错机会，第三次失败结束；只剩一次机会时正确提交仍能获胜。

## 公开数据与验证

三关端点布局均由独立的无弦简单路径枚举和全盘覆盖搜索验证为唯一格着色解。运行时只读取端点和上述规则，不保存完整颜色答案、求解器或下一步路线。求解器仅在测试目录。
