# 独立规则复核

只从公开端点出发，独立枚举不含自接触弦边的简单路径，再搜索互不重叠且完整覆盖棋盘的组合。三局各颜色候选数分别为[1,1,1]／[1,3,4,2]／[44,2,84,7,2]，完整着色严格各1解。此处考虑同色正交邻格会自动连接，未把路径当成可独立编辑的边。

16组通过，294次普通A换色和24次B检查。三局普通胜利、仅剩一次机会时胜利、三次无效检查失败，以及所有端点不可改色均通过。每次核对完整度数、组件、各颜色路径和覆盖计数；完整着色仍须手动B才会获胜。

还用实际A操作在6×6中画出颜色2的端点路径和分离的2×2闭环：该颜色每格度数正确但有两个组件，必须拒绝。清除闭环后再向路径侧面增加同色格，实际产生度数3的分叉并被拒绝。没有为这些反例写入模型状态。详细数据见 `independent-report.json`。

浏览器与实际录像另行验收，不声称实体电视／手机测试。
