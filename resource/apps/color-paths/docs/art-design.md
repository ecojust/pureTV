# 彩径连点美术与信息设计

深靛色路线台上使用青、珊瑚、金、淡紫、淡蓝五组线条。每一格同时配路径数字和圆／方／三角／菱形／十字标志，数字至少24逻辑像素，形状不承担唯一信息渠道。固定端点有浅色双框，普通格单框；金框单独表示光标。

相邻同号格的连接先按真实模型颜色画出，再叠加数字形状牌，四个方向都能看见线条进入格子。度数错误用小珊瑚点提示，右侧给出具体当前度数。没有把预期答案或自动路由画成引导线。

4／5／6盘格距80／68／58，格区中心 (295,292)。列标固定在 y82，24像素标签下缘106与最大格框上缘至少119相隔13像素；行标中心 x86，右缘不超过98，与最左格框至少122相隔24像素。格区底部不超过466，留出独立控制栏。端点框、数字、形状与焦点框都有独立层次。
