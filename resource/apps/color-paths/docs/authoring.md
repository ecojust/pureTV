# 端点生成与唯一性证明

本游戏采用格着色而非独立画边，因此同色正交相邻必定连接。生成与求解必须排除一条路径内部非连续点之间的额外邻接，否则会在运行时形成分叉或环，不能把普通自避路径当成合法答案。

生成从网格的完整遍历中截取无弦简单路径，至少两个格子一段，再打乱路径号码，只保留每段两端为公开题面。生成过程中使用的完整颜色不进入生产文件。

测试重新从公开端点出发，枚举每对之间的所有无弦简单路径：不得经过其他颜色的端点，新加入格子只能邻接当前路径尾端。每关各颜色的候选路径数量分别为：

- 4×4：1、1、1。
- 5×5：1、3、4、2。
- 6×6：44、2、84、7、2。

随后独立选取每色一条路径，检查互不占格和全盘覆盖。三关均恰有一个合法格着色解。完整路径搜索访问节点26／104／1220；这些是离线题面验证统计，不是游戏中的答案提示或难度计时。

自行测试通过正常按键式输入循环改色、手动提交三关胜利与最后一次检查胜利，并验证固定端点保护、分叉、端点多连线、断路、孤立环和缺格。普通题面没有“所有路径均完整但仍留空格”的替代组合，覆盖反例采用从正常解中清空一个普通格，明确保留其伴随断路错误，未虚构约束完全独立的反例。

生产资产只有公开端点、规则模型和绘制代码。独立 QA 应自行推导候选路径与覆盖，不读取本次临时生成掩码。
