# 果园游蛇 / Orchard Snake

带着不断增长的身体穿过果园，收集果实，避开石墙、边界和自己的身体。蛇会自动向前移动，方向键为下一拍预排转弯。

| 操作 | 作用 |
| --- | --- |
| 四个方向 | 排入下一次移动的转弯，不能直接掉头 |
| A | 消耗一枚刹车令牌，暂停移动 0.6 秒 |

每拍只能排入一个转弯，移动前再次变向不会覆盖已排方向，避免两次快速转向撞向蛇颈。长按不重复排入。刹车期间可以排方向，已积累的移动进度会保留；每局只有 **3 次**，正在刹车时再按不扣次数，用完不补充。B 无操作。

吃果会增长一节；达到该园目标立即获胜。撞石墙、越界或撞到身体失败。未吃果的普通移动可以进入同时离开的尾格；增长时尾巴不会离开。果实从当前可达空格中确定性选择，不会出现在身体或石墙上。

| 果园 | 目标果实 | 每格时间 |
| --- | ---: | ---: |
| 草甸果径 | 5 | 0.35 秒 |
| 树篱曲径 | 7 | 0.30 秒 |
| 石间果林 | 9 | 0.26 秒 |

没有整局倒计时。暂停会冻结移动和刹车；输入取消会清除待执行转弯，但游蛇仍按当前方向前进。开始或恢复后先松开控制，再排方向。请观察画面显示的下一拍方向，提前绕开障碍。

- 键盘：方向键 / WASD；空格 / Z / Enter 刹车；P / Escape 暂停，R 重试。
- 手机扫码：左侧摇杆选四向，右侧整个区域短刹车。

精确规则、地图和时间积分见 [模型契约](docs/model-contract.md)。测试命令：`node resource/apps/orchard-snake/tests/model-test.cjs`。路线搜索仅用于 tests，浏览器操作与录像只读公开蛇身、地图、果实并发送正常按键，不能代表实体电视或手机验证。
