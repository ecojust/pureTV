# 词阶接龙 / Word Ladder

每关公开完整四字母英文词库，按字母顺序展示，没有隐藏词典。从起词到目标，每一步只能改变一个位置的字母，并且必须选择本关可见词库中的词。只判断公开规则，不比较任何预设路线；无需用户凭空猜英文单词。选中词的简短中文释义显示在信息栏。

方向键在四列词格中选择。A 提交：恰好一个字母不同才接龙并消耗一步；相同词或多字母不同均免费拒绝。可回到旧词，但仍耗一步。B 撤销最近一步，共两次，恢复当前词和光标，但不退还已用步数。未走过或次数用完时 B 免费无效。终局不能撤销。

| 词阶 | 完整词数 | 起词 → 目标 | 最短步数 | 预算 |
|---|---:|---|---:|---:|
| 从头到尾 |18|HEAD → TAIL|5|9|
| 冷词成形 |22|COLD → FORM|6|10|
| 沙地农场 |24|SAND → FARM|7|11|

测试专用 BFS 从可见词库逐对建图证明上述距离，求解器不打包。目标到达先于预算耗尽判断，所以最后允许的一步也能获胜。LEAF、CORK、BONE 分别为三题中可在目标之前到达的非目标叶节点；离开死路须返回原词并耗步，或使用不退步数的撤销。不会因为叶节点直接判失败。

分支证明把目标作为吸收终点。第二题的 ROAM 虽在普通无终局图上距起词8步，但那条最短路穿过目标 FORM；绕开目标要11步，超出预算，因此不把 ROAM 宣称为可玩死路。CORK 在2步可达并可返回，提供真实分支。词库不是按答案顺序排列。

原创纸质词格、逐字母下划线、当前/目标栏、完整路径、图标及中文规则在本目录。实际浏览器输入、双尺寸目视检查、录像和正式签名仍由集成验收补齐。未进行实体电视或手机测试；源码候选不计入正式完成数量。
