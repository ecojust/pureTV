# Pure model contract

Exports only `create(seed,level)`, `step(state,dt,input)`, frozen `config`. Defaultseed798/level0, gridColumns4, initialUndos2. Public layouts contain only id/name/nameZh, alphabetically sorted words, meanings map, start, target and moveLimit. Dictionaries18/22/24 entries are unique uppercase ASCII4-letter words. All displayed meanings are public; no hidden dictionary, solution route, graph distance table or planner is shipped.

State copies words/meanings/start/current/target, path initially[start], cursor at start index, gridColumns4, movesUsed0, moveLimit9/10/11, undosLeft2/undosUsed0. Derived differences is one array of differing character positions0..3 per visible word; legalIndices contains exactly those with one difference. Also acceptedReceipts, undoReceipts, lastTransition, phase/reason/score, bounded gate counters/events and terminalReceipt.

Arrows move one grid cell without row wrap. Left/right clamp within current row and existing words; up preserves column and clamps to first row; down preserves column but clamps to final existing word in a short last row. B undo always restores cursor to the restored current word. There is no freeform word submission input, only cursor selection among all visible words.

A checks selected `words[cursor]`: Hamming distance exactly1 accepts, increments movesUsed, appends path (including revisits), updates current and all differences. Other distances reject free and leave path/move counts/undo credits unchanged. Accepted receipt and lastTransition are `{type:'move',from,to,changedIndex,moveNumber,pathLength}`. Then current==target wins before movesUsed>=moveLimit loses reason`moves`. No other path, spelling-source or route test is used. A reachable one-neighbor word is not automatic loss because a legal return exists.

B requires path length>1 and remaining undo credit; otherwise a free blocked event. Success pops the immediate latest word, restores preceding current, repositions cursor, consumes one undo, and leaves movesUsed unchanged. LastTransition uses type`undo` with the same field names; undoReceipt adds undosLeft. Receipts remain detached. AcceptedReceipts≤moveLimit, path≤moveLimit+1, undoReceipts≤2; thus revisits cannot grow state indefinitely. No timer and no history editing beyond the explicit two undos.

Terminal score100 for win,0 for loss; terminalReceipt snapshots outcome/start/current/target/path/move counts/undo credits/receipts/lastTransition. All later steps freeze exactly, including undo. Correct final-budget arrival wins. Invalid candidate attempts do not advance budget and cannot force loss.

Input follows the release gate: only finite0<dt≤.25 while playing and not paused; own data descriptors, finite clamped axes and literal buttons; dominant axis>.5 with vertical ties. FreshB>A>changednonneutraldirection. Initial neutral arms; epoch changes or rising cancelled quarantine until neutral. Held controls do not repeat. Paused/invalid dt are exact no-ops. Admitted counters saturate2147483647 and elapsed86400. Current events/lastCommand reset per admitted call. Unknown fields, including candidate or word strings, have no submit authority.

Public BFS proves shortest5/6/7; meaningful branch reachability excludes target as an intermediate because arrival terminates play. LEAF/CORK/BONE paths satisfy the budget before target. ROAM graph-distance8 through FORM is explicitly not an ordinary reachable branch under10-move budget (target-avoiding path11). All solver/proof code lives in tests only; production permits every one-letter move from the visible dictionary.
