# 滑格归序 / Sliding Order

经典 3×3 滑块数字谜题：八块瓷砖和一个空格，把棋盘排成 `1 2 3 / 4 5 6 / 7 8 空格`。三种固定起点都可解，不会随机生成无解棋盘。

**方向键移动的是空格。** 例如按右，空格向右一格，同时右边的数字瓷砖向左填入原来的空格。

| 操作 | 动作 |
| --- | --- |
| 方向键 / WASD / 手机方向区 | 移动空格，与相邻瓷砖交换 |
| A：空格 / Z / 确认 / 手机整个右区 | 撤销最近一次尚未撤销的滑动 |
| P / Escape / START | 暂停／继续 |
| R / SELECT | 从本关初始排布重新开始 |

每次实际滑动消耗一步。碰到棋盘边缘不动，也不扣步。**撤销不会退还已用步数**，但不额外扣一步；没有历史时无法撤销。长按不重复移动，每次操作后先松开再按。B 没有游戏动作。

当最后一次允许的滑动恰好完成目标时仍可获胜；额度用完而未归位则结束，结算后无法撤销，只能重试。没有倒计时。右侧小棋盘始终显示目标；大棋盘里已经归位的数字以蓝色和勾号提示。

| 排布 | 最短滑动数（测试证明） | 实际滑动额度 |
| --- | ---: | ---: |
| 晨光棋格 | 8 | 14 |
| 午后排布 | 12 | 18 |
| 暮色归序 | 18 | 24 |

初始数字、精确输入和撤销规则见 [模型契约](docs/model-contract.md)。求解器仅用于测试，不在游戏资源中。瓷砖、木框和空格图形由代码绘制，按 [MIT 许可证](LICENSE) 提供。
