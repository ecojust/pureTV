# 正常游玩录像

[播放或下载《孤胆枪手》0.1.2 游玩视频](gameplay-0.1.2.mp4) · [来源与校验记录](gameplay-0.1.2.json)

91.27 秒，1280 × 720，15 fps，H.264，11.14 MiB。原始游戏画面约 89.27 秒，从标题进入首关，包含拾取冲锋枪、移动射击、正常怪潮和三个控制台任务，最后进入补给界面。片尾额外定格 2 秒，便于查看补给页。

录制加载正式版本的原始 `tv.html`，在 Chromium / SwiftShader 中运行；通过模拟的原生局域网房间桥发送标准手柄输入，自动寻路并使用游戏自带的辅助瞄准。敌人、拾取、碰撞、伤害及任务进度均由正常游戏规则产生，未使用实体手机或电视。正常 HUD 和游戏镜头完整保留。

固定录制时钟提供随机种子 19790503，原始 runtime 按 60 Hz 执行正常模拟，离线采集帧后编码。因此 15 fps 是视频导出规格，不代表设备实时帧率。录制使用静音设置，成片没有声音轨。画面下方持续显示自动操控和非电视实拍说明。

图像序列哈希、真实日志检查点和录制检查终止情况见来源记录；未保存的后续帧没有编入视频。
