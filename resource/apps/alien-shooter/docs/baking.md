# 低模材质与地面光照烘焙

0.1.1 使用本地预烘焙材质，把货箱的边框、凹槽、铆钉、加固带、标签、磨损，以及地面的静态接触阴影和灯光存入贴图。货箱保留立方体轮廓，细节由图集提供；改变了轮廓的角色甲壳、肢体、培养罐等仍保留必要几何。

这是原创程序绘制的材质和近似静态地面烘焙。不是从原版游戏提取的资产，也不是离线路径追踪结果。接触暗部根据固定地图的距离场估算，灯光按距离衰减并检查墙体遮挡；不把活动闸门、可破坏油桶或敌人的影子烘焙进地面。

## 贴图及空间约定

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `baked-atlas.png` | 1024 × 1024 | 货箱顶面/侧面、金属、皮肤、油桶、五种补给标记、纯白材质区域 |
| `baked-floor.png` | 1024 × 1024 | 三关共用的重复钢板材质，保留通风条、螺钉、污渍与磨损 |
| `baked-light-0.png` | 512 × 512 | 货运站的地面接触暗部、局部灯光、地面标线与区域字样 |
| `baked-light-1.png` | 512 × 512 | 实验室的同类烘焙信息 |
| `baked-light-2.png` | 512 × 512 | 反应堆的同类烘焙信息 |

`baked-materials.js` 提供静态 `AlienShooterBaked` 元数据。它不会在加载脚本时发起请求或创建图片；启动加载器显式加载并解码图片后，渲染器才能开始绘制。

- 所有图片采用 `flipY=false`。图集矩形使用图像左上为原点的归一化 `[u0,v0,u1,v1]`，UV 已避开边界并加入半像素偏移。
- 图集各区域有 4–16 像素的边缘颜色扩展，降低 mipmap 下的相邻区域漏色。材质尺寸均为 2 的幂，兼容 WebGL 1 的重复采样及 mipmap。
- 图集和重复地板按 sRGB 解码；地面光照图包含直接存储的线性 RGB 数值，不能再做 sRGB 转换。光照图第二套 UV 是 `worldX / 48, worldZ / 34`。
- 三关共用一张地板贴图，用 `floorTint` 和各自的光照图区分货运站、实验室及反应堆。这样无需保留三张完整尺寸的重复材质。
- 图集和地板使用无抖动的 256 色 PNG 编码降低包大小，解码后仍是普通纹理。光照图保留 RGB，以免人为减少渐变层次。

五张 PNG 合计约 1.41 MiB。PNG 文件大小不是显存占用：若五张图全部驻留并按 RGBA8 完整 mipmap 估算，上限约 14.67 MiB；游戏的其它小纹理、帧缓冲、几何和浏览器开销另计。

## 重建与校验

在仓库根目录执行。生成需要 Node、`desktop` 的 Playwright 依赖、Chromium，以及 Python 3 / Pillow；这些只用于离线制作，应用运行时不需要它们。

```sh
CHROMIUM_PATH=/usr/bin/chromium node resource/apps/alien-shooter/tools/bake-materials.mjs
node resource/apps/alien-shooter/tools/bake-materials.mjs --verify
```

可使用 `--output /absolute/path` 把生成结果写入其它目录。制作过程只使用固定种子的绘图、原创位图字母和本地 `world.js`，不下载图片，也不依赖系统字体。

校验模式不启动浏览器、不重建 PNG：它检查现有图片的大小、SHA256、PNG 头、尺寸、图集和坐标约定，以及当前地图和制作脚本的 SHA256。修改地图或配方后必须重新生成；CI 不要求不同 Chromium / PNG 编码器产生相同文件字节。

渲染器仍需处理动态角色、闸门、爆炸和拾取物；优化前后的 draw call、三角形与同镜头截图由 `tests/performance.mjs` 记录。软件渲染器的提交耗时不能代替真实电视的帧率。
