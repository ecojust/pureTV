# 独立规则复核

双方全部手牌和剩余牌堆顺序在游戏中公开。测试依据公开双六牌编号、接龙朝向与对手最大点数／小编号／左端优先规则另写参考，不访问隐藏资料。加权状态搜索独立证明三局至少需要5／5／4次玩家出牌才能获胜；三局均以正常输入完成胜利与自然失败。

12组通过，367次普通 `create/step` 行动逐次核对完整牌链朝向、双方手牌顺序、库存、点数、AI抽牌与出牌、连续跳过及收据。观察到51次玩家抽牌、106次AI抽牌、41次跳过，以及玩家清空手牌、封局低点数胜、高点数负和同分负。测试还覆盖错端出牌／可出牌时B免费拒绝、B优先级和松开重按。

独立普通样本没有覆盖AI清空手牌终局；实现者单测另有明确标注的合成AI清空分支。本报告不将合成状态称为普通玩法。详见 `independent-report.json`；浏览器键盘、截图和录像另行验收，不代表实体电视／手机测试。
