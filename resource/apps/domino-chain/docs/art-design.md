# 骨牌接龙美术与信息设计

暖木边框、酒红桌毡、象牙牌面和黄铜端点牌组成一张公开对局桌。原创图集烘焙木纹、细密毡纹、牌面边缘与分隔铆钉。数字明确写在每一半骨牌上，下面附同值圆点；零以数字 0 和短横表示。

从上到下依次为对手完整明牌、完整有序摸牌堆、当前牌链、玩家完整手牌。两种手牌都可容纳初始七张加全部五张摸牌的最大十二张，没有隐藏页或省略牌。十二张时牌宽 66 逻辑像素、数字 24，整行宽 858，仍在 898 宽面板内。手牌数量和点数和分别列于各自面板顶部。

牌链最多展示七张；超过时保留前三张与后三张，中间明确标 `+N MIDDLE`，同时显示完整链总张数。两侧黄铜牌始终写出真实 L/R 数值，选中端有金框。当前手牌用金框表示可匹配所选端，用珊瑚框表示不匹配；底部还写出当前牌面、端点和 MATCH / NO MATCH。对手末次接牌若仍显示在端部，用青色细框标记。

自定义图集区域：dominoTable (0,0,640,384)，ivoryTile (640,0,128,128)，endBadge (768,0,128,128)，tableMark (896,0,128,128)，避开公共图形和 ASCII 字符。中文由公共 DOM 绘制，画布只用 ASCII。无外部图片或字体。

实际 960×540／1280×720 预览、完整侧栏、最大手牌及长链状态仍需由串行 QA 验证；本设计说明不声称已有签名或实体设备性能证据。
