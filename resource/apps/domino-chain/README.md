# 骨牌接龙 / Domino Chain

双方手牌、牌链和摸牌顺序全部公开的双端骨牌残局。每张牌有两个 0 至 6 的数字，数字与圆点双重显示；同一无序牌面只有一张。

三局双方起始手牌分别为 5、6、7 张，摸牌堆分别有 3、4、5 张，桌面已有一张起始牌。未用于当前牌局的其余双六骨牌不会进入游戏。

## 操作与接牌

- 左／右：选择自己的手牌，到两端停止。
- 上：选择牌链左端；下：选择牌链右端。
- A：把当前骨牌接到所选端，匹配的一面自动朝内。键盘空格、Z、Enter，遥控器确认，或手机右上区域。
- B：没有任何牌能接任一端时，摸一张牌；牌堆已空则跳过。键盘 X，或手机右下区域。
- P / Escape / START 暂停；R / SELECT 重试。

摸牌后仍是你的回合，光标会移到新牌。只要手中有任一合法接法，就不能摸牌或跳过。选错牌或端点不消耗回合。每次动作后松开再按，长按不会连续出牌。

牌链两侧的 L／R 显示准确端点，中段很长时以 `+N MIDDLE` 合并显示；端部骨牌与总张数仍是真实状态。对手手牌始终明牌，摸牌堆从 `NEXT` 指向的第一张依次抽取。

## 胜负与对手

你先出完手牌便立即获胜，对手不再回应；对手先出完则失败。当摸牌堆空且双方连续跳过时，比较手牌剩余点数，严格较少者获胜，平分需要重试。出牌和摸牌都会清零连续跳过次数。没有思考倒计时。

对手总是从合法牌中选点数和最大的一张，同分选固定编号较小者；一张牌两端都能接时优先左端。无牌可接就按公开顺序摸到能接为止，牌堆空仍不能接则跳过。固定编号按 `0|0, 0|1, …, 0|6, 1|1, …, 6|6` 排列；它没有隐藏信息、随机选择或答案表。

精确数据、朝向和输入约定见 [模型契约](docs/model-contract.md)。测试目录包含独立公开策略搜索，验证三局正常胜负路线、摸牌、堵局与点数结算；求解器和路线不随游戏资产打包。
