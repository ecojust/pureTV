# 旋环锁匠 / Rotor Locksmith — 公共设计

状态：公开规则已接受；实现与实际验证结果另行记录。本文不是执行结果，不含作者路线、私有解或自动驾驶程序。

## 核心玩法

玩家控制一枚沿顶部导轨进出的探头，同时拨转最外层齿环。三个带缺口的圆环按公开齿轮比同步转动；外环的实际有符号角位移直接决定两个内环的角位移。探头需要从外侧穿过三环，在中心取钥匙，再穿回全部三环并完整带出钥匙。绕过回程、只换颜色或把前进离散成格子都不满足本游戏。

- 摇杆向左 / 左方向键：外环逆时针转；向右：顺时针转。松开方向后齿轮组停止，玩家可以在环间安全空隙调环，再保持角度推进。没有自动漂移、惯性、隐藏相位或正弦调速。
- 按住 A：探头向中心连续推进。按住 B：探头向外连续退回。A+B 同按时只制动径向移动，方向输入仍可转环。竖向输入不移动探头。
- 手机沿用左侧 2/3 摇杆、右侧 1/3 上 A / 下 B 的完整触区。暂停是固定独立入口。原生确认键在局内按住映射 A，需要 `holdConfirmAsA:true`。
- 碰壁在本 tick 的首次真实接触处停住探头和整个齿轮组；扣 1 耐久、增加 1 阻力，并启动“松开全部操作后再试”的接触制动。保持顶墙不会逐帧扣血。松开后可以退回或反转；碰过的阻力不会因退回、取钥匙或暂停消失。

本作是手动驱动的角度与径向时机游戏：可以停环对齐再过，也可以同时拨环和推进；两种操作都用同一连续碰撞规则。停环是公开控制功能，不是自动驾驶或免碰撞捷径。时间预算约束反复试错。

## 世界几何与钥匙包络

单位为世界长度单位和角度度数。圆心是世界原点，角度 0° 指正上方，正角顺时针。探头中心始终在 0° 射线，径向坐标 `r` 从外向内减小。起点 / 完整提取线 `r=210`，取钥匙线 `r=18`。探头半径方向范围限制在 `[18,210]`。

只有探头及它携带的钥匙接触包络参与碰撞。导轨用细虚线画出，不是贯穿所有外环的刚性杆，也不能把它画成同等碰撞实体。这样已穿过的外环可以继续转动，不会凭空卡住一根并不存在的长轴。

- 每环实体是闭合厚环扣除一个角缺口：中心半径 R，径向半厚度 5；缺口中心角为当前 angle，缺口半宽 H。
- 空探头的接触包络为极坐标矩形：径向 `[r-2,r+2]`、角向 `[-2°,2°]`。
- 携钥匙时包络扩大为径向 `[r-4,r+4]`、角向 `[-5°,5°]`。这是公开的钥匙外形包络，不在独审或渲染时另猜一个圆形半径。
- 因而理想几何的径向碰撞带为 `(R-5-p,R+5+p)`，p 为当前包络径向半长；相对角允许范围半宽为 `H-a`，a 为当前包络角半宽。精确有效边界固定采用合同中的 1e-9 径向 / 角向余量，不是另一个可调的碰撞规则。恰好贴到有效径向边界或缺口角边界允许接触，不造成损伤；穿入实体内部才会碰撞。
- 中心取钥匙区域离最内环有足够间距，扩大包络不会瞬间穿墙。带钥匙到 r=210 时其内侧边缘为 206，超过三关最外实体边缘最大 193，整把钥匙已经完全带出。

## 三个公开锁芯

所有关卡为 90 秒 / 5400 个有效 tick，耐久 4，阻力初值 0。基础径向速度 7.5 单位/秒；每次碰撞增加 1 阻力，径速为 `7.5 - 0.5*resistance`，双向相同。存活时阻力最多 3，最低存活径速 6。三关规则、包络和胜负相同，仅齿轮比、半径、缺口和初相位不同。

## 成功、失败和完整往返

初态没有钥匙，A 将 r 减到 18 时取钥匙一次，随后提示“钥匙已取得，退回出口”。继续 A 停在 18，不会提前胜利。B 令 r 增到 210 且实际携钥匙才获胜；没钥匙回到起点只是空返。整个回程使用较大的钥匙包络，并对三个有限厚度圆环重新做连续碰撞。

每次有效 tick 依次处理输入、提出整段运动、检查首次接触并提交实际运动、处理接触损伤或非碰撞取钥匙/提取、最后判定时限。最后一个预算 tick 的合法完整提取可获胜；同 tick 碰撞耗尽耐久优先失败，不补发钥匙或胜利。碰撞但仍有耐久，若同时用尽 tick 则以时间失败。没有分段强制等待、自动角度吸附、关卡跳过或提前不可达失败。

## 可行性手算，非已通过运行

健康状态径向往返距离为 `2*(210-18)=384`，即 51.2 秒真实推进。它自然满足 30–90 秒目标，无需在出口人为等时间。

各环存在安全空隙。最挤的第三关最外环带在携钥匙时为 `(179,197)`，起点 210 仍在外侧；中间两安全空隙长度为 `64-18=46` 与 `64-18=46`。另两关也至少有 36 单位的完整安全空隙。在空隙中径向不动而拨转外环不会与任一实体相交。

任何环都可用左右选较短圆周方向把缺口调入 0° 附近的安全区；因为每个齿轮比非零，连续理想调节的最坏角路程为 180°。固定 tick 不保证中心恰好为 0°；每次至多再计一个 tick 的取整时间，最终偏差不超过一个该环角步长。最小安全半宽 21° 大于最大角步 2.4°，因此可停在安全区内。方向归零后所有环稳定停止，允许以正常径速完整通过有限厚度带。正反各过三环，健康连续理想调环时间上界分别为：

- 第一关：`2*(180/36 + 180/36 + 180/72)=25` 秒；加径向 51.2 秒为 76.2 秒。
- 第二关：`2*(180/42 + 180/84 + 180/84)=120/7≈17.143` 秒；合计约 68.343 秒。
- 第三关：`2*(180/48 + 180/96 + 180/144)=13.75` 秒；合计 64.95 秒。

六次调环各增加至多 1/60 秒的整 tick 取整余量，合计再加 0.1 秒；另保守预留初始中立确认 1 tick、两次径向端点各最多 1 tick，共 3/60 秒。健康径向步长 0.125 恰能整除 192，但可行性上界仍保留端点取整预算，不依赖这个实现精度巧合。三关健康上界分别约 76.350、68.493、65.100 秒。以上一般性几何论证不指定动作路线或具体过环时间；它保留至少 13.65 秒的健康容错余量，不承诺任意人类反应、任意低频浏览器回调或碰撞后仍必胜。所有普通通关仍必须由实际公开输入验证。

最小携钥匙角余量为第三关 inner 的 `26-5=21°`。最大每 tick 计划角移动是 2.4°；调入缺口安全区后可释放方向并穿环，不要求中心恰好对齐 0°。安全空隙的尺寸远大于单 tick 0.125 单位径向步长。测试不得把上述裕量当成某次实录成功的替代证据。
