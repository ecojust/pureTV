# 旋环锁匠 · Rotor Locksmith

拨转黄铜锁环，让探头穿过三层缺口，进入核心取钥匙，再把整把钥匙带回出口。三个圆环按不同的正反齿轮比同步转动；拿到钥匙后，探头占用的空间变大，回程也需要逐环对齐。

**左右拨环，A 推进，B 退回。** 手机左侧摇杆控制转向，右侧上半区为 A、下半区为 B，两块区域均可按住。松开方向会停住圆环；同时按 A+B 只停止探头进退，仍可拨环。在环间空隙停车对齐，再继续穿环。

键盘方向键控制转环，空格或 Z 为 A，B 或 X 为 B；Enter 在菜单开始，在局内按住也可推进。P／手机 START 暂停或继续，R／手机重试重新开始。

碰壁会在接触处停住整个机构，扣除 1 点耐久、增加 1 点阻力。先松开全部操作，再退回或反向转环；持续顶墙不会连续扣血。每次碰撞使进退速度降低 0.5，退回和取得钥匙都不会清除阻力。耗尽 4 点耐久或用完 90 秒即失败；进入核心只算取得钥匙，完整带回出口才算成功。

| 锁芯 | 外环转速 | 外／中／内环齿轮比 | 时限 |
| --- | --- | --- | --- |
| 黄铜三联 | 36°/秒 | +1、−1、+2 | 90 秒 |
| 反向齿室 | 42°/秒 | +1、+2、−2 | 90 秒 |
| 三倍锁核 | 48°/秒 | +1、−2、+3 | 90 秒 |

暂停会冻结位置、角度和计时；取消输入只停止操作，本局时钟仍继续。首次开始、取消输入或切换手柄后，先松开全部按键并让摇杆回中。重试才会恢复初始锁芯、耐久、阻力、钥匙状态和时间。
