# 电视启动器

每个启动器都有独立包名、APK、源码、layout.json 示例和原生渲染预览，可同时安装后在管理器切换。作者、版本、APK 大小和封面见[资源表](../README.md)。

| 启动器 | 界面风格与排布 |
| --- | --- |
| [Nova TV](nova/) | 参考 tvOS 主屏幕：大幅峡湾背景、底部六个应用入口、角落状态与控制中心 |
| [Aster TV · 星轨](aster/) | 深蓝星空、轨道图形、大时钟与错位悬浮卡片 |
| [Sol TV · 日光](sol/) | 暖白北欧风，大卡片与轻盈的不对称排布 |
| [Moss TV · 苔原](moss/) | 森林晨雾背景，右侧六应用矩阵 |
| [Forma TV · 构形](forma/) | 包豪斯三原色、几何拼贴与大小不同的应用块 |
| [Mono TV · 墨白](mono/) | 黑白编辑设计、大时钟、留白与线条构图 |
| [Drift TV · 流境](drift/) | 粉彩梦境背景、轻柔色彩与错落卡片 |
| [Circuit TV · 回路](circuit/) | 紫青霓虹、电路纹理与不对称模块 |
| [Pixel TV · 像素](pixel/) | 复古像素图标、游戏地图式的应用排布 |
| [pureTV Launcher](puretv/) | 浅色底、柔和配色卡片与简洁系统组件 |

以上启动器使用 layout v5，推荐搭配 Manager 0.3.8，以正确重现小尺寸时钟与导航组件。Manager 0.3.7 起动态检测已安装启动器的标准布局接口，切换为当前桌面后可编辑；无需逐个向管理器注册包名。布局只能添加当前电视已安装、可启动的用户应用，系统组件保持只读。首页与应用页可分别设置背景。

安装：从对应文件夹下载 APK，在管理器启动器页面导入、安装并激活，再使用“调整布局”。预览图来自实际 Android 页面在 Robolectric 中的渲染，使用测试应用；实际应用列表以电视为准，未进行电视实机兼容性测试。

已有自定义配置会保留。升级 Nova 后如需采用新的默认风格，可在“调整布局”中选择“恢复默认”。

## 添加其他启动器

每个启动器使用独立的软件文件夹，APK 不直接放在本级目录：

```text
launcher/
├── nova/
│   ├── NovaTV-版本.apk
│   ├── resource.json
│   ├── README.md
│   ├── LICENSE
│   ├── SHA256SUMS.txt
│   └── … 源码、源码归档或封面
└── 其他启动器/
    └── … 对应的 APK、说明和元数据
```

新增启动器至少提供真实 APK、resource.json、使用说明、许可证和校验文件。元数据说明作者、包名、版本、文件大小、签名、来源以及是否支持自定义；可以额外附对应源码及封面。自定义布局协议和 ContentProvider 接入说明见[开发与协议 README](../README-development.md#第三方启动器接入与动态检测)。仅放入静态 JSON 文件不会实现运行时读写接口。
