# Mechapede

Original game, procedural audio and machine-interior art by David Bachman, copyright 2026. Based on the MIT-licensed source at https://github.com/davbachman/Mechapede/tree/b29536289e3fc6010f7cd0acef817c2101033bcf. The original license is in LICENSE.

pureTV adapted native controller and keyboard input, focus/pause, read-only observation and the offline layout. The upstream mechanical simulation, renderer, trackball option and image remain included. The interface uses installed system fonts. The shared pureTV controller code is covered by docs/puretv-LICENSE.txt.
