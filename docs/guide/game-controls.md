# 游戏输入与连接显示规范

所有新开发或移植到 pureTV 的游戏按本规范设计和验收。更新现有游戏的输入、房间或界面时，复验受影响的路径。每款游戏在自己的说明中列出键位、支持的玩家数和恢复操作。

## 四种游玩方式

| 平台与输入 | 玩家应能完成的操作 | 实现参考 |
| --- | --- | --- |
| 电脑 · 键盘 | 从游戏入口用键盘选项、开局、完成核心动作、暂停和继续。保留游戏原有键位，输入存档名或种子时，字母键交给文本框。 | [电脑启动器和输入桥](../../tools/pc-games/) |
| 电脑 · 无线手柄 | 同一局域网内的 pureTV Wi-Fi 手柄可通过 `_puretv._tcp` 发现游戏，用方向和动作键完成菜单与玩法。手柄独立开局和操作，全程无需鼠标。 | [服务发现、九键与 ACK](development.md#controller-protocol) |
| Android TV · 手机虚拟手柄 | 电视菜单或暂停页显示当前房间的二维码。手机在同一局域网扫码，用浏览器直接进入触控手柄；方向、动作和开始键通过原房间作用于电视上的游戏。 | [Game Kit 房间与触控约定](../../resource/game-kit/README.md) |
| Android TV · 无线手柄 | 玩家也能直接用 pureTV Wi-Fi 手柄发现电视游戏、开局和游玩，无需手机。电视连接详情显示监听端口，默认 TCP `63485` 已被占用时公布实际分配的端口。 | [实体手柄协议与 SDK](../../puretv-joystick/README.md) |

电脑端可以提供独立程序，也可以复用统一启动器。使用启动器时，将游戏登记到目录，填写稳定的游戏 ID、可下载的正式 APK、大小和 SHA-256。键位映射按游戏保留，例如，保留经典游戏的 SELECT 功能，以及九键移植游戏中独立的 X、Y 动作。[电脑游戏目录](../../tools/pc-games/catalog.json) · [现有按键适配](../../tools/pc-games/pc-bridge.js)

## 连接信息放在哪里

- **菜单和暂停时**提供配对详情。电视展示可扫的手机二维码，区分手机房间地址与实体手柄的 TCP 地址。每个已连接的玩家显示席位、设备类型和连接状态；实体手柄详情显示它实际报告的设备 ID。房间令牌及会话凭据只用于连接。
- **游玩中**收起二维码、地址和长说明。用既有侧栏或 HUD 的空闲角落显示简短状态，例如「1P · 手机」或「2P · 手柄」。状态提示不抢焦点、不拦截按键或点击，避开角色、瞄准区、比分及暂停按钮。玩家加入或离开时，画布的位置、尺寸和宽高比保持稳定；小屏双席应在预留区域内排得下。
- **状态变化时**根据当前房间更新对应席位，断开后清除或标明失联。状态卡读取输入层已经采样的状态，避免重复读取把短按提前消耗。若游戏首帧绘制失败，仍在显示的房间面板应继续更新。[移植游戏输入与状态卡](../../joystick-games/shared/web/input.js) · [双手机布局实测](../../resource/game-kit/qa/controller-browser-2026-11-20/compact/README.md)

## 暂停、断线和返回

- 按席位处理按下、持续按住、松开与取消。窗口失焦、手机触摸取消或手柄断线时清空受影响来源的输入。一次短按只生效一次；恢复连接时先同步当前按键，已按住的动作键须松开再按。双人游戏保留另一席的身份和输入。
- 区分玩家主动暂停、参与者断线和系统弹窗造成的暂停。主动暂停要等玩家明确继续。实体手柄重连后按该游戏说明重新按 START 或确认。若游戏支持手机在取消退出弹窗后自动继续，要等参与手机的新房间状态到达，并确认游戏此前正在运行。以《极品二手车》为例，同样选择「继续游戏」，驾驶中的赛钟应恢复，原已手动暂停的赛钟应保持停止。[Android 系统弹窗验收](../../joystick-games/used-car-racing/docs/releases/0.1.7/verification.json)

## 新游戏验收清单

- [ ] 分别用电脑键盘、电脑无线手柄、电视扫码手机、电视无线手柄，从正常入口完成选项、开局及至少一个能在画面或游戏状态中确认的核心动作。手机测试要扫描电视实际绘出的二维码，在独立触控页面按下并松开；无线协议测试用官方 SDK 或实体手柄核对设备身份与输入响应。
- [ ] 比较接入前、游玩中、断开后的画布边界和截图。在 960×540、1280×720 检查支持的界面语言；小屏连接区另测 720×480。检查状态文字、二维码和关键 HUD 的边界。支持双人时加入第二席，分别输入并离开其中一席，核对剩余玩家。
- [ ] 实际操作主动暂停、失焦、断线重连；有原生退出弹窗的游戏还要测试取消返回。核对游戏进度、暂停状态和下一次按键。Wi-Fi 发现分别检查默认端口与端口被占用时公布的端口。
- [ ] 随该款游戏记录版本、已测平台、输入设备或 SDK、操作和可观察结果，并关联发行文件 SHA-256 与截图或报告。注明哪些结果来自实体设备、电视模拟器或独立浏览器，供发布时复核。[电脑实玩方法](../../tools/pc-games/qa/README.md) · [手机房间与手柄实玩方法](../../joystick-games/qa/controller-input/README.md)
