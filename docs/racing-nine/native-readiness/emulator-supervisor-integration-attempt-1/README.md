# Default-off Pon emulator launch supervision: integrated QA source

This patch implements the previously reviewed mechanism and restores the disposable SDK launcher afterward. It adds only android-emulator-supervisor.py, its dedicated tests, and an optional input/hooks in the existing original-package runtime reuse workflow. The existing Backroad installation opt-in is preserved. `supervise_pon_emulator` defaults to false and is restricted to the exact original Pon source/run/export and racing-01 single-game selection. No game, APK, GPU option, RAM setting, or emulator flag changes.

The pre-launch hook retains the original ELF bytes in the same directory, records SHA/mode, atomically installs a small entry shim and compares original/wrapped `-version` exit/stdout/stderr exactly. Unexpected version, output, timeout, truncation or installation failure triggers restore. Queries call the original directly. AVD launch must use the exact original argv0 and arguments. The action is pinned to its already-resolved a421e438 source so the inspected hook contract cannot drift. The upstream action catches pre-hook errors and can still attempt to launch the restored original AVD; the new mandatory `assert-ready &&` guard prevents QA from running in that case.

The supervisor owns the real launcher child, forwards original stdout/stderr to preserve upstream listeners, and retains bounded per-stream logs with total counts/hashes. It records real wait return code/signal, PID/starttime/executable hashes, and distinct supervisor intervention. It does not relabel a forked descendant: QEMU exit is unknown unless the same owned PID/starttime was observed executing QEMU inside this SDK. Existing bounded kernel/environment diagnostics remain in use; no additional kernel flag is injected.

Fifteen actual local ELF/process fixture tests passed: default-off/wrong-artifact selectors; installation atomicity and rollback; original/wrapped query equality and exit/output/budget negative cases; repeated/existing shim rejection; exact argv0/args and output forwarding; exit0/23, SIGKILL/SIGTERM; bounded over-limit output; same-PID exec versus unowned fork; supervisor signal escalation/cleanup; and normal/failure restoration. actionlint and six embedded Python blocks passed. Exact execution source and logs are retained. These results are local QA implementation evidence, not an Android emulator run. Root alone will freeze and dispatch a single real diagnostic run; actual launcher compatibility and exit cause remain unverified.
