当前建议将 **Dirt Crown 与 Kart Rush** 纳入跨组前九画面复核。Dirt 有 20 赛道、7 地区、26 生涯赛事和六类升级的源码支持，但本轮实际仍在起跑倒计时，必须把驾驶手感低信心带入后续评选。

Kart Rush 的实际角色/车身辨识、赛场构图和源码内容广度更好；源码有 8 个普通赛道、7 站大奖赛，试跑没有覆盖全部内容。Space 后重开倒计时、菜单按钮持焦和暂停的可见状态需专项处理，不能直接把本次试跑描述为完整可交付版。

Mini 的固定源实际有 **5 条赛道**；Long Road 是秋林、夜间针叶林、草原、海岸 **4 环境**，不是完整四季系统；Rally Navigator 的 OpenRouter 是可选动态副驾，基本驾驶有无 Key 的预设模式。Frostline 是单雪地赛道，不能由道具数量推断多赛道生涯。

每款 `review.json` 分开列出实际观察、源码确认但未玩到的功能、许可和依赖。`attempt-*/report.json` 保留截图 SHA256、文档/脚本响应哈希、原始异常和正常输入动作；`executed-review.cjs` 是实际执行脚本。图片标签 `driving-straight` / `steering` 仅是自动化步骤名：Dirt Crown、Frostline 与 Rally Navigator 对应图片仍在倒计时。Rally 退出后的 73 km/h 是游戏自带吸引演示，不能作为玩家驾驶证明。

所有 `attempt-*` 截图为本轮 Chromium 1280×720 原游戏渲染，没有注入模型、时钟、比分或胜负。Mini/Long 首轮 `/tmp` 满盘失败原样保存，第二轮只将临时目录改到 `/dev/shm`。Dirt 的固定源重试单独保留原在线失败，36 文件闭包中的 31 个实际文档/脚本响应与固定原源哈希完全一致；以前丢失的未提交 pureTV 适配没有恢复，也不复用为本次成果。

Dirt Crown 固定根许可证为 MIT；另外五款未确认明确根许可。外部库许可不能替代项目许可。Dirt 的 `author-preview.jpg` 另有来源标记，是作者车库图，不属于本轮实玩。

本组没有账号登录、付费购买、付费 AI API 调用、实体设备或三平台包验证。根盘满，源检查缓存临时位于 `/dev/shm/racing-review-rally/`，永久复查使用记录中的固定提交、URL 和哈希。
