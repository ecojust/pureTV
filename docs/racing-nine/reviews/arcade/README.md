全部评分使用画面 50 / 玩法 50 的候选目录细则；GitHub 星标、许可证与本机软件 GPU 帧率不计分。实际看见/操控与固定源码功能分别记录在 comparison.json；保留每次实际脚本、正常输入命令、只读状态和原始截图哈希。

Poly GT 的 79 是有界估分，不能和实际驾驶确认过的同分等量看待，bestGameplayImage 保留 null。实际第三次通过 Quick Play 展开、正常填写 Guest 名称到 Time Attack 赛道选择，但列表一直加载且没进入比赛；文件名 driving 不表示发生驾驶。所有原尝试保留，未做模型/时钟改写。Neon/Turbo 最后补充重试在拿锁之前取消，以便选中候选验收；这是调度决策，不是游戏运行失败。

每个浏览器样本均独占 `/dev/shm/puretv-racing-browser.lock`，预算只在实际拿锁后开始。KART 的一次有界延长允许未改动的倒计时自然结束。screenshot-validation.json 校验全部本轮1280×720截图与原报告SHA；不能把软件渲染速度推断成实体电视性能。
