# 游戏视觉更新 0.5.2

**状态：经典游戏检查及两款现代游戏的 3D 专项已通过；完整联动、Android CI、签名发布仍在进行，实机验收尚未完成。** 九款游戏的源码版本统一为 0.5.2，当前下载和 APK 元数据仍属于已发布的 0.5.1。

本轮按各作品对应原版的表现选择渲染方式。七款 FC/NES 游戏保留各自的像素比例、二维图块和人物表达；Coast Kart 与 Cozy Island 分别参考现代三维赛车与岛屿生活游戏，重建实际 3D 场景。统一版本号用于整组发布，不要求九款使用同一种美术风格。

## 已确认的经典游戏改动

| 应用 | 视觉参考对象 | 本轮实际改动和范围 |
| --- | --- | --- |
| Tank | 1985 年 FC/NES《Battle City》 | 本轮审查保留现有像素战场，没有修改渲染器。 |
| Jackal | NES 美版《Jackal》 | 本轮审查保留现有像素关卡，没有修改渲染器。 |
| Magic Jewelry | FC《Magic Jewelry》 | 单人画面改为大棋盘、左侧 NEXT、右侧完整举火炬雕像和计数；重画宝石、红框网格与夜景。等级按原版从 000 显示，同步游戏、侧栏和手机。双人保留独立棋盘与状态。 |
| Tetris | Nintendo NES《Tetris》 | 重画灰色迷宫背景、方块样式及经典单人布局：统计在左、棋盘居中，分数／NEXT／LEVEL 在右。双人扩展顶部信息移开边框，避免数字底边压线。 |
| Mighty Bomb Jack | 1986 年 FC/NES《Mighty Bomb Jack》 | 本轮只修正 8 像素 HUD 字体与字段对齐；场景、角色和动画仍有独立简化，不能称为完整视觉复刻。 |
| Adventure Island | FC/NES《Adventure Island》初代 | 分数、体力条和生命标记直接叠在场景上，移除遮挡场景的实底 HUD；保留对应像素人物和场景比例。 |
| Super Mario | 1985 年 FC/NES《Super Mario Bros.》 | 分别绘制小／大形态的站立、跑步、跳跃、蹲伏姿态以及火焰／路易吉配色，避免将小形态直接拉高充当大形态。 |

这些改动均以所选作品为依据；自行绘制的姿态、宝石、雕像和场景并不等于原版逐像素、逐帧复刻。具体内容与仍存在的差距见各游戏 `docs/reference.md`。

## 两款现代游戏：实际 3D 场景

| 应用 | 视觉参考对象 | 实现方向与待核对内容 |
| --- | --- | --- |
| Coast Kart | 《Mario Kart 8 Deluxe》 | WebGL 1 立体赛车／车手、道路、护栏和四种主题景物，追车镜头及双人分屏；路面细纹、海浪、弯道箭头、道具与漂移反馈已接入。 |
| Cozy Island | 《集合啦！动物森友会》／Animal Crossing: New Horizons | WebGL 1 圆润人物、建筑、树木、家具、海岸及阴影；近景跟随、附近同屏／远处分屏、独立室内视图、遮挡淡化与昼夜已接入。 |

实际三维重建应具有空间几何、深度遮挡和镜头关系，仅把二维图形平滑放大或以屏幕坐标计算透视不能作为完成依据。两款赛道、岛屿、角色与素材仍由本项目独立制作，有限内容和游戏规则不等同于商业原作的完整移植。

整区手机操作、双人状态、暂停与断线恢复、存档及退出清理继续纳入检查。已通过模型测试，不代表新的三维渲染、电视 GPU 性能或实际手机操作已经验收。

三维专项显式使用 WebGL 1 并检查实际绘制，不能由二维回退替代。Coast Kart 的连续分屏绘制复用 25 份几何和 5 份纹理；Cozy Island 的 60 件家具及反复预览检查中，GPU 几何 67、纹理 3、保留几何 72 均未持续增长。以上为受控资源检查，使用 ANGLE／SwiftShader 软件渲染，不能据此推断电视 GPU 帧率。完整截图集成同时检查实际 GPU 绘制调用、上下文状态及错误，兼容回退另行验证并显示标记。

只读视觉复核查看了三款平台游戏的受控 gameplay 图、Mario 原生姿态图，以及两款拼图游戏的中英文单人主图和双人图。Mario 大小形态未见旧有纵向拉伸；平台 HUD 未见明显重叠或数字裁切。Tetris 双人顶部数字压框问题已在复核后修正；Jewel 的右上计数和双人标题避开了云带，000 等级与侧栏一致。截图检查限定于这些视图，不代表全部关卡、动画和原机画面均已匹配。

本轮检查产物位于工作区的 `scratch/visual-052/`；它们与已发布资源预览分开。既有 APK 和仓库下载图片不能用于证明 0.5.2 已发布。
