# 手柄客户端侧边标识

本轮为根 README 的20款游戏及霓虹飞车macOS客户端增加连接标识。当前源码和专项检查进行中，正式新版安装包尚未发布。

连接后，侧边显示手柄图标、1P／2P席位和完整连接ID。双手柄分别显示，断线时移除对应卡片，同一手柄重新连接后继续显示原ID。游戏收起二维码时，连接标识仍然可见。ID较长时换行，避免挤掉席位和连接状态。

当前固件未上报RSSI，暂不显示信号强度。默认TCP端口仍为63485，电视和手柄需在同一局域网。

[版本与交付清单](rollout.json)记录本轮目标版本和实际状态。[模型复用核对](model-reuse.json)证明20款玩法模型与上一正式APK相同；本轮仍将使用新版安装包检查新侧栏并更新实际画面。上一轮完整玩法及Used Android宿主崩溃限制见[原接入记录](../readme-controller-support/README.md)。

实体电视、手机和ESP32联调尚未进行。UI专项、完整玩法、软件模拟器和实体设备结果分别记录。
