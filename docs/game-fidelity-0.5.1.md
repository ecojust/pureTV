# 游戏还原度复核与 0.5.1

本轮继续检查九款游戏，重点是原作核心规则、完整交互流程及玩家能感知的反馈。九款游戏使用 0.5.1 版本号，沿用 0.5.0 发布证书；已安装 0.5.0 的设备可以覆盖更新。其他应用与启动器不随本轮游戏更新改变版本。

## 本轮修正

| 游戏 | 实际差距与改进 |
| --- | --- |
| Tank | 复核 35 张地图、敌人波次、移动／炮弹数值、道具、双人及关卡编辑回归；本轮没有新增玩法，保留已核对的模型与整区开火手柄。 |
| Jackal | 第 3 关的两段激光原来都使用长光束。现在读取真实地图事件的 source_page，屏 7 用长束、屏 8 用短束，同时切换两端预警闪光位置。依据 Bank6 的 Level3LaserState0。 |
| Tetris | 修正首次 3 帧／随后 2 帧软降、落块后需重新下拉、横移与软降组合规则，以及同帧横移／旋转的顺序；消行擦除按动画节拍开始。高速等级仍由较快的自然重力主导。 |
| Magic Jewelry | 大连锁跨过多个奖励阈值后，逐列兑现魔法列；先发已赢得的魔法列，再判断隐藏区域顶出；完整连锁落稳后推进速度和场景配色。两名玩家的进度独立。 |
| Mighty Bomb Jack | 绿色能力真正限定为 5 秒：敌人转为可收集金币，未收集者到时恢复；最后一秒闪烁提示，恢复时有短暂保护，续用能力不会复制敌人或奖励。 |
| Adventure Island | 加入隐藏云朵奖励流程：武器经过隐藏点消失作为提示，停留召云、乘云进入奖励段，收集水果后落回下一检查点，保留装备与主关卡已拾取状态。 |
| Super Mario | 旗杆抓握、滑杆、走入城堡、时间结算与末位 1／3／6 烟花；桥斧逐段塌桥、Boss 落下。另修火球侧撞墙与穿透多敌、大形态进入奖励房插地、道具出砖时提前拾取及部分关底楼梯挡路。 |
| Coast Kart | A 持物拖曳防御、松开投掷，摇杆上下选择方向；道具概率随名次变化，AI 使用相同规则；加入来袭提示、拦截反馈，并修复高速及跨终点线碰撞顺序。 |
| Cozy Island | 三种昼夜昆虫巡游、接近惊飞、举网慢走及松开 A 按朝向挥网；两人共享实体、物种背包、出售、图鉴与首次发现奖励，兼容已有鱼类图鉴和旧存档。 |

具体来源、参数依据和独立调校范围见各游戏的 `docs/reference.md`；Jackal 的敌人细节见 `docs/reference-enemies.md`。

## 验证方式

模型回归覆盖规则边界、两人状态隔离、暂停和断线。浏览器集成通过实际手机控制页面发送输入到模拟电视桥接，验证双语界面、动作连通、恢复、退出清理与不同电视尺寸。Coast Kart 另外通过 `tests/combat.mjs` 检查持物、后抛、漂移与防御并用及来袭拦截；悠岛捕虫后的物种、鱼类和昆虫图鉴通过真实页面重载核对。

本轮本地验证通过 271 项模型／渲染行为测试及九款游戏共 18 个双语集成场景。兼容测试检查 Chrome 61 语法、启动、故障提示及退出清理；悠岛另有 5 个真实运行时输入回归，覆盖原生暂停、隐藏、失焦以及暂停期间新按住 A，确保恢复后不产生幽灵捕获或存档奖励。两款游戏还使用持久取消序号区分正常松手和触摸中断；取消摇杆、B 或同区另一根手指不会撤销仍有效的 A。服务端超时会取消待动作，后续心跳不会覆盖该标记。两款 LAN 服务另通过共 24 项纯 JVM 协议回归，完整 Android 检查由 CI 执行。

```sh
node --test resource/apps/{tank,jackal,jewel,tetris,bomb-jack,adventure-island,super-mario,coast-kart,cozy-island}/tests/*.test.cjs
CHROMIUM_PATH=/usr/bin/chromium node resource/apps/coast-kart/tests/combat.mjs
```

各游戏另外提供 `tests/controller.mjs`、`tests/compatibility.mjs`、`tests/capture.mjs`。浏览器依赖由 `npm ci --prefix desktop` 安装；Jackal 需按其工具说明准备预览素材。

## 尚未达到的还原范围

- 马里奥的 32 关仍含公共地形／敌人模板，缺少若干原作特有敌人和城堡迷宫；冒险岛、炸弹杰克的地形、道具布局及部分秘密路线也使用独立设计坐标。本轮的云朵奖励段不是原版奖励房逐格复刻。
- 马里奥 32 关路线回放移除了敌人来隔离地形与出口可达性；它不证明普通玩家能按原作节奏完成全部战斗。其他受控首领、道具、结算和画面 fixture 同样与自然游玩证据分开记录。
- Coast Kart 和 Cozy Island 是参考相应类型玩法的原创游戏；其赛道、岛屿、角色和有限内容量并不等同于商业原作。新增攻防与捕虫缩小核心交互差距，不代表完整内容复刻。
- 画面、音乐及大部分运动数值仍有独立绘制和调校；尚未完成逐帧硬件对照，也未完成电视与真实手机的实机验收。

本轮发布不会改变 0.5.0 已统一的签名证书。旧证书的 0.4.x 及更早版本仍不能覆盖安装；0.5.0 升级到 0.5.1 不需要卸载。
