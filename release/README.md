## 中文有声教程

教程围绕连接电视、选择默认桌面、寻找与安装小软件、交流和分享创意展开。主题是「你的每一次创作，都值得被公平对待」。视频包含普通话合成旁白与画内中文字幕，1920×1080，约 10.88 MB。

管理器画面来自官方未修改的 Linux 0.5.0 原生客户端实录，展示真实市场、下载到待安装列表和本地 APK 导入。连接电视、默认桌面与安装步骤结合清楚标注的步骤卡讲解；本次没有连接实体电视或执行电视安装。创意与 AI 流程卡是创作方向，不代表管理器内置 AI 编辑器；软件分享只展示现有入口，没有提交作品或自动公开上架。

开头和结尾共使用 6 秒本项目已有游戏演示，分别标注「极品二手车」与「孤胆枪手 TV」，保留原有画面说明。配音采用通用合成声音，背景音为本次原创合成器音轨。录屏、游戏片段、字幕和音频来源及剪辑时间段详见 JSON。

## 0.5.0 功能演示

[播放 / 下载 0.5.0.mp4](0.5.0.mp4) · [制作与校验信息](0.5.0.json)

53.3 秒 · 1920×1080 · H.264/AAC · 约 2.04 MB。

视频演示两项功能：在 0.5.0 原生客户端内阅读论坛正文与跟帖；使用原版 0.4.19 客户端真实检查并发现 0.5.0 更新。两个版本的画面分为独立章节，未演示下载、安装或重启完成。

论坛取自 Gitee 的公开内容，录制时有 1 篇帖子、1 条跟帖。客户端提供前往 Gitee 发帖与回复的入口；本视频不提交帖子或回复。

画面取自 macOS 原生客户端的带时间戳连续 PNG 截屏序列，按原始采样间隔保持画面，另加片头、章节标题与片尾；素材来自连续截屏，并非原生录屏视频流。后期仅裁去客户端外的桌面、等比例缩放并裁剪等待时间，章节转场使用短淡入淡出；字幕和标识位于客户端画面外。原生序列采样约 1.8–1.9 fps；30 fps 是成片导出帧率，重复已有原生截屏，不插值或补造客户端画面与鼠标动作。实际采样率、取材时间段、截屏哈希与输出参数见 JSON。背景音为本次制作的原创合成器音轨，无外部音乐采样或旁白。
