# Finland stage screenshot samples

Each file contains the RGB24 bytes of a 160 × 90 nearest-neighbour reduction of an original Android system screenshot, compressed with zlib. The tests use the same size and sampling regions as the runtime check. Both screenshots show the Swift Mk1 in the Finland quick stage with stage-default conditions.
