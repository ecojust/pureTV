# 星落舰队 · 中文试玩记录

2026 年 11 月 27 日，在 Linux Chromium 156.0.8078.79 的 960 × 540 窗口打开离线游戏页。软件 WebGL 2 加载指挥甲板用时 19.35 秒，场上有 35 艘舰船。界面、舰种、造舰、研究和指挥说明均提供中文。[开始菜单](menu.png) · [行进中的采集舰](playing.png) · [暂停界面](paused.png)

- 键盘 Ctrl+A 选中全部 15 艘我方舰船。
- 软件手柄通过 pureTV SDK 回环 TCP 发送 START 开局、X 切换至 6 号舰、方向键移动光标、B 下令。该舰从一处世界坐标移动至另一处，两次采样时显示采集指令。
- 用最终构建另开一局，仅在原作画布上读取订单。按下 SDK 的 B 键前，9 号舰正在自动采集 355 号矿石。抬起后收到手动移动命令，目标世界坐标为 (−17425.22, −1594.35, −10254.30)。[原作订单前后记录](order.json)
- 通过浏览器标准 Gamepad API 模拟左摇杆，光标随之移动。按 START 暂停后，400 毫秒内的对局时间、舰船位置和选择保持不变。按住左方向时断线，输入释放，游戏自动暂停。重连后再按 START 恢复。
- 离线测试未记录页面异常、控制台错误、站外请求或本地资源错误。本次浏览器实测使用软件客户端、模拟摇杆和软件 GPU。实体电视与实体手柄尚未实测。[浏览器报告](browser.json)

游戏封面从实玩画面截取，中间的行星环和两艘舰船均为原作实时生成。缩放及裁剪参数见来源表。最后两处显示文案“自由编队”和“混合姿态”在首次采图后补齐，已对比确认主程序除此两处字符串逐字节一致。构建使用完整的固定上游和本地音频，重新拉取该提交后逐文件重建通过。[资源校验](source-check.json) · [封面来源](../upstream.json)

从游戏目录运行 `python qa/play.py /tmp/starfall-qa` 可复现输入与断线测试并生成截图。追加 `--order-only` 可单独验证手柄 B 是否改变原作指令目标。
