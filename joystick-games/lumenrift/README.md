# Lumenrift · 光隙守望

[Android TV 0.1.0 签名 APK](lumenrift-0.1.0.apk?raw=true) · [扫码连接手机](../../docs/guide/README.md#在电视上扫码加入) · [在电脑上游玩](../../docs/guide/README.md#在电脑上玩)

在夜色、日光或四季战役中守住中央的光源。用围墙改变敌人的路线，在路边架设炮塔、在矿脉上建造采集站。每个战役都有自己的建筑、敌人和音乐。撑过第 30 波后可以继续挑战无尽模式。

从 [dist/tv.html](dist/tv.html) 打开离线版。选择战役和难度后按 START 开局。游戏保留原版八种语言；首次进入时会依据系统语言选择，未匹配时显示英语。

| 场景 | pureTV 手柄 | 电脑键盘 |
| --- | --- | --- |
| 菜单 | 方向键切换选项，A 确认；START 开始、继续或执行主按钮，B 返回 | 方向键、Enter、P、K |
| 选建筑、升级或技能 | X 打开操作栏，方向键切换，A 选中 | L、方向键、Enter |
| 建造或选择目标 | 方向键移动方格光标，A 在该格放置或使用选中的技能；B 取消 | 方向键、Enter、K |
| 提前迎战 | Y | I |
| 暂停或继续 | START | P |

升级一座塔时，先按 B 收起建造工具，在已建的塔上按 A，再按 X 打开该塔的操作栏。菜单中的滑杆和语言选择用左右调整，用上下离开。也可使用原版鼠标、触控与快捷键，或使用主机通用数字小键盘。画面失焦或当前手柄离线时会暂停，重连后按 START 恢复。可在标题页继续最近的十二份本地存档。

## 重建与验证

在本目录运行以下命令。浏览器回归使用本机 Chromium 或 Google Chrome，也可以通过 `CHROMIUM` 指定路径。

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run build:check
npm run test:browser
```

规则回归覆盖六个战役的建造、迎战与存档槽复用。浏览器回归从标题页操作，建设弩塔、召唤第一波、暂停、断线并载入存档。键盘、Wi-Fi 输入帧和手机输入帧分别使用 960×540、1280×720 和 720×480。实际主机协议与实体设备需分别验收。来源和许可证见 [NOTICE.md](NOTICE.md)。
