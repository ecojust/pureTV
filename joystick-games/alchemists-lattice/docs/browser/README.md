# Chromium 手柄验收 · 0.1.1

在 960 × 540 和 1280 × 720 两个视口均从标题经过学徒对白与地图，选中并放置手牌，完成暂停、断线、持 START 重连与手动继续。两种视口内，原画背景、任务栏、9 × 9 棋盘、手牌与右侧手柄信息可同时辨认。暂停菜单保留了棋盘画面。运行期间未访问站外资源。

测试读取真实 Web Audio 的状态与时钟。游戏运行时为 `running`，暂停后为 `suspended` 且时钟停止，断线、失焦和宿主挂起时也为 `suspended`。恢复窗口和重连均保持暂停，松开后新按 START 才恢复音频。测试使用 Chromium、Mesa 软件 WebGL 2 和浏览器内的宿主按键夹具。[原始报告](report.json) · [实际棋盘](playing-1280.png) · [执行脚本](verify.py)
