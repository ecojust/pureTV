# QQ 飞车 · pureTV 手柄版

基于 riba2534 的 [qq-speed](https://github.com/riba2534/claude-opus-5-5-demo/tree/54adc1fb64155f9dd7c1c90ecae7b8185ac540b8/qq-speed) 适配。保留 11 城、情迷爱琴海、法老金字塔、雪地大冒险四张赛道，以及竞速／道具两种模式。上游的车辆、场景、漂移集气、氮气、小喷、双喷、跳台和六车比赛沿用上游实现。

## pureTV 手柄

电视／Mac 和手柄连接同一局域网，使用 GPIO 23 搜索游戏。默认 TCP 端口 63485，通过 `_puretv._tcp` 发现。当前是单人驾驶；侧边显示实际手柄 ID，未上报 RSSI 时不显示信号强度。

| 按键 | 比赛 | 菜单 |
| --- | --- | --- |
| 上／下 | 油门／刹车、倒车 | 移动焦点 |
| 左／右 | 转向 | 移动焦点 |
| A | 按住配合转向漂移 | 确认 |
| B | 使用氮气／道具 | 返回／继续比赛 |
| X | 小喷 | — |
| Y | 复位至当前赛道位置 | — |
| START | 暂停／继续 | 开始比赛 |

道具换位、视角、音乐开关和切歌都在暂停菜单中，可以只用方向键和 A 操作。键盘和触屏操作保留，可展开大厅的键盘说明。失焦、切到后台或手柄断线会清除输入并暂停，需要主动继续；取消漂移不会奖励小喷。

首版默认「流畅」画质。游戏需要 WebGL 2；Android API 版本达标仍需系统 WebView／GPU 支持，无法初始化时会显示明确提示。实际平台安装包与验收状态由本目录交付记录说明，不把浏览器测试当实体电视或 ESP32 联调。

## 源码与重建

在本目录执行：

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run build:check
```

`dist/tv.html` 是包含本地 Three.js 与所有程序化资源的单文件产物，不依赖 CDN；同目录 `THIRD-PARTY-NOTICES.txt` 随安装包保留完整许可。`build:check` 重新打包到内存并逐字节比较，不修改已冻结产物。Android／Mac 宿主共用该文件，由上级 `shared/` 构建工具打包。

`window.JoystickGameQA.snapshot()` 只读公开当前菜单／比赛、车辆与已消费的手柄缓存，供正常输入验收；没有模型写入、改时钟或强制通关入口。原先上游的可写 `window.game` 调试引用不再导出。

来源、非官方同人属性和许可事实见 [NOTICE.md](NOTICE.md)。
