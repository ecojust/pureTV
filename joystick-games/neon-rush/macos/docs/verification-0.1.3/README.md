# macOS 0.1.3 · 修复左右转向

源码冻结于 `cc04129f0369c1e9f9262ab798b353f276f1dc3b`。[工作流43724380197](https://github.com/ecojust/pureTV/actions/runs/43724380197) 的构建、ARM／Intel验收和导出全部成功。应用版本0.1.3/build3，默认TCP63485和稳定连接行为保持，Android0.1.1 APK未重打包。

## 根因与修改

原始协议、原生桥接和公共runtime均使用RIGHT−LEFT作为输入x。车辆世界坐标以+Y向上、+Z向前，追尾相机的右方向为`(-cos(yaw), 0, sin(yaw))`；正yaw实际转向画面左侧。旧模型把正x直接转换成正yaw，旧单测又按同一世界坐标假设断言RIGHT为正，所以未能发现视觉反向。

本次在车辆输入边界将屏幕x转换为世界yaw方向，保持侧滑和前轮一致。AI控制输出同步转换，使AI的物理轨迹维持原行为；不互换协议按键，菜单左右选择不受影响。渲染器增加实际相机矩阵的只读诊断，方向验收观察普通LEFT/RIGHT输入下的车辆位置并投影到起始相机，不依赖AI或世界坐标正负假设，不写模型、时钟或相机。
