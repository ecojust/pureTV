# 光球挑战 0.1.0 试玩记录

从中文菜单进入三维场地后，手柄 A 点亮中央青色光球，得分从 0 增至 100。随后检查光标、视野缩放、暂停与断线重连。使用鼠标逐一点亮余下 14 颗光球，共完成 15 次脉冲、15 连击，命中率 100%，最终 3655 分、S 级。结算后再次按 A，第二局从 0 分开始。[实玩录像（79 秒）](gameplay.mp4) · [结算画面](result-1280.png) · [原始记录](report.json)

验收运行于 Linux Chromium 156.0.8078.79。软件手柄客户端通过本机回环 TCP 连接桌面宿主，标准手柄接口通过游戏手柄测试夹具提供摇杆输入，浏览器通过键鼠事件移动光标和点选球体。主动暂停后分数与计时保持稳定。按住方向键时断开 TCP，游戏暂停并清除转向状态，重新连接后按 START 恢复。记录中外网请求、脚本异常与加载失败均为空。实体电视和实体手柄尚未实测。[暂停画面](paused-960.png) · [复现脚本](../../qa/play.py)
