# 星球点灯人 · KINDLE

在极光下环绕小行星，寻找并点亮九座灯塔。方向上下行走，左右转向，A 跳跃（长按滑翔），B 点灯，X 呼唤，Y 奔跑，START 开始或暂停。

电脑小键盘 8/2/4/6 对应方向，5 对应 START，1/3/7/9 对应 A/B/X/Y。运行 `npm ci && npm run build` 后打开 `dist/tv.html`。
