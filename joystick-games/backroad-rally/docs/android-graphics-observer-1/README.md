# Independent graphics Observer: local preparation

This preparation does not repair or repackage Backroad Rally. The original v7 SDK/model checks passed, while the actual Android playing screenshots lacked the car and track. Those 142 frozen files remain unchanged. This new test APK collects the evidence missing from that run.

The target stays the original `4b6cf0b8cba288eae66bcae2ef2784acc279a695` package from run `44625676430`, artifact `14579726223`: 105,024,551 bytes, SHA256 `2cd35f145f5362264a720708325c22e283a3828d21899058f17422ba87103c08`. Its v7 normal installation returned `Success` in 10.57 seconds; no install confirmation ran. This target35 package is different from the old target29 package guarded by the per-app confirmation helper. A new install failure is only observed, never retried or clicked through.

The separate unsigned Observer has package `com.ecojust.joystickgraphicsqa.backroadrally`, minSdk 26, targetSdk 35, and `testOnly=true`. It only attaches a console callback when the original WebView has no Chrome client and has not loaded a URL. The frozen host creates its WebView in `onCreate`, then starts its room and loads the entry document after `onStart`. The diagnostic neither replaces the WebViewClient nor installs game/input hooks. Actual lifecycle attachment is still untested until the one CI run.

`/graphics` reads the existing cached `JoystickGameQA.snapshot()` once and records canvas dimensions, computed styles, ancestors, the center-point DOM stack and bounded resource timing entries. Controller identity/service/keys are copied from that same cached frame; the phone-room URL and QR are omitted. It never calls `getContext`, `getError`, `readPixels`, the consuming native snapshot, renderer setters or clock/model setters. No GL-context availability is inferred from a new context. `/console` retains at most 256 events and 262,144 payload bytes.

The main-thread observation uses nonblocking `Handler.post` and a ten-second latch; a queued task is cancelled on timeout. A late callback only changes that abandoned request's private result. Thus a busy WebView does not indefinitely block future console reads. Headers have a shared 8,192-byte budget and a shared twelve-second deadline, plus a per-blocking-read twelve-second socket timeout: the conservative header wall upper bound is 24 seconds, not twelve.

The separate driver first runs the unchanged original package/Observer input guards and independently verifies the new signed test Observer. It starts only the new instrumentation. Original SDK messages pass through the existing byte-transparent ACK recorder. It executes original plan indices 1–20 and 24–33, retaining each selected key, predicate and timeout, with the existing ordinary sixteen-millisecond menu taps. This is 30 menu actions into one original stage; career/save, driving-input acceptance, pause, reconnect, occupied-port and storage-restart checks are excluded. Results say `diagnostic-completed`, never native acceptance or visual pass.

The driver preserves initial-menu, original-Low-settings and original-stage system PNG/console/DOM captures. Final system screenshot collection is independent of the Observer so that a blocked UI/HTTP request still leaves the actual display. Each HTTP outcome is logged; failed GETs never reuse an old successful observation. Installation failures preserve the existing bounded XML/window/screen diagnostics without taking UI actions.

Twelve driver tests cover the original cached report, package binding, held/missing keys, identity/session cancellation, source-bound subset, exact query navigation, fresh frames, transport failure, game errors and zero device observations after rejected preflight. The Node fixture verifies no native poll or GL-context call and no mutation of the supplied game state.
