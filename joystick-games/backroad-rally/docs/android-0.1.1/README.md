# Backroad Rally 0.1.1 的 Android TV 实测

从已公开的测试发行版下载并核对了 `backroad-rally-0.1.1.apk`。包名为 `com.ecojust.joystick.backroadrally`，版本码为 2，大小为 105,024,551 字节，SHA-256 为 `772f628b498ed73b7ac378e30797f4007145960222af0040be89b8e28b9af13d`。APK 包含 338 个资产条目，网页构建的 333 个文件与静态浏览器测试所用文件逐份一致。[公开测试版](https://github.com/ecojust/pureTV/releases/tag/joystick-racing-nine-test-20261120) · [独立 APK 签名校验](https://github.com/ecojust/pureTV/blob/e6747bd7d10a20dee7e0300dffd5c998d425a53c/package.json)

Android API 36 TV 模拟器通过原 pureTV TCP SDK 操作。普通端口和占用端口两种模式各通过 77 项控制与生命周期检查。普通模式收到 1,046 条输入的完整回执，占用模式收到 1,087 条，两者均覆盖全部九个按键。两个模式都因驾驶截图未显示赛车、道路或景物而验收失败，计时器、手柄卡和仪表盘可见。[原运行](https://github.com/ecojust/pureTV/actions/runs/44681226359) · [普通模式原图](https://github.com/ecojust/pureTV/blob/2c4d4dc0b19adf91ccaa1f23f8c370359f70fe9f/artifact/backroad-rally-normal/playing.png) · [占用模式原图](https://github.com/ecojust/pureTV/blob/2c4d4dc0b19adf91ccaa1f23f8c370359f70fe9f/artifact/backroad-rally-occupied/playing.png)

另一台同规格模拟器用同一签名 APK 和原 SDK 进入芬兰赛段。实际 WebGL2 设备名为 `Android Emulator OpenGL ES Translator (Google SwiftShader)`，同时提供两项浮点颜色缓冲区扩展，上下文未丢失。独立测试程序向原 WebView 发送两次固定 P 键，原 HUD 依次报告后处理开启、关闭和恢复开启。三次画面都是 low 55%，绘制缓冲区均为 1056 × 594。关闭时出现了对手的名字，三张图上均无车辆或道路。原 APK 的浮点输出类型在三个阶段相同。0.1.2 会为已识别的软件渲染器选择 RGBA8 输出，并将设备像素比限制在 1。[上下文和 HUD](https://github.com/ecojust/pureTV/blob/fead24fa947978a89270f955e04862c422a42621/evidence/backroad-original-apk-graphics-diagnostic/graphics-diagnostic/original-stage-running-capabilities.json) · [开启](https://github.com/ecojust/pureTV/blob/fead24fa947978a89270f955e04862c422a42621/evidence/backroad-original-apk-graphics-diagnostic/graphics-diagnostic/original-stage-running.png) · [关闭](https://github.com/ecojust/pureTV/blob/fead24fa947978a89270f955e04862c422a42621/evidence/backroad-original-apk-graphics-diagnostic/graphics-diagnostic/original-stage-post-toggled.png) · [恢复](https://github.com/ecojust/pureTV/blob/fead24fa947978a89270f955e04862c422a42621/evidence/backroad-original-apk-graphics-diagnostic/graphics-diagnostic/original-stage-post-restored.png)
