This change signs only the new `com.ecojust.joystickgraphicsqa.backroadrally` test APK. Nothing here rebuilds or signs that game.

The workflow has no caller-supplied inputs. Its Observer job checks the fixed original producer, runs boundaries and builds only the separate unsigned Observer. Only its signing step receives the existing signing-secret interfaces. The helper checks the exact committed source/build receipt, safe bounded APK members, exact compiled test-only manifest and original producer before reading those interfaces; it verifies the pinned existing certificate, signs only the Observer, checks alignment and all payload hashes, and emits a distinct test-only receipt. Passwords are passed by environment reference, the temporary key is mode 0600 and removed on failure or success, and command failures expose only sanitized codes. No real key or signing credential was accessed during preparation.

The runtime job has no signing secrets. It downloads and verifies the original signed artifact with the existing reader and unchanged original input verifier, then verifies the new Observer separately. It executes Driving's one-normal-mode diagnostic driver, with the same emulator build `16970787`, API 36 Android TV x86_64, 2,048 MB RAM and SwiftShader configuration as the original `382de` comparison. There is no new Vulkan switch. The old Observer remains validated but is not started. New graphics evidence is not formal acceptance; the unresolved blank-track playing image continues to block delivery.

The independent `export` job alone has `contents: write`. It reads only the two fixed small evidence artifacts after exact run/source/attempt, producer and successful-upload checks; verifies each original ZIP digest; and permits only named logs, screenshots, public receipts and the explicit executed-source closure. APKs, wrapper ZIPs, key files, environment files, unknown paths, traversal, symlinks, duplicates and oversized entries are rejected. Bounds are 32 MiB per downloaded ZIP, 16 MiB per file and 64 MiB total original evidence. The export preserves failed reports and says `formalAcceptance: false`. A create-only Git lease writes `build-assets/backroad-graphics-diagnostic-{run}-attempt-{attempt}` and cannot replace an existing branch.
