# Backroad macOS query compatibility diagnosis

Original run `44602407034`, attempt 1, source `ea7854ca06ed53967aed00fe160034185f2906b3`: native ARM, occupied-port ARM and Rosetta all failed the 90-second initialization wait. The original reports and state snapshots remain under `docs/racing-nine/native-readiness/ci-44602407034-attempt-1/original-arm-export/`; hashes and exact paths are recorded in `analysis.json`.

The native agent identified the first source-level blocker: `LocalAssetServer.swift` rejects every request containing `?`, while the original Backroad loader always adds content hashes such as `/data/menu.json?v=198988baa6`. Independent review found a second blocker: the WK navigation delegate requires `url.query == nil`, rejecting the original same-page menu-to-race URL. The loader hashes and gameplay parameters must be retained; removing them from the game is not an equivalent fix.

The original `runMenu()` first awaits `loadMenuData()`, before calling `loadSave()`, registering gameplay hooks or creating a renderer. A rejected JSON request is consumed by `main().catch`, which inserts `#fatal`; it does not reach the adapter's `unhandledrejection` listener. This explains why the original read-only states can show empty errors, empty gameplay, renderer loading and zero frames. All three states have a ready host, thousands of adapter polls and 367 initial/current storage keys, so the reports do not support a stalled storage bootstrap.

`replay.mjs` executes the fixed original TypeScript data loader and navigation functions in Node against a source-equivalent HTTP rejection fixture. The first GET returns 400 and the original loader throws `data/menu.json: HTTP 400`; a fresh original loader instance with a path/query-separated fixture receives the unchanged JSON. The original navigation function produces the query rejected by the original WK guard. `replay-result.json` preserves the actual result. This is not Swift, WKWebView or game/GPU execution. The original native run has no HTTP access log, so the report does not pretend to contain a recovered native 400 trace.

`frozen/` and `source-bindings.json` preserve the exact relevant source bytes. The nine-candidate static scan finds local hash and stage queries in Backroad; Penguin's only matching navigation is an optional external checkout URL, not a local asset query. No matching query literal was found in the other seven games. This scan does not prove the absence of every computed URL and does not justify rebuilding already-passed packages.

No game, renderer, asset, host source or original report was changed by this investigation. Shared Mac query handling is being corrected separately with real HTTP and navigation checks; a rebuilt native Backroad run is still required.
