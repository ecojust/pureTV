合集正式目录共 **3,888 款**，其中 **3,867 款可勾选**，另有 **21 条已发布或同源记录**可对照。游戏可以先按兴趣勾选，移植时再核对所用版本和素材的授权。可用游戏前的序号挑选，同名游戏也有独立编号。
