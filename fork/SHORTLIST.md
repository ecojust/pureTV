# 安装即用的精简选品建议

核对日期：2026-11-08。根据 TVAPP 已收录及超限候选，按具体用途每类最多保留两款；优先原版免费、有现成 APK、无需找源、填写接口或自行编译的应用。合适的不足两款就留空。

这是选品建议，尚未执行缩减归档、替换安装包或商城上架。判断依据是原作者文档、公开发布资产和上游说明，没有逐款安装到实体电视测试。原版的说明也不等于 TVAPP 修改包已经通过验证。[核对依据](planning/shortlist-sources.json)保留初选记录；以下按用户追加的“直接安装就能用”要求收紧。

## 优先候选

“免费”区分客户端与内容服务：不使用会员解锁修改版；B站会员视频、平台付费画质等仍按原平台权限。若要求连所有内容、画质都免费，B站及平台聚合类不符合该标准。

## 因本次条件排除

- **FongMi、TVBox、我的电视·〇**：需要准备播放源或接口。即使客户端可免费使用，也不符合无需配置就能看内容。
- **Simple Live**：当前官方明确不提供 Release 安装包，需要自行编译。
- **HTV**：官方明确完整内置源需赞助，不能当作完全免费开箱即用方案。
- **各类“VIP 解锁版”及换名修改包**：不使用修改包宣传证明原版免费。TVAPP 的 `BBLL5改1.5.2.apk` 不代替官方 BBLL 原包。
- **MT／NP／ES 修改版**：MT 有 VIP 功能，NP 偏 APK 编辑且缺少电视易用性证据，ES 收集包为会员解锁版。

## 老电视需另选版本

- **WebViewTV** 当前文档要求 Android 5.0、WebView 78 及以上，内存最低 2GB；不适用于直接给 Android 4.4 安装最新版。
- **纯粹直播 TV** 当前版要求 Android 7.0 及以上；作者给 Android 5／6 用户指向旧版 `v2.0.20`。旧版接口目前是否有效尚未实测。
- **BBLL** 作者说明 `api19` 是 Android 4.4 兼容版，普通版要求 Android 5.0 及以上；本次核对的最新 GitHub 发布只列普通 `BBLL1.5.2.apk`，未获取 api19 包。
- **BiliTV** 作者称理论支持 Android 5.0，所列实测设备有限；不能据此保证小米电视 2／4 能用。

因此，这份选品表不等于对 Android 4.4、6.0 全部机型的兼容承诺。后续实际收录时还应固定原版 APK、验证来源，并在目标电视检查安装、首次启动、遥控器和核心功能。
