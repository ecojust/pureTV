> **兼容性**：仅含32位 ARM（armeabi-v7a）原生库；用户在 Apple Silicon / APK Checker 电视模拟器安装时报 INSTALL_FAILED_NO_MATCHING_ABIS。需要支持该32位 ABI 的 Android 系统或原作者提供 ARM64 版本。 [检查记录](../../verification/2026-11-10-education-compatibility/README.md)
