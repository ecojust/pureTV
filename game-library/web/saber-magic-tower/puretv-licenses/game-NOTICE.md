# 光刃魔塔

Saber Magic Tower is a new pureTV game under the repository MIT license. Its 21 maps, rules, language, procedural meshes, materials and animation were created for this campaign. Saber / Descent by Vheissu (commit 8e4f70cf99bfb1342282ca4e9cd2f3d5db8519d6) is the design reference for the glowing saber, strike chains, heavy cleaves and timed parries. The inspected revision has no license file. The campaign uses its own implementation of those ideas and of the classic Magic Tower key, door, gem, merchant and staircase mechanics.

https://github.com/Vheissu/saber-battle/tree/8e4f70cf99bfb1342282ca4e9cd2f3d5db8519d6
