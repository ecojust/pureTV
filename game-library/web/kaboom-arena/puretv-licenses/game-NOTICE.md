# Kaboom Arena

TV adaptation of [janroudaut/kaboom-arena](https://github.com/janroudaut/kaboom-arena/tree/b9191f6f045e4153ec238a47969a21621a940713), distributed under WTFPL v2. Kaboom Arena is an unofficial fan tribute to Bomberman and has no affiliation with Konami. The arena simulation, enemies, rules, art, audio and renderers come from the upstream browser game.

Three.js and its addons use the MIT license. Press Start 2P uses SIL OFL 1.1. The QR library and Rails Action Cable client use MIT licenses. See the license files under `src/game/vendor/`. The packaged game operates locally. The Rails server and public online rooms are outside this port.
