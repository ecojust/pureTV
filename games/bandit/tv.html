金库大盗

在劫案模式中，逃脱者要在倒计时结束前将钻石送到撤离点。破坏者负责藏起钻石、守住屋子。

玩法与操作

  1. 标题页的 PLAY 会快速匹配到公共房间。和朋友玩时，直接选 CREATE ROOM，选择 PRIVATE、HEIST 和人数，然后按 CREATE 建房。
  2. 在 SAFEHOUSE 把 ROOM CODE 发给同伴。同伴在标题页选 JOIN BY CODE 输入房间码。劫案至少两人，所有人选 READY 后由房主开始。每轮先看自己的角色。
  3. 逃脱者靠近家具长按 E 搜寻，找到钻石后送到 GETAWAY。用方向键移动，Shift 冲刺。标准手柄用摇杆移动、A 互动、RT 冲刺。
