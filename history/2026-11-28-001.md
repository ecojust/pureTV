## 行动记录

开始核对 Manager 游戏栏目、电视市场的下载与安装流程，以及网页游戏的 Android 封装方式。

打包范围已明确为客户端已有的游戏。核对各款独立电视安装包与六款作者在线原作的共用宿主。

「游戏」栏目现在可切换网页游戏和电视游戏市场，两处市场入口共用版本选择、下载、安装与队列。目录中的 50 款原有安卓游戏包已逐项核对大小、SHA-256、发布证书及包名，合计 308,631,164 字节。客户端按冻结目录获取安装包，校验后缓存。其余六款复用原有中文指南、扫码和手柄宿主，各有唯一包名和电视封面，可直接打开对应的作者网页。已从固定源码启动专用签名流程。[独立包宿主和生产签名 PR #94](https://github.com/ecojust/pureTV/pull/94) · [六款安卓包的构建、签名与共存验收](https://github.com/ecojust/pureTV/actions/runs/46111689982)

签发六款 APK 后，Manager 将共用的代码和资源存为 1,550,626 字节模板。测试中断开网络，用 Rust 客户端准备并导出全部六款，结果与固定证书签名原件逐字节一致。对话框取消仅作用于该次准备请求。Android 首轮确认六包可共存，测试脚本的启动参数有误。已改为启动系统解析出的电视 Activity，并复用同批原件验收。[源码 PR #95](https://github.com/ecojust/pureTV/pull/95) · [设备复验修订 #96](https://github.com/ecojust/pureTV/pull/96) · [离线组装核对](../desktop/docs/release-0.7.0-evidence/assembled-game-apks.json)

Android TV API 36 第二轮逐款从独立入口冷启动，六款均连接到对应作者域名。第三轮改用电视方向键和确认键操作，并记录退出前后的系统前台窗口。Manager 0.7.0 从提交 `37d067eb` 构建 Windows x64 安装版与便携版、macOS 两种架构和 Linux x64 DEB。[逐款启动记录](https://github.com/ecojust/pureTV/actions/runs/46112357565) · [遥控器复验](https://github.com/ecojust/pureTV/actions/runs/46112987912) · [桌面正式构建](https://github.com/ecojust/pureTV/actions/runs/46113023059)

Manager 0.7.0 于 05:48 UTC 正式发布。五个下载文件经匿名下载，文件大小和 SHA-256 全部匹配。182 项桌面界面回归通过。实际运行公开 Linux 版后，在游戏栏目逐款生成六个独立的 APK，验证了自选位置保存、无电视时入队、获取已有《Tetris》包，以及从市场选择并下载历史版本。[桌面正式版](https://github.com/ecojust/pureTV/releases/tag/desktop-v0.7.0) · [验收记录及客户端截图](../desktop/docs/release-0.7.0-evidence/README.md)
