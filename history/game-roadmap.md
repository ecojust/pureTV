# 第63–100款候选路线

状态：百款任务已完成，本表保留为历史候选规划，原暂定名称及描述不回写成最终规格。最终100款见[实际进度](../resource/game-kit/progress.json)和[审计说明](../resource/game-kit/docs/delivery-audits/README.md)。本表不构成新待办，也不作为验收计数证据。

| 编号 | 暂定ID／名称 | 独立规则核心 |
| --- | --- | --- |
| 63 | orchard-snake／果园游蛇 | 持续移动的身体占格、吃果增长、禁止反向、自碰和墙碰；三种障碍路线 |
| 64 | tower-overlap／叠塔工匠 | 抓准移动石板的落下时机，仅保留与前层重叠的宽度，逐层收窄后达到目标高度 |
| 65 | brick-paddle／弹板清砖 | 移动球拍改变反弹角、球砖碰撞、失球有限生命，清完目标砖 |
| 66 | merge-tiles／数字汇聚 | 整行滑动、相等数字每步只合并一次、确定性新块，达到目标值 |
| 67 | four-in-row／四子列阵 | 重力落子、四向连四、公开确定性对手，三种可胜残局 |
| 68 | draughts-trail／跳吃棋径 | 斜行棋子、强制跳吃、连跳和升王，与确定性对手争胜 |
| 69 | hex-connection／六角连线 | 六邻接棋盘、连接己方两边、对手阻断，连通路径判胜 |
| 70 | seed-mancala／播子棋盘 | 环形逐颗播种、己仓再走、对面捕获、终局收籽计分 |
| 71 | dots-boxes／点线围格 | 轮流补边、封格得分并连走、棋盘耗尽多数胜 |
| 72 | traffic-escape／车阵出口 | 不同长度车辆仅沿车轴滑动、不能重叠，让目标车驶出 |
| 73 | river-guard／渡河守则 | 船容量和驾驶者约束，两岸无人看守时的捕食／冲突限制 |
| 74 | torch-bridge／夜桥接力 | 两人共灯过桥、速度取慢者、灯须带回，有限总时间 |
| 75 | sorting-wires／比较器工坊 | 在有限层放置比较器，所有公开二进制输入都须正确排序 |
| 76 | nim-orbit／取石回合 | 多堆取石、每回合只动一堆、最后一子规则，与确定性对手对弈 |
| 77 | domino-chain／骨牌接龙 | 手牌两端同点匹配、无牌可接时补牌／让行，有限固定牌局 |
| 78 | tile-garden／叠牌花园 | 仅顶面无遮挡且左右至少一侧开放的同纹牌可配对移除 |
| 79 | pocket-solitaire／口袋接龙 | 红黑交替降序列、同花升序收牌、有限空位临存，固定可解牌局 |
| 80 | liberty-stones／气眼棋局 | 正交气、提子、自杀限制和简单劫，与确定性对手完成残局 |
| 81 | quadrant-five／旋盘五子 | 每回合落子后旋转一象限，连五与同时连五判定 |
| 82 | sum-crossings／交叉数和 | 横竖连续数段分别满足和数且段内不重复，公共线索推理 |
| 83 | shade-duplicates／墨格净盘 | 阴影去除行列重复数，阴影不可正交相邻、白格须连通 |
| 84 | island-ink／岛海分界 | 每岛一个数字且面积精确、岛不相邻、海连通且无2×2海块 |
| 85 | light-chambers／灯室布光 | 灯沿行列照明至墙、灯不可互照、数字墙限制邻灯数 |
| 86 | fleet-ledger／舰队推演 | 按行列数和舰队长度摆放互不接触舰船，公共线索唯一解 |
| 87 | color-paths／彩径连对 | 配对端点之间互不重叠的正交路径并覆盖指定区域 |
| 88 | rectangle-atlas／矩形图谱 | 将全图分成每块含一个面积数字的无重叠矩形 |
| 89 | tetro-islands／四格群岛 | 每区域选一枚四格块，全体连通、无2×2实心且同形不可接触 |
| 90 | binary-weave／双色织阵 | 每行列两色等量、不能三连且行列互异；固定线索保护 |
| 91 | rook-rescue／车阵解围 | 小型棋盘合法走子、王安全和捕获顺序，有限步内解围 |
| 92 | lane-bowling／轨道保龄 | 选择发球位置和角度、球与瓶碰撞、有限投球达到击倒目标 |
| 93 | pocket-golf／口袋果岭 | 调整角度和蓄力、墙面反弹与地面阻力，有限杆数低速入洞 |
| 94 | orbit-turret／轨道炮台 | 旋转炮台提前量射击来袭目标，弹速、冷却与漏防额度 |
| 95 | star-formation／星阵防线 | 横移射击移动阵列、弹丸遮挡与敌弹躲避，清除固定波次 |
| 96 | river-hopper／流桥跃行 | 逐格穿越车流、随浮木漂移过河、边界与落水危险 |
| 97 | rooftop-runner／屋顶奔跑 | 固定前进速度下跳跃／下蹲处理不同障碍与间隙 |
| 98 | word-ladder／字梯工坊 | 每步只改一个字母且新词在公开词表，有限步到达目标词 |
| 99 | twenty-four／四数算坊 | 四张数字各用一次、选择两数与运算逐步组合，达到24 |
| 100 | logic-workbench／逻辑工坊 | 在公开有向电路槽放AND／OR／XOR／NOT，满足整张真值表 |

题材是可调整的工程路线，不能用本表替代设计、可解性证明或验收。63–100分配时仍需明确动作、失败、输入取消、终局、三关难度、QA策略与画面检查。私有谜底类游戏不得在公开快照泄露答案；物理／动作类不得靠改状态或改浏览器时钟通关。

修订记录：第64款最初考虑下落方块，经核对仓库已有tetris应用后，于实际实现前改为移动石板重叠裁切的叠塔玩法；没有将俄罗斯方块换皮计为新增游戏。
