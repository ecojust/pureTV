# 首页游戏来源入口及客户端实机画面图标

状态：completed

## 用户 prompt

### U1

> readme中游戏列表，如果是从原有repo来封装的，那么下面再加一个链接的图标，点击之后直接跳到原本的repo
> 然后所有游戏的客户端软件logo，必须采用游戏内容画面作为图案，不要单纯的文字

## 行动记录

已登记请求，下一步逐项核对来源、图标素材、安装包和构建入口。

### A1 · 核对游戏与来源，冻结安装包和图标的输入

- 双语首页各有 37 张游戏卡片，其中 29 款封装自 17 个上游仓库。生成器读取每款游戏声明的原仓库，另外 8 款沿用原有入口。
- 158 个游戏源码目录均已选取游玩截图并核对方形裁剪。发行输入清单记录了 141 个现有独立 Android 包、41 个 macOS 客户端和 41 个 Windows 客户端的下载地址及 SHA-256，其中包含 4 款已从首页隐藏的游戏。其余 17 款只有源码。
- 本地回归核对了截图选取、横幅与方形取景、Windows 多尺寸 ICO、无效输入。三个平台的工作流将从固定的原安装包生成发行文件并检验其实际图标。

### A2 · 验证源码构建与原生安装包

- 新构建使用游戏自己的截图，macOS 写入 ICNS，Windows 写入不同尺寸的图标资源。Android 使用方形启动图标和横幅，并将素材纳入构建输入校验。
- 用实际工具链编译并比对了 11 款旧版 Gradle 游戏及 Game Kit、手柄移植游戏各 1 款的 Android 图标。源码／签名契约回归通过 36 项。电视商城的快捷方式图标也改为同一取景。
- 已建立 GitHub 草稿发行。首次原生工作流暴露了托管 SDK 写权限、Windows 快捷方式路径及不同 macOS SDK 重签后的比对差异，已分别修正并重跑。后续 Android 工作流已用正式证书完成 141 款 APK 的构建签名，仍待安装态检验及上传。此次客户端图标变更保留以前按游戏版本归档的验收记录。

### A3 · 核对 macOS 发行文件与历史下载入口

- [macOS 原生验证工作流](https://github.com/ecojust/pureTV/actions/runs/44870559182)已通过，41 个 DMG 和 25 个 ZIP 已进发行草稿。核对全部 66 个文件的大小、SHA-256、签名和截图来源。另行解包 Kart Royale 确认为 `com.ecojust.joystick.kartroyale`，应用图标逐像素匹配该游戏的海岬之冠驾驶画面。
- 游戏详情、手柄游戏索引与双语安装指南区分本次客户端和以前的实玩验收。旧版 APK、游戏录像及归档校验值按原发行版本保留。所有 17 个上游地址已通过 GitHub API 核对公开仓库根地址。
- [PR #55](https://github.com/ecojust/pureTV/pull/55)已建立。Windows 和 Android 原生安装验证仍在运行，首页尚未切换下载。

### A4 · 完成原生客户端的专项验证

- [Windows 原生验证](https://github.com/ecojust/pureTV/actions/runs/44870768064)覆盖 41 个独立安装程序，另有 20 个便携 ZIP。逐款核实已安装游戏、安装器、卸载器中的多尺寸图标、快捷方式目标及启动；61 个发行文件的总大小为 618,111,810 字节。Kart Royale 原生窗口使用自己的图标。
- Android TV 的覆盖安装在一次性 API 36 模拟器上完成。逐款先装原发布包，再用同一证书签名的新版覆盖安装；通过 PackageManager 读取应用及活动的启动图标和电视横幅，打开实际电视启动入口并核对已安装 APK 哈希。两个生产工作流的 8 个设备测试批次合计验证 141 款。[第 2 批](https://github.com/ecojust/pureTV/actions/runs/44872763543) · [其余 7 批](https://github.com/ecojust/pureTV/actions/runs/44873014406)
- 在并发写入的草稿发行里，资产列表翻页可能重复返回同一条记录。三个已通过设备验证的批次在上传时遇到这一问题。恢复工作流按资产 ID 和 SHA-256 去重，仅接受与原签名、原设备验证记录逐字节一致的 APK。[恢复上传](https://github.com/ecojust/pureTV/actions/runs/44873544114)

### A5 · 发布客户端并切换下载

- 已从固定源码提交 `444bd563f2dbdb942a73bf1307f1c65b12224400` 公开[游戏客户端发行](https://github.com/ecojust/pureTV/releases/tag/gameplay-icons-2026.11.21)，桌面管理器的 latest 发行仍为 `desktop-v0.5.9`。发行包含 223 个独立客户端主安装包、45 个桌面 ZIP 和 10 份平台验证记录。全部 278 个文件已通过匿名公开下载并重新计算 SHA-256、比对字节数。
- [逐款客户端文件索引](../docs/releases/gameplay-icons-2026.11.21/clients.json)按平台列出实际版本、下载地址、字节数及验证记录。两份首页各有 37 款游戏、111 个游戏专用平台下载按钮和 29 个上游仓库按钮。公开的源码仓库数为 17。所有游戏卡片的语言对应、文件身份及四款隐藏项都已核对；5 个截图渲染回归、10 个电脑客户端回归和 3 个手柄桥接回归通过。
- 112 个资源 APK 已分别通过证书、包名、版本、安装证据及像素核对。另从发行处下载的 29 个手柄移植 APK 逐一核对了实际嵌入的 PNG。当前游戏目录保留旧版的录像、校验和与验收记录。覆盖安装验证使用 Android TV 模拟器。macOS 验证使用临时签名的原生应用。

- 逐一核对 100 项历史游戏验收及其原始录像；Gravity Courier 的历史审计回放通过 257 项。124 份 Android 游戏详情页及 Neon Rush 的 macOS 详情页已核对。Git 暂存的 112 个新 APK 全部匹配已公开的发行文件。
- 交付与合并记录见 [PR #55](https://github.com/ecojust/pureTV/pull/55)。本次发行保留上一版本的归档及其验收范围，17 个只有源码的目录已接入同一游戏画面图标构建流程。
