### A2 · 首要型号、源码边界与自动回归

- 用户确认小米电视 4、Android 6 为重点。清单设为 P0 实机样本，但确切型号／SDK／固件／ABI 未采集，所有实机项仍为 NOT_RUN/E0；此前 Android 4.4 目标保留。
- AOSP 固定标签核对 API19–36 的 current-user、PM、HOME/content 能力分界，特别确认 API21/22/23 的 mUserLru 在同锁下维持当前用户位于末项。生产回退仅扩展这些核实 SDK，API20 和其他未知版本不泛化。
- 修复默认 HOME 多候选时取首项的问题，改为只接受唯一规范化、非 Resolver/Chooser 组件，避免错误放开停用／卸载保护。
- 新增 11 项管理器兼容回归和 1 项解析回归；完整核心首轮 **100 passed、0 failed、1 ignored**，包括 Android6 同用户安装复查、命令缺失不去掉 --user、未知容量和歧义 HOME 保护。样本为合成／AOSP格式，不能当小米实测。
- Info 三语同步扩展范围及启动器 minSdk26 限制；构建（750 条文案）和 3 项相关 UI 通过。首轮文案检查发现拉丁开头字符串被抽取为片段，已调整自然语言开头后通过；一次构建命令误在根目录执行失败，未改变代码，原始日志均保留。
- [品牌／版本验收清单](../desktop/docs/tv-compatibility-checklist.md) 共 30 项用例；[命令源码依据](../desktop/docs/android-command-compatibility.md) 与两处生产修改完成独立只读复核，无实质问题。

### A3 · 只读采集工具与跨平台门禁

- 新增 Python 标准库只读采集工具及 **23 项自动测试**：明确选择已授权目标、固定读取命令、每命令／总预算／输出上限、SDK19/21/22/23 用户回退、旧 df 回退、HOME 元数据／歧义处理、属性地址过滤、报告不保存应用名单和错误原文，写能力全部为未验证。
- 独立审查发现并修复两处：Windows 读线程持有文件描述符锁时，主线程 close 可能突破超时，改为读线程自行关闭；AOSP resolve --brief 的正常 metadata 行原被误判，改为严格识别已知格式。加入相应回归后 23 项全通过，原始日志 `probe-02.log`，二次只读复核通过。
- 清单增加 Linux/macOS、Windows 采集用法、报告含义和小米电视4首轮未执行事项。报告不认证实体电视、不推断写操作可用；后续需要在实际连接电视的电脑上执行采集和逐项验收。
- Python 23 项测试已加入现有桌面四平台 CI，其余原有门禁保留。测试作者末次补入未知 SDK 拒绝输入后，最终冻结核心再次完整验证 **100 passed、0 failed、1 ignored**（`core-02.log`）；生产修改没有变化。准备冻结源码推送后检查 Windows、两种 macOS、Linux 的实际执行结果；没有创建新发布标签。
