## 用户 prompt

### U1

> 按需优化游戏专栏的所有游戏，需要支持PC游玩（键盘控制，手柄无线连接）电视游玩（扫码加入提供虚拟手柄界面，或者真实手柄无线连接），在不影响主游戏界面的前提下，优化用户连接显示

### U2

> 窗口装配 这个游戏隐藏；然后表格里面文字只显示游戏名字，不要带tv字眼
> 有的表格多出预览两个字，检查一下

## 行动记录

- 核对首页六类 35 款游戏，含 12 款资源游戏与 23 款独立移植。原首页链接到 35 个 Android、24 个 macOS 和 19 个 Windows 安装包。Android 的 Game Kit 宿主已提供局域网手机房间，但独立移植的共用输入层只选择 Wi-Fi 实体手柄，手机接入需要从输入和游戏画面两端验证。
- 电脑端正复用已发行 APK 内的原版网页游戏资源，为没有原生桌面安装包的游戏补充键盘和局域网手柄入口；电视端按宿主核查扫码、按键、连接身份显示和断线处理。
- 12 款资源游戏的电视端将手机与实体手柄按席位显示。七款旧游戏取消连接后自动加宽侧栏的行为。俄罗斯方块使用真实 Java 局域网房间和手机网页，按 START 进入游玩；在 960×540、1280×720 两种视口实测，玩家加入或离开时画布边界一致。原手机 ID 和会话密钥分开处理。[12 款 Android 构建](https://github.com/ecojust/pureTV/actions/runs/44756990162)
- 独立移植的 23 款复用现有 Android 房间与真实二维码，保留各游戏键盘映射，并支持手机九键输入。Sugarplum Drop 已通过两个尺寸的二维码解码、Java WebSocket 手机九键和 TCP SDK 输入检查。14 款与 9 款赛车分别冻结在 `89faf2e4`、`20e50e1e`，对应安装包与运行器正分组复核。[14 款冻结源码](https://github.com/ecojust/pureTV/commit/89faf2e4f5e17bd54d08859962dc9335c8b4cddb) · [9 款冻结源码](https://github.com/ecojust/pureTV/commit/20e50e1e1e5ef4b2cdd8f1fa4f482916258b7284)
- 电脑启动器只在本机提供游戏网页，按游戏缓存经过 SHA-256 校验的资源，将局域网真实手柄输入传给原游戏。Windows x64 可执行文件在真实 Windows 上以键盘和 SDK 各启动俄罗斯方块并移动方块。首批已发行的 35 份原游戏包共 188,497,079 字节。[Windows 实玩运行](https://github.com/ecojust/pureTV/actions/runs/44757301102)
- 在 master 上独立修正七张卡片苹果图标的悬停与替代文字，两份指南收录相应 macOS 独立包的预览状态。用 GitHub Markdown 渲染检查两种语言各 35 张唯一卡片、六类、每行四格，封面加载失败时也只保留一次游戏名。[首页更新](https://github.com/ecojust/pureTV/commit/08986f74fdfb51117f2b786504f60f20e0bf66f4)
- 已核对 12 个 Android 原签包的公开固定下载及 SHA-256。旧版与新版签名证书一致，12 个 PC 资源包内的 585 项游戏文件与对应签名 APK 逐字节相同。Android 12 款的升级、输入与游戏状态正在六个分片上核对。[Android 运行](https://github.com/ecojust/pureTV/actions/runs/44759906140) · [整合 PR](https://github.com/ecojust/pureTV/pull/48)
- 独立移植的电视验收复用原生 Java 房间，扫描游戏实际显示的二维码，在第二个浏览器操作手机虚拟手柄。Sugarplum 的双尺寸九键、断开后暂停和实体手柄协议实测均已收录。[重跑方式和结果](../joystick-games/qa/controller-input/README.md)
